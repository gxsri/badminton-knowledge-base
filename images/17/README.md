## 图1：运动控制完整链条

![运动控制链条](../images/17/motor-control-chain.svg)

**对应章节**：第一章 1.1-1.2

**图解说明：**

```
大脑想动 → 神经传信号 → 肌肉收缩 → 筋膜传力 → 骨骼运动 → 动作完成
   ↑                                                          |
   └──────────────────── 感觉反馈 ─────────────────────────────┘

这不是单向链条，是一个闭环。
每一层都可能出问题。康复的原则是不只看疼痛的位置，要看整个链条。
```

## 图2：激痛点形成机制——能量危机恶性循环

![激痛点循环](../images/17/trigger-point-cycle.svg)

**对应章节**：第四章 4.1.3

**图解说明：**

```
激痛点的恶性循环：

肌纤维过度负荷 → 钙离子调节异常(持续收缩) 
  → 毛细血管被压(缺血缺氧) → ATP不足(钙泵失灵)
  → 更无法放松 → 代谢废物堆积(刺激痛觉神经)
  → 脊髓异常兴奋(更多肌纤维卷入) → 回到第一步

物理层面总结：
激痛点 = 一小团肌纤维因为能量危机而无法放松
→ 按压痛 = 缺血的代谢废物刺激了痛觉神经
→ 牵涉痛 = 脊髓层面的信号"串线"
```

## 图3：牵涉痛机制——脊髓节段"串线"现象

![牵涉痛机制](../images/17/referred-pain.svg)

**对应章节**：第四章 4.1.4

**图解说明：**

```
以冈下肌激痛点为例：
冈下肌痛觉信号 → 脊髓C5-C6节段(与肩前侧信号交汇)
→ 大脑分不清信号来源 → 告诉你"肩前侧痛"
→ 问题实际在肩后侧的冈下肌

临床意义：患者说肩前侧痛 → 不要只查前面，查冈下肌和小圆肌
```

## 图4：上交叉综合征——圆肩+头前引

![上交叉综合征](../images/17/upper-cross-syndrome.svg)

**对应章节**：第三章 3.3

**图解说明：**

| 紧张(红色) | 无力(蓝色) |
|:-----------|:-----------|
| 胸大肌 | 深层颈屈肌 |
| 上斜方肌+肩胛提肌 | 中下斜方肌+菱形肌 |

**纠正方案：**
- 拉伸：胸大肌（门框拉伸）、上斜方肌（侧向拉伸）
- 强化：中下斜方肌（Y/T/W训练）、深层颈屈肌（收下巴）

## 图5：下交叉综合征——骨盆前倾

![下交叉综合征](../images/17/lower-cross-syndrome.svg)

**对应章节**：第三章 3.3

**图解说明：**

| 紧张(红色) | 无力(蓝色) |
|:-----------|:-----------|
| 髂腰肌+股直肌 | 腹肌 |
| 竖脊肌腰部 | 臀大肌 |

**纠正方案：**
- 拉伸：髂腰肌（弓步拉伸）、股直肌
- 强化：臀大肌（臀桥）、腹横肌（死虫式）

## 图6：肩袖四肌——包裹肱骨头的稳定系统

![肩袖肌群](../images/17/rotator-cuff.svg)

**对应章节**：第二章 2.4

**图解说明：**

| 肌肉 | 功能 | 扳机点位置 | 牵涉痛区域 |
|:-----|:-----|:-----------|:-----------|
| **冈上肌** | 肩外展0-30° | 肩胛冈上方 | 肩外侧 |
| **冈下肌** | 肩外旋 | 肩胛冈下方 | 肩前侧到上臂 |
| **小圆肌** | 肩外旋+内收 | 肩胛骨外侧缘 | 肩后侧 |
| **肩胛下肌** | 肩内旋 | 肩胛骨内缘 | 肩后到手腕 |

**肩袖不是发力肌肉——它是稳定肌肉。**
杀球时肩关节内旋速度可达7000°/秒，肩袖不稳定→撞击综合征/肌腱炎/关节不稳。
