4周训练计划

Level 0-1 · 自适应框架 + 训练计划模板

核心理念：四个阶段是原则，不是日历。你需要做的是：把当前的训练量做到稳定，再做下一个。

每周训练频率计算

每周训练频率 = 恢复能力系数 × 基础频率 基础频率 = 3次/周（最低有效刺激量） 恢复能力系数： 年龄 < 25岁 → 1.2（可练3-4次） 年龄 25-40岁 → 1.0（3次） 年龄 > 40岁 → 0.8（2-3次，中间加一次恢复训练） 例：30岁 → 3 × 1.0 = 3次/周 例：22岁 → 3 × 1.2 = 3.6 → 取3-4次 例：50岁 → 3 × 0.8 = 2.4 → 2次力量+1次恢复

每周是否增量判断

状态判断标准行动
绿码上次训练后24-48小时恢复，精力≥7/10，无疼痛可正常训练
黄码48小时仍有明显酸痛，精力4-6/10减量50%或改为恢复训练
红码精力<4/10，有刺痛，睡眠<5小时休息

热身与整理时间公式

热身时间(min) = 年龄 ÷ 10 + 2 整理放松时间(min) = 年龄 ÷ 15 + 5 例： 20岁：热身 4分钟，整理 6分钟 40岁：热身 6分钟，整理 8分钟 60岁：热身 8分钟，整理 9分钟 热身内容必须包含： ✓ 激活训练部位（如今天练肩→弹力带外旋1组15次） ✓ 动态拉伸（非静态拉伸，训练前不做静态拉伸） ✓ 心率准备（从静止到训练心率的50%）
