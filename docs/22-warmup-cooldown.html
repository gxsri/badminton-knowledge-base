15分钟标准热身方案

阶段1：激活（3分钟）
  • 慢跑/高抬腿 — 2分钟，逐渐提高心率
  • 开合跳 — 1分钟，激活全身肌肉
阶段2：动态拉伸（5分钟）
  • 手臂环绕 — 前后各10次
  • 躯干转体 — 左右各10次
  • 弓步走 — 每侧8步
  • 侧向移动 — 每侧8步
  • 脚踝环绕 — 每侧10圈
阶段3：专项激活（4分钟）
  • 弹力带外旋 — 2×15次（肩袖激活）
  • 蚌式开合 — 2×15次（臀中肌激活）
  • 分腿蹲 — 2×8次/侧（下肢激活）
阶段4：技术激活（3分钟）
  • 徒手挥拍 — 20次慢速
  • 轻力对打 — 1分钟

重要原则：热身前不做静态拉伸！静态拉伸会降低肌肉力量。动态拉伸才是正确的热身方式。

25分钟比赛热身方案

阶段1：一般热身（5分钟） 慢跑 → 高抬腿 → 开合跳 → 后踢腿 阶段2：动态拉伸（8分钟） 手臂环绕 → 躯干转体 → 弓步走 → 侧向移动 → 腿摆动 → 脚踝环绕 → 颈部环绕 阶段3：专项激活（7分钟） 弹力带外旋 2×15 → 蚌式开合 2×15 → 分腿蹲 2×8 → 单腿站立 30秒 阶段4：技术激活（5分钟） 徒手挥拍 20次 → 多球高远球 20个 → 吊球 10个 → 轻杀 10个

训练后整理方案

阶段1：冷身（2-3分钟）
  • 慢走 — 让心率从运动水平降到<100bpm
  • 不要突然坐下 — 血液会淤积在下肢
阶段2：静态拉伸（5-8分钟）
  • 小腿后侧 — 每次30秒
  • 大腿前侧 — 每次30秒
  • 大腿后侧 — 每次30秒
  • 髋屈肌 — 每次30秒
  • 胸部拉伸 — 每次30秒
  • 前臂拉伸 — 每次30秒
阶段3：筋膜放松（5-10分钟）
  • 泡沫轴 — 每个部位30-60秒
  • 顺序：小腿→大腿前侧→大腿外侧→臀部→背部
  • 重点：找到酸痛点停留20秒

训练后营养补充时间表

0-15分钟： 快速碳水 1-1.2g/kg（白米饭/香蕉） 快速蛋白 0.3-0.4g/kg（乳清蛋白） 水分：减重×1.5倍 15-60分钟： 正常饮食（碳水+蛋白+蔬菜） 继续补水 睡前： 慢速蛋白 20-30g（酪蛋白/酸奶）
