发力原理 — 鞭打效应

羽毛球击球不是"用手打"，是全身动力链的传递。力量从地面开始，通过下肢→核心→上肢传递到球拍。

动力链顺序：脚蹬地 → 髋转动 → 核心传递 → 肩内旋 → 肘伸展 → 前臂旋内 → 手腕闪动 → 击球。任何一环断裂，力量都会损失。

发力效率检查清单： ✓ 脚有没有蹬地发力？还是只转了上身？ 看：投出后脚是否离地或转动 有 = 正确发力，没有 = 只用了上肢 ✓ 力量是从脚到手的顺序，还是"同时"发力？ 看：投掷动作是否流畅分阶段 流畅 = 好，僵硬同时发力 = 不对 ✓ 球出去的方向和身体朝向是否一致？ 偏差 >45度 → 核心没有参与稳定 如果1不过 → 退回到分腿蹲训练 如果1过2不过 → 做慢速弹力带模拟 如果123都过 → 可以加入速度变化

握拍技术

握拍是所有技术的基础。握拍不对，后面所有技术都会受影响。

正手握拍

正手握拍要点

虎口：对准拍面窄边（拍框侧棱）
手指：食指稍前于拇指，像握鸡蛋一样
掌心：留空，不要握死
松紧：准备时放松，击球瞬间握紧

反手握拍

反手握拍要点

转换：从正手握拍，拇指顶到拍柄宽面上
拇指：发力点，顶住拍柄
食指：收回，与中指并拢
发力：拇指顶推 + 手腕外旋

网前技术

搓球

要素要点
握拍放松握拍，靠手指控制
击球点网前最高点，抢高点
拍面切削球托侧面，产生旋转
力量轻柔，靠手感而非力量

推球

要素要点
时机对手回球质量不高时使用
动作拍面稍后仰，向前推送
落点对方后场两角
变化可配合假动作，先搓后推

勾球

要素要点
动作拍面斜切，改变球路方向
隐蔽准备动作与搓球相同
落点对方网前对角
时机对手站位偏后时使用

后场技术

吊球

吊球技术要点

动作：与高远球准备动作一致，击球瞬间减速
拍面：稍后仰，切削球托底部
落点：对方前场，贴网下落
变化：轻吊、劈吊、拦吊三种

杀球

杀球技术要点

起跳：双脚起跳，身体后仰成弓形
击球点：身体前上方，手臂伸直
发力：全身协调发力，不是只用手臂
落点：对方身体或边线附近

杀球常见错误：①只用手臂甩（没有转体）②击球点太低（起跳时机不对）③杀球太猛（控制比力量重要）④杀球后不回位（杀完就站着看）

技术训练顺序

Level 1-2：高远球 → 吊球 → 杀球 → 挑球 Level 3-4：搓球 → 推球 → 勾球 → 扑球 Level 5+：假动作 → 组合技术 → 变化球路 原则： 先学后场技术，再学前场技术 先学高远球（基础），再学其他 每个技术掌握后再学下一个
