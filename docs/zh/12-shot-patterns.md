# 球路训练——战术型实战指南

> **写给谁**：技术已经够用，但打比赛时球路单调、容易被看穿、不知道怎么组织进攻的人
> **核心理念**：球路不是"你会打什么球"，是"你能让对手打什么球"

---

## 第一章：球路不是技术，是"让对手难受"的方法

### 1.1 技术思维 vs 战术思维

| 技术思维 | 战术思维 |
|:---------|:---------|
| "我会打高远球和吊球" | "我用高远球逼他后退，等他重心在后脚时吊他网前" |
| "他反手弱，我打他反手" | "我连续打他两个反手，等他站位偏反手时，突然打正手" |
| "我要杀球得分" | "我先让他起球质量变差，再杀" |

**技术解决"怎么打"，战术解决"打哪、什么时候打、让对手怎么跑"。**

### 1.2 球路设计的三个层次

```
第一层：这一拍打哪？
  看对手当前站在哪 → 打远离他的方向

第二层：这一拍打了之后，下一拍对手会打哪？
  根据你这一拍的质量和对手的习惯 → 预判他的回球方向

第三层：连续几拍后，对手会怎么跑？
  用球路引导对手的移动 → 让他按照你的预期跑 → 打他跑的反方向

三个层次逐级进阶。
大多数人只停留在第一层。
```

## 第二章：远网抓推——从后场控制比赛

### 2.1 什么是"远网抓推"

```
"远网"不是指球离网远，是指——
你站在后场，对手也站在后场。

这时候双方都在底线，谁先出质量差的球谁被动。
远网抓推的核心是：在这个阶段，用推球控制对手的移动。
```

**不是打高远球对拉，是主动用推球改变节奏：**

```
高远球：弧度高、速度慢、给了对手时间准备
推球：弧度平、速度快、压缩对手的反应时间

远网抓推的策略：
从后场打平高球或推球，不让对手有充分的时间准备进攻，
同时观察他的移动习惯。
```

### 2.2 什么时候推、什么时候拉

| 情况 | 应该打 | 为什么 |
|:-----|:-------|:-------|
| 对手在后场，重心偏后 | 推网前（让他向前跑） | 重心在后时往前跑最难受 |
| 对手在后场，重心偏前 | 推后场（让他后退） | 重心在前时后退最慢 |
| 对手在后场，重心居中 | 推重复落点（让他连续转身） | 连续同一方向最考验步法 |
| 对手刚打完一个球还在回位 | 推他回位的反方向 | 人在移动中变向最难 |

### 2.3 远网抓推的训练

```
训练1：推压练习
规则：双方都在后场，只允许打平高球和推球（不允许打高远球）
目的：强迫自己用速度和弧度控制对手
要求：连续10拍不出界、不到位算过关

训练2：推-吊组合
规则：1拍推后场→1拍吊网前
目的：让对手无法判断你是推还是吊（准备动作要一致）
标准：对手猜错方向算你成功

训练3：远网转近网
规则：从后场推球→上网封网
目的：把远网的控制转化为近网的进攻
标准：推完球后能在对手回球前到达网前
```

## 第三章：诱饵球路——让对手走进你的陷阱

### 3.1 什么是"诱饵球"

```
诱饵球：故意给对手一个"看起来很好打"的球，
让他打出你预期中的回球，
然后你提前等在回球路线上反击。

诱饵球的本质：你控制对手的决策。
```

**诱饵球和普通球的区别：**

```
普通球：你打了，希望对手回不好
诱饵球：你打了，你知道对手会回什么方向，你已经等在那里了
```

### 3.2 三种常见诱饵球路

**诱饵1：放网诱挑球**

```
你放网 → 对手挑球 → 你杀球

这是最基础的诱饵球路。
你放网不是为了得分，是为了让对手挑球。
对手挑球之后，你就有机会杀球。

关键：放网的质量不需要太好（不贴网也行），
但放完网之后你必须立即准备后退。

如果对手不挑球（放网或勾对角）→ 你的诱饵失败了，
说明对手网前比你好，不要继续用这个诱饵。
```

**诱饵2：半场球诱杀球**

```
你故意打一个不到位的中场球 →
对手杀球 →
你提前偏一侧防守 →
挡住杀球后打到他的空档

这个诱饵用于对付"一有机会就杀球"的进攻型选手。
你给他一个"看起来能杀"的球，让他杀。
你提前站好防守位置，挡住他的杀球后反击。

关键：你的防守能力要能接住这一拍杀球。
如果接不住 → 这个诱饵不能用。
```

**诱饵3：重复球路诱变线**

```
你连续打3次同一个方向（如连续3拍正手底线）→
对手以为你还会打正手，站位偏正手 →
第4拍突然打反手

这个诱饵用于对付"开始习惯你的球路"的对手。
前3拍是真的打那个方向（不是假动作），
让对手建立"他喜欢打正手"的印象，
第4拍再变。

关键：前3拍的质量不能差。如果前3拍不到位，
对手不需要适应你的球路，因为你本来就打不死他。
```

### 3.3 诱饵球训练

```
训练：3+1训练
规则：
1. 前3拍打同一个方向（固定）
2. 第4拍必须变方向

目的：练习"先建立对手的预期，再打破预期"
标准：前3拍的落点偏差<1米，第4拍的变向让对手来不及反应

注意：训练中前3拍也要认真打，不要"因为要变了所以前3拍随便打"。
前3拍质量不好 → 对手不会形成习惯 → 第4拍的变向没有意义。
```

## 第四章：推挑结合——控制对手的纵向移动

### 4.1 推和挑的战术区别

```
推：速度快、弧度平、给了对手回球角度但压缩了他的反应时间
挑：弧度高、速度慢、给了自己回位时间

战术上：
推 → 压迫对手的反应速度
挑 → 压迫对手的跑动距离
```

### 4.2 推挑结合的四种模式

**模式1：先推后挑（变节奏）**

```
连续推2-3拍（快节奏）→ 突然挑一拍高弧度（慢节奏）

对手刚适应了快节奏，
你突然变慢，他有两种反应：
1. 也变慢 → 你可以再突然加速
2. 继续快 → 他提前出手，容易失误

什么时候用：对手很适应你的节奏时。
```

**模式2：先挑后推（加速）**

```
挑一拍高弧度（对手退到后场）→
他回球后立即推一拍平弧（压缩他的反应时间）

对手刚从后场跑回来，还没站稳，
你一拍平推球已经到他的位置了。

什么时候用：对手回位慢时。
```

**模式3：推直线+挑斜线（调动跑动）**

```
正手推直线到对手正手底线 →
他回正手直线 →
你挑斜线到对手反手底线

对手需要从正手底线跑到反手底线（全场最远距离）。
连续2次这个组合 → 对手体力消耗很大。

什么时候用：对手体能不好或横向移动慢。
```

**模式4：推追身+挑空档**

```
推球打向对手的右肩（追身球，他很难发力回球）→
他被动挡网或挑球 →
你根据他的回球方向，挑到空档侧

什么时候用：你想迫使对手失误时。
```

### 4.3 推挑训练

```
训练1：节奏变化
规则：2拍推→2拍挑→2拍推→2拍挑（交替）
目的：练习在不同节奏间切换
标准：切换时主动控制节奏，不是被对手带着走

训练2：推挑路线固定
规则：推直线→挑斜线→推直线→挑斜线
目的：练习用推挑控制对手的跑动方向
标准：每次推和挑的落点偏差<1米

训练3：自由推挑
规则：根据对手位置自由选择推或挑
目的：在实战中应用
标准：10拍中至少有5次主动的节奏变化
```

## 第五章：防守反击球路——不是"等着对手失误"，是"主动制造反击机会"

### 5.1 防守不是被动

```
业余球友最常见的错误：防守就是"把球打回去"。
然后等对手失误。

正确的防守：防守是你为反击创造条件的过程。
```

**防守和防守反击的区别：**

```
防守：把球打回去 → 等对手下一拍 → 再打回去
防守反击：用防守球路迫使对手打某个方向 → 提前预判 → 在对手发力最弱时反击
```

### 5.2 三种防守反击模式

**模式1：挡网后反击**

```
对手杀球 → 你挡网（挡到网前）→
对手上网挑球或放网 →
你已经从防守位置上前了 → 在网前反击

关键：挡网的质量决定反击的机会。
挡网贴网 → 对手只能挑球 → 你可以在网前等他的挑球
挡网不到位 → 对手可以放网或推球 → 你的反击机会减少
```

**训练：**
```
同伴连续杀球 → 你挡网 → 挡完后立即上前一步 →
同伴上网挑球/放网 → 你根据回球选择扑球或放网
标准：10球中5球能完成从防守到反击的转换
```

**模式2：抽斜线后反击**

```
对手杀直线 → 你反抽斜线 →
对手从正手位跑到反手位接球（被动）→
你的下一个球打他跑的反方向

关键：抽斜线的质量要够快够平，不给对手调整的时间。
```

**模式3：顶后场后反击**

```
对手连续进攻 →
你连续顶后场（挑到底线）→
第3拍对手进攻质量下降（体能或注意力下降）→
你在这一拍反击

什么时候用：对手体能下降时。
关键：前三拍必须顶到位，质量不够的话对手一拍就杀死了。
```

### 5.3 防守反击训练

```
训练1：3防1反
规则：前3拍全部防守（挡网/挑球/抽球），第4拍必须反击
目的：练习在防守中找反击机会
标准：第4拍的反击能让自己从被动转为主动或得分

训练2：防守落点控制
规则：对手连续进攻，你把球防到指定的3个位置
      位置1：直线网前
      位置2：斜线中场
      位置3：直线底线
目的：练习控制防守球路的落点，而不是"只要打回去就行"
标准：连续5拍防守打到指定位置
```

## 第六章：重心调动——让对手的脚和身体打架

### 6.1 重心和位置是两回事

```
位置：对手站在哪里（物理位置）
重心：对手的体重偏向哪个方向（运动状态）

打位置空档 → 对手需要跑过去
打重心反方向 → 对手需要改变运动方向

打重心反方向比打位置空档更有效，
因为改变方向比直线跑难10倍。
```

### 6.2 如何判断对手的重心方向

```
对手刚打完一拍球——
看他的脚：
  右脚在前 → 重心偏前（打后场）
  左脚在前 → 重心偏后（打网前）
  双脚平行 → 重心居中（可打任何方向）

看他的移动趋势：
  正在向前跑 → 重心偏前 → 打后场
  正在向后跑 → 重心偏后 → 打网前
  正在向左移动 → 重心偏左 → 打右边
  正在向右移动 → 重心偏右 → 打左边

看他的击球后姿态：
  打完球身体前倾 → 重心在前 → 打后场
  打完球身体后仰 → 重心在后 → 打网前
  打完球身体偏左 → 重心在左 → 打右边
  打完球身体偏右 → 重心在右 → 打左边
```

### 6.3 重心调动的球路设计

```
原则：让对手的脚跟不上他的重心。

具体做法：

1. 前后调动（最常见也最有效）
   打一个后场球 → 对手后退 → 重心在后 →
   立即打网前 → 对手重心在后但需要向前跑 →
   他需要用额外的力量改变重心方向

   ⚠️ 关键：后场球的质量必须深必须到位。
   后场球不到位 → 对手不需要全力后退 →
   他的重心没有偏后 → 你的网前球打不动他。

2. 左右调动
   连续2拍打同一个方向 →
   对手重心已经偏到这个方向 →
   第3拍打另一个方向 →
   对手需要反方向启动

   ⚠️ 关键：前2拍必须是同一个方向，不能换。
   第1拍正手、第2拍反手 → 对手重心没偏 → 第3拍起不了作用。

3. 前后+左右复合调动（高级）
   后场正手 → 网前反手 → 后场反手 → 网前正手
   对手需要：后退→向前→斜向跑→向前→斜向跑

   这个组合跑完4拍，对手的体能消耗相当于连续跑了半个球场。
```

### 6.4 重心调动训练

```
训练1：两点调动（前后）
规则：你只能打后场和网前两个位置，交替打
标准：对手每拍都要跑3步以上

训练2：三点调动（前后+左右）
规则：你打后场→网前→反手后场，循环
标准：对手每拍都需要改变方向

训练3：自由调动
规则：根据对手的移动趋势，打他的重心反方向
标准：对手每2拍中至少有1拍出现"起步错误"（第一步迈错方向）
```

## 第八章：球路组合库——可以直接用的实战模式

以下球路组合按"目的"分类。每个组合包含：**球路序列 → 你在哪 → 你在等什么 → 关键要点**。

### 8.1 后场进攻类（8个组合）

#### 组合1：放远网→抓推→杀直线

```
第1拍：放一个远的网前球（落在前发球线附近）
第2拍：对手挑球
       你在后场等他的挑球 → 侧身杀直线
你在哪：放完后留在中场，不上网
你在等什么：等对手挑球
关键：放远网的目的不是得分，是让对手挑球。放太贴网对手放网你反而被动。
```

#### 组合2：网前放网→后退杀球

```
第1拍：放网（贴网）
第2拍：对手挑球 → 你从网前立即后退 → 侧身杀直线或斜线
你在哪：放完立即后退
你在等什么：等对手挑球
关键：放完网重心向前，借前冲力快速后退。
```

#### 组合3：平高球压反手→吊正手网前

```
第1拍：平高球压对手反手底线
第2拍：对手回球 → 你吊正手网前（他重心在反手侧）
你在哪：后场保持进攻位
你在等什么：等对手重心偏反手
关键：第1拍必须压到位，不到位对手不需要全力后退。
```

#### 组合14：杀斜线→上网推直线

```
第1拍：杀斜线（对手反手侧）
第2拍：对手挡斜线网前 → 你上网推直线到正手底线
你在哪：杀完立即上网
你在等什么：等对手挡斜线
关键：杀斜线后对手大概率挡斜线，你推直线是他跑的反方向。
```

#### 组合15：吊直线→上网勾对角

```
第1拍：吊直线网前
第2拍：对手放直线网前 → 你上网勾对角
你在哪：吊完立即上网
你在等什么：等对手放网
关键：吊完球重心向前冲，做出去直线的假象。
```

#### 组合16：连续平高球压同一点→突击杀球

```
第1-2拍：连续平高球压对手正手底线（同一位置）
第3拍：对手站位偏正手 → 突击杀直线或反手位
你在哪：后场保持进攻位
你在等什么：等对手站位偏一侧
关键：前2拍平高球速度要够快，让他没时间调整站位。
```

#### 组合17：高远球拉底线→平高球加速

```
第1拍：高远球（慢节奏）
第2拍：对手回高远球
第3拍：突然平高球加速（同一方向，弧度变平速度变快）
你在哪：后场，前2拍拉节奏，第3拍变速
你在等什么：等对手进入慢节奏模式后突然加速
关键：前2拍节奏要完全一致，让对手习惯慢节奏。
```

#### 组合18：低手位被动→抽斜线→上网

```
第1拍：你在后场低手位，抽斜线到对手反手底线
第2拍：对手跑过去过渡 → 你回中上网封网
你在哪：被动→回中→上网
你在等什么：等对手过渡球质量一般
关键：被动时不要强攻，先化解再找机会。
```

### 8.2 网前控制类（8个组合）

#### 组合4：反手放网→提前侧身抓挑球

```
第1拍：反手放网（贴网）
第2拍：对手挑球 → 你提前侧身等 → 正手杀或吊
你在哪：放完不后退，侧身等
你在等什么：等对手挑球
关键：放完网身体不要正对网，提前转成侧身，对手挑球你直接杀。
```

#### 组合5：搓球→后退抓推

```
第1拍：搓球（让球旋转）
第2拍：对手只能挑球 → 你后退一步推球压反手底线
你在哪：搓完退一步到中场
你在等什么：等对手挑球
关键：搓球旋转移够→对手不敢放网→你100%知道他要挑。
```

#### 组合6：推腰→上网封网

```
第1拍：推球打到对手腰部位置
第2拍：对手挡网或挑球 → 你上前封网
你在哪：推完立即上前一步
你在等什么：等对手挡网
关键：推腰不是推高，是推平。推太高对手有时间准备。
```

#### 组合19：重复放网→逼对手挑球→杀球

```
第1拍：放网 → 对手放网 → 你再放网（同一位置）
第2拍：对手被迫挑球 → 你后退杀球
你在哪：网前对放→后退杀
你在等什么：等对手先沉不住气挑球
关键：比的是放网稳定性和耐心，不是技术。
```

#### 组合20：连续推压

```
第1拍：推球到对手正手底线
第2拍：对手挡网 → 你上网再推一次反手底线
第3拍：对手连续跑动后质量下降 → 你杀球
你在哪：中场推完上网→再退后场杀
你在等什么：等对手连续跑动后回球变差
关键：每拍推球必须推到底线，不到位就无效。
```

#### 组合21：挑球→接杀挡网→上网

```
第1拍：挑球到对手底线
第2拍：对手杀球 → 你挡网
第3拍：对手上网挑球 → 你跟进推或扑
你在哪：防守→挡完立即上网
你在等什么：等对手杀完球上网挑
关键：挡网贴网，不给对手放网的机会。
```

#### 组合22：勾对角→对手放网→推后场

```
第1拍：勾对角（正手网前勾到反手网前）
第2拍：对手放直线网前 → 你推直线后场
你在哪：勾完立即调整位置准备推
你在等什么：等对手放直线
关键：勾对角后立即准备向直线方向移动。
```

#### 组合23：假放真推

```
第1拍：你做放网动作 → 对手重心向前 →
       你触球瞬间改为推球推后场
你在哪：网前
你在等什么：等对手重心向前移动的瞬间
关键：放网和推球的准备动作必须完全一致，最后一刻才改变拍面。
```

### 8.3 调动跑动类（8个组合）

#### 组合7：重复落点压正手→变反手底线

```
第1拍：正手底线 → 第2拍：同一个位置 →
第3拍：突然变反手底线
你在哪：后场保持进攻位
你在等什么：等对手站位偏向正手侧
关键：前2拍必须打同一个位置偏差<1米。
```

#### 组合8：前后大调动

```
第1拍：放网前 → 第2拍：挑后场 → 第3拍：再放网前
你在哪：前后不停地跑
你在等什么：等对手体能下降或回球变差
关键：前提是你的体能比对手好。
```

#### 组合9：杀直线→上网勾对角

```
第1拍：杀直线 → 第2拍：对手挡直线网前
       你上网勾对角
你在哪：杀完立即上网
你在等什么：等对手挡直线
关键：杀完必须立即上网，杀完站在原地勾对角后你回不来。
```

#### 组合24：三点调动

```
第1拍：正手后场 → 第2拍：反手网前 → 第3拍：正手网前
你在哪：你不需要跑，你的球让对手跑
你在等什么：等对手第3拍来不及到位
关键：连续3拍不同方向，中间不给喘息，让他每一拍都全力跑。
```

#### 组合25：连续重复落点（3次以上）

```
第1-3拍：反手底线 → 第4拍：还是反手底线
你在哪：后场重复打同一个目标
你在等什么：等对手耐心和注意力崩溃
关键：连续3次后对手开始怀疑"又打这里？"，第4次他心态崩。
```

#### 组合26：杀球结合软杀（轻重交替）

```
第1拍：重杀 → 第2拍：对手全力防守 →
       你软杀（60%力）→ 第3拍：对手节奏乱了
你在哪：后场交替使用重杀和软杀
你在等什么：等对手适应杀球节奏后突然变速
关键：重杀和软杀的准备动作必须完全一致。
```

#### 组合27：长短结合

```
第1拍：放网前（短）→ 第2拍：打半场（中）→ 第3拍：打后场（长）
你在哪：控制三个深度
你在等什么：等对手在半场位置处理不好
关键：短→中→长的节奏，让对手每一次都差一步。
```

#### 组合28：连续斜线→突然直线

```
第1拍：斜线高远球 → 第2拍：斜线吊球 →
第3拍：对手站位偏斜线 → 你突然直线杀球
你在哪：后场到中场控制位
你在等什么：等对手习惯性偏向斜线侧
关键：前2拍必须是正手侧的斜线（最大调动距离）。
```

### 8.4 防守反击类（7个组合）

#### 组合10：接杀挡网→跟进扑球

```
第1拍：对手杀球 → 你挡直线网前
第2拍：对手上网挑球 → 你跟进攻扑球
你在哪：防守→挡完立即上前
你在等什么：等对手挑球
关键：挡网要贴网，不给对手放网机会。
```

#### 组合11：接杀抽斜线→回中→变线

```
第1拍：对手杀直线 → 你抽斜线到反手底线
第2拍：对手跑过去回球质量下降 → 你打他跑的反方向
你在哪：防守→回中
你在等什么：等对手跑动后回球变差
```

#### 组合29：连续顶后场→突然放网

```
第1-2拍：对手连续进攻，你连续顶后场
第3拍：对手以为你还会顶 → 你突然放网
你在哪：防守位突然变节奏
你在等什么：等对手习惯了你的防守模式
关键：前2拍顶后场必须到位，否则对手不需要全力后退。
```

#### 组合30：连续两次放网

```
第1拍：对手杀球 → 你放网
第2拍：对手放网 → 你再放网（更贴网）
第3拍：对手被迫挑球
你在哪：防守→网前
你在等什么：等你的放网质量超过对手
关键：第2拍放网质量必须比第1拍好。
```

#### 组合31：预判对手杀斜线→挡直线

```
第1拍：挑球到反手底线
第2拍：对手大概率杀斜线 → 你提前偏斜线防守 → 挡直线
你在哪：提前移动偏斜线侧
你在等什么：等对手杀斜线（基于前几分的习惯观察）
关键：不是猜，是基于观察的判断。前几分先看他反手位杀哪个方向。
```

#### 组合32：接发推压→连续平抽→变线

```
第1拍：接发球推压 → 第2-3拍：连续平抽 →
第4拍：对手平抽质量下降 → 你突然变线
你在哪：中场平抽位
你在等什么：等对手平抽变慢或变高
关键：接发推压的质量决定你能不能主导平抽。
```

#### 组合33：被动挑球→接杀抽球→上网

```
第1拍：被动挑球 → 第2拍：对手杀球 →
       你接杀抽斜线 → 第3拍：上网控制
你在哪：被动→突然反击→上网
你在等什么：等对手以为你还会继续防守
关键：越被动越要想"我怎么反击"，不要只想着"打回去"。
```

### 8.5 双打专项（8个组合）

#### 组合12：发网前→第三拍推后场

```
第1拍：发网前到对手反手位
第2拍：对手放网或挑球 → 你或搭档推后场
你在哪：发完球在网前准备封网
你在等什么：等对手放网→封网；等对手挑球→退后进攻
关键：发完球不要后退，准备封网。
```

#### 组合13：平抽压中路→变线推边线

```
第1-3拍：连续平抽打两人中间
第4拍：对手站位往中间收 → 推边线
你在哪：中场平抽
你在等什么：等对手站位偏中
关键：前几拍平抽质量决定后几拍变化。
```

#### 组合34：发后场→挡网→搭档封网

```
第1拍：偷后场
第2拍：对手杀球 → 你挡网
第3拍：搭档在网前封网扑球
你在哪：发完后退防守→挡网
你在等什么：等对手杀球
关键：偷后场后你和搭档角色明确——你防守、搭档封网。
```

#### 组合35：接发推腰→封网

```
第1拍：接发推腰（推到两人中间）
第2拍：对手处理不好 → 你和搭档同时上前封网
你在哪：接发完立即上前
你在等什么：等对手处理不好腰部球
关键：推腰推平推快，推到两人中间偏一人位置。
```

#### 组合36：平抽变吊球

```
第1-2拍：和对手对抽
第3拍：平抽动作做到一半突然减力变吊球
你在哪：中场平抽位
你在等什么：等对手进入"平抽模式"
关键：平抽和吊球的准备动作必须完全一致。
```

#### 组合37：杀球结合软杀（双打版）

```
第1拍：重杀 → 第2拍：对手挡网 →
       你软杀（50%力）→ 搭档网前扑球
你在哪：后场进攻位
你在等什么：等对手防守重心过低
关键：重杀后对手习惯一个球速→软杀突然变慢→他节奏全乱。
```

#### 组合38：轮转进攻

```
第1拍：你在后场杀，搭档在网前
第2拍：对手挡网贴网 → 你上网接，搭档退后场
第3拍：你放网或推球，搭档在后场准备进攻
你在哪：你从后场到网前，搭档从网前到后场
你在等什么：轮转过程中对手打中路时最脆弱
关键：你上网的同时搭档后退，喊"换"让搭档知道。
```

#### 组合39：接杀顶后场→轮转防守

```
第1-2拍：对手连续杀球，你连续顶后场
第3拍：你和搭档轮转防守位置（直线换斜线）
你在哪：防守位轮转
你在等什么：等对手连续进攻后体能下降
关键：连续防守时和搭档轮转，打乱对手的进攻习惯。
```

## 第九章：从"会打"到"会设计球路"

### 9.1 打完一局后应该能回答的问题

```
这一局我用了哪些球路？
  远网抓推：___次（有效___次）
  诱饵球：___次（成功___次）
  推挑结合：___次
  防守反击：___次
  重心调动：___次
  球路组合：用了哪几个？________

哪些球路效果好？
  效果好的球路：__________ 下次继续用
  效果不好的球路：__________ 下次调整或不用

对手适应了我的哪些球路？
  他适应了的球路：__________ 下次需要加变化
  他没适应的球路：__________ 继续保持

这一局我学到的最重要的一件事：
______________________________
```

### 9.2 每一局都有一个"球路主题"

```
不要每一局都"看情况打"。
每一局开始前，给自己定一个球路主题。

第1局主题："我主要用重心调动，前后拉他"
第2局主题："我发现他反手弱，70%的球打他反手"
第3局主题："他体能下降了，我用防守反击等他失误"

一个主题用到底。不要因为丢了2分就换主题。
除非你有明确的证据证明这个主题无效（比如你调动他但他跑得比你预想快很多），
否则坚持最少打完一局。
```

### 9.3 球路成长路径

```
从一个"只会打直线"的选手到"会设计球路"的选手，需要经过几个阶段：

L1：只会打一个球路
  特征：只会高远球，或者只会杀球
  问题：对手很快就能适应
  突破：选择一个新球路，练到比赛中能用

L2：会打多个球路，但不会组合
  特征：高远球、吊球、杀球都会，但一场比赛里切换生硬
  问题：球路之间没有衔接
  突破：选一个组合（如高远+吊球），在比赛中刻意使用

L3：会组合2-3个球路
  特征：能在比赛中用固定的组合打出效果
  问题：组合固定，容易被对手预判
  突破：增加组合的变化（同一个场景至少3种选择）

L4：会设计球路
  特征：能根据对手的特点和比赛局势灵活设计球路
  问题：偶尔判断失误
  突破：建立对手数据库（打过的每一个对手都有记录）

L5：自动化的球路设计
  特征：不需要刻意想，球路自然根据对手变化
```

**你现在在哪个阶段？**

```
自检：回想最近打的一场比赛——

你的球路让对手难受了吗？
  □ 是的，他经常猜错方向 → L3+
  □ 没有，他基本能预判我的球路 → L2以下

你知道对手的弱点吗？
  □ 知道，我专门打他的弱点 → L3+
  □ 不知道，我只是把球打过去 → L2以下

你打完比赛能说出"这一局我学到了什么"吗？
  □ 能 → L4
  □ 不能 → 从记录开始
```
