体能训练

力量训练动作指导

正确动作 · 避免受伤 · 循序渐进

力量训练原则：动作质量 > 重量。先掌握正确动作，再逐渐增加负荷。每个动作都要从最简单的版本开始。

🏋️ 下肢训练

🦵
深蹲（Squat）
下肢力量基础动作
股四头肌 臀大肌 腘绳肌 核心
动作分解
  1. 双脚与肩同宽，脚尖略微外展（15-30度）
  2. 挺胸收腹，目视前方
  3. 臀部向后坐，膝盖弯曲
  4. 下蹲至大腿与地面平行或更低
  5. 脚跟用力蹬地，站起还原
常见错误
膝盖内扣：臀中肌无力，需要加强臀中肌训练
弓背：核心力量不足，需要加强核心训练
脚跟离地：踝关节灵活性不足，需要拉伸小腿
进阶路径
初级
徒手深蹲
中级
高脚杯深蹲
高级
杠铃深蹲
🦵
弓步蹲（Lunge）
单侧下肢力量训练
股四头肌 臀大肌 臀中肌 核心
动作分解
  1. 站立，双脚与髋同宽
  2. 一脚向前迈出一大步
  3. 下蹲至前腿大腿与地面平行
  4. 后腿膝盖接近地面但不触地
  5. 前脚蹬地，回到起始位置
常见错误
步幅太小：膝盖超过脚尖过多，增加膝关节压力
躯干前倾：核心没有收紧，身体不稳定
膝盖内扣：臀中肌无力，需要加强臀中肌训练
🦵
罗马尼亚硬拉（Romanian Deadlift）
后链肌群训练
腘绳肌 臀大肌 竖脊肌 核心
动作分解
  1. 双脚与髋同宽，膝盖微曲
  2. 双手持哑铃或杠铃
  3. 臀部向后推，上身前倾
  4. 杠铃/哑铃沿腿部下降
  5. 感受腘绳肌拉伸，然后臀部发力站起
常见错误
弓背：核心没有收紧，腰部压力过大
膝盖弯曲过多：变成了深蹲，没有练到目标肌群
杠铃离身体太远：增加腰部负担

💪 上肢训练

💪
俯卧撑（Push-up）
上肢推力基础动作
胸大肌 三角肌前束 肱三头肌 核心
动作分解
  1. 双手撑地，与肩同宽或略宽
  2. 身体成一条直线，收紧核心
  3. 屈肘下降，胸部接近地面
  4. 推起至手臂伸直
  5. 保持身体稳定，不要塌腰或弓背
进阶路径
初级
跪姿俯卧撑
中级
标准俯卧撑
高级
击掌俯卧撑
💪
引体向上（Pull-up）
上肢拉力基础动作
背阔肌 肱二头肌 菱形肌 核心
动作分解
  1. 双手正握单杠，与肩同宽
  2. 身体悬垂，肩胛骨下沉
  3. 背部发力，将身体拉起
  4. 下巴超过单杠
  5. 控制下放，回到起始位置
进阶路径
初级
弹力带辅助
中级
标准引体
高级
负重引体

🎯 核心训练

🎯
平板支撑（Plank）
核心稳定性基础动作
腹直肌 腹横肌 竖脊肌 臀肌
动作分解
  1. 前臂撑地，手肘在肩膀正下方
  2. 身体成一条直线，收紧核心
  3. 不要塌腰或弓背
  4. 保持呼吸，不要憋气
  5. 保持姿势直到力竭
常见错误
塌腰：核心没有收紧，腰部压力过大
弓背：臀部太高，没有练到目标肌群
憋气：应该保持正常呼吸
🎯
死虫式（Dead Bug）
核心稳定性进阶动作
腹横肌 腹直肌 髂腰肌
动作分解
  1. 仰卧，手脚举起朝天
  2. 下背部紧贴地面
  3. 呼气时对侧手脚伸直
  4. 吸气时还原
  5. 保持下背部始终贴地
