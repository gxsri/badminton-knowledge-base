💪 专业训练

训练1：专项体能
组数：4组 时间：45分钟/组 频率：每周4次
  1. 力量训练：深蹲、卧推、硬拉
  2. 速度训练：反应速度、移动速度
  3. 耐力训练：间歇跑、多球训练
  4. 柔韧训练：动态拉伸、PNF拉伸

关键：训练量和强度要达到专业水平。

训练2：技术精化
组数：3组 时间：60分钟/组 频率：每周5次
  1. 多球训练：强化技术稳定性
  2. 对抗训练：提高实战能力
  3. 专项训练：针对弱项强化
  4. 比赛模拟：适应比赛节奏
训练3：心理训练
组数：2组 时间：20分钟/组 频率：每天
  1. 注意力训练：单点凝视、多目标追踪
  2. 压力适应：L4-L5级别训练
  3. 决策训练：快速决策、模式识别
  4. 自我对话：认知重构、关键词
