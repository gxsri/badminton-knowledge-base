Level 0

零基础启蒙

0-3个月 · 建立正确的神经肌肉控制模式
学习进度
0/10 完成

🎯 目标

在3个月内，建立正确的神经肌肉控制模式，培养本体感觉和基础运动能力。

核心理念：质量 > 数量，控制 > 力量。这个阶段不追求"练多少"，而是"练对没有"。

🏋️ 训练内容

训练1：单足站立（本体感觉）
组数：3组 时间：每组30秒 频率：每天
  1. 赤足站立，双手叉腰
  2. 抬起一只脚，保持平衡
  3. 睁眼开始，逐步过渡到闭眼
  4. 进阶：在软垫上做

检查点：身体是否晃动？支撑脚是否稳定？

训练2：死虫式（核心稳定性）
组数：3组 次数：每侧10次 频率：隔天
  1. 仰卧，手脚举起朝天
  2. 呼气时对侧手脚伸直
  3. 吸气时还原
  4. 保持下背部贴地

检查点：下背部是否离开地面？动作是否流畅？

训练3：臀桥（臀部激活）
组数：3组 次数：15次 频率：隔天
  1. 仰卧，双脚踩地
  2. 臀部发力向上推
  3. 顶部停留1秒
  4. 缓慢下放

检查点：是否用臀部发力而非腰部？

训练4：弹力带外旋（肩袖激活）
组数：2组 次数：15次 频率：每次训练前
  1. 弹力带固定在门把手上
  2. 手肘弯曲90度，贴近身体
  3. 小臂向外旋转
  4. 控制速度，不要借力

检查点：手肘是否贴紧身体？是否有耸肩？

常见问题：
• Q: 训练后肌肉酸痛正常吗？
A: 轻微酸痛是正常的，但如果疼痛持续超过48小时，请减少训练量。
• Q: 可以每天训练吗？
A: 可以，但建议隔天进行力量训练，让肌肉有时间恢复。
