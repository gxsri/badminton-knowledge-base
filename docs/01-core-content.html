训练哲学 — 四个不变的原则

不管你是15岁还是50岁，零基础还是复训，以下四个原则不变：

这四个原则不是建议，是底线。任何训练安排必须同时满足四条才能执行。

原则为什么什么不能做
动作质量 > 训练数量神经肌肉系统记住的是你重复最多的模式，练错的动作重复100次=巩固100次错误不能用"做了多少次"衡量训练效果
神经肌肉控制 > 力量输出神经系统先学会控制肌肉，肌肉才能发力。顺序不能反不能在动作模式不稳定时加重量
预防损伤 > 追求表现一次受伤=倒退回起点，恢复时间往往是训练时间的3-10倍不能在疲劳状态下冲击极限
长期发展 > 短期进步神经系统适应需要4-6周，结缔组织初步适应约8-12周不能每周都加量

基线测试 — 不要猜，测

不要猜自己是什么水平，测。以下测试每月重测一次，每次15分钟。

测试项目测试方法基准线
单足站立（睁眼）赤足，双手叉腰，每侧3次取最好≥30秒
单足站立（闭眼）同上，闭眼。旁边放垫子保护≥10秒
死虫式耐久仰卧对侧手脚伸直，2秒出2秒回≥15次标准
平板支撑前臂撑地，身体成直线计时≥45秒

注意：训练年限不代表当前水平。练了两年但断断续续，基线测试可能和练三个月的差不多。以测试结果为准，不以你觉得自己"应该"什么水平为准。

起始训练量计算

第一步：测基准（用上面的测试） 第二步：定起始强度 = 基准的 60-70% 第三步：此量安全使用1-2周 第四步：进阶条件 = 连续2次训练顺利完成且动作不变形 第五步：进阶增量 = 每次增加 5-10% 举例 — 死虫式： 基线测试：15次动作变形 起始量：15 × 70% = 10次 进阶条件：连续2次训练做完10次且不变形 进阶后：10 × 110% = 11次

为什么是60-70%不是80-90%

这是基于运动学习的"最佳挑战点"理论：

  • 太容易（50%以下）→ 不产生适应
  • 最佳（60-75%）→ 最大学习效果
  • 太难（85%以上）→ 代偿动作出现，神经肌肉系统学习错误模式

对零基础学员，宁可低估，不可高估。低估的代价是一周后要加量；高估的代价是代偿动作需要4-6周来纠正。

四大训练模块

模块一：神经肌肉控制

足部本体感觉训练
闭眼单足 <3秒 → 初级 3-10秒 → 基础 10-30秒 → 进阶 >30秒 → 熟练

本体感觉训练的唯一变量是难度梯度，不是训练量。你不需要做100次单足站立，你需要找到你当前"刚好能完成但需要努力"的难度。

难度梯度的控制维度： 支撑面大小（双足→单足→单足+软垫） 视觉辅助（睁眼→闭眼→闭眼+头部转动） 上肢干扰（安静→手臂移动→接球） 时间（5秒→15秒→30秒→60秒） 次级进阶原则：每次只改变一个维度，稳定后（连续3次训练达标）再换下一个。

TDEE计算： 男性 BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄 + 5 女性 BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄 - 161 TDEE = BMR × 活动系数（久坐1.2 / 轻度1.375 / 中度1.55 / 高度1.725） 三大营养素： 蛋白质：维持1.2-1.6g/kg / 增肌1.6-2.0g/kg / 减脂2.0-2.4g/kg 脂肪：0.8-1.0g/kg（占热量20-25%） 碳水：休息日2-3g/kg / 训练日3-5g/kg / 高强度5-7g/kg
