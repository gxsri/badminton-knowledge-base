# Level 0：训练计划——自适应框架

> **写给谁**：学员和教练
> **目标**：不是给你28天的固定日程。是教你怎么安排每一周、每一天，根据你自己的恢复状态和进步速度
> **核心理念**：一个好的训练计划不是写在纸上的，是你根据身体反馈每天都在调整的

---

## 第一章：训练计划不是日程表

### 1.1 每周训练频率的决策公式

```
每周训练天数 = 你的恢复能力系数 × 3（基础频率）

恢复能力系数由两个因素决定：
1. 年龄系数：
   < 25岁 → 1.2（一周可以练3-4次）
   25-40岁 → 1.0（一周练3次）
   > 40岁 → 0.8（一周练2-3次）

2. 训练年限修正：
   < 3个月训练经验 → 年龄系数再 × 0.8
   3-12个月 → × 1.0
   > 1年 → × 1.1

综合公式：每周训练天数 = 3 × 年龄系数 × 年限修正

例1：22岁，练了2个月
  每周 = 3 × 1.2 × 0.8 = 2.88 → 2-3次/周

例2：30岁，练了2年
  每周 = 3 × 1.0 × 1.1 = 3.3 → 3次/周

例3：50岁，练了6个月
  每周 = 3 × 0.8 × 1.0 = 2.4 → 2次/周（中间加1次恢复训练）
```

### 1.2 什么决定了你今天练不练（不是"今天是周二，该练了"）

**每次训练前的三问：**

```
第一问：上次训练到现在，恢复了吗？
  ● 完全不酸痛，精力充沛 → 正常训练
  ● 轻微酸痛，但活动开了就消失了 → 可以练，减量20%
  ● 明显酸痛，不碰都疼 → 休息或恢复训练
  ● 某个部位有刺痛 → 休息，不练这个部位

第二问：今天的精力水平（1-10）？
  ● 7-10 → 正常训练
  ● 4-6 → 减量50%
  ● 1-3 → 休息

第三问：今天的训练对上一周的进步有帮助吗？
  ● 有帮助，能感觉到进步 → 继续
  ● 没什么感觉 → 考虑换训练方式
  ● 感觉退步了 → 检查是不是过度训练
```

**只有第一问和第二问都答"可以练"，才能练。**

## 第二章：一周训练的结构——不是随机安排

### 2.1 一周训练的原则（不是日程）

```
原则1：训练和训练之间至少隔24小时
原则2：两次力量训练之间至少隔48小时
原则3：高强度训练后安排低强度或恢复日
原则4：一周至少有一天完全不训练
```

### 2.2 三种训练日类型

| 类型 | 目的 | 内容安排 | 时长 |
|:-----|:-----|:---------|:----:|
| **A型（主训练日）** | 技术/力量进步 | 技术训练 + 主力量训练 | 45-60分钟 |
| **B型（辅助训练日）** | 补充强化 | 辅助力量训练 + 恢复训练 | 25-35分钟 |
| **R型（恢复训练日）** | 主动恢复 | 筋膜放松 + 拉伸 + 基础激活 | 15-20分钟 |

### 2.3 如何排列一周

每周训练天数是2还是3还是4，对应的排列方式不同：

**一周2次（适合 > 40岁或0-3个月新手）：**

```
例：周二 A型 / 周五 A型
周四 R型
```

**一周3次（适合大多数Level 0-1）：**

```
例：周一 A型 / 周三 B型 / 周五 A型
```

**一周4次（适合 < 25岁或恢复能力好）：**

```
例：周一 A型 / 周二 B型 / 周四 A型 / 周五 B型
周三和周末各休息一天
```

## 第三章：每次训练的结构——热身/主训练/整理

### 3.1 热身时间计算公式

```
热身时间(分钟) = 年龄 ÷ 10 + 2
整理时间(分钟) = 年龄 ÷ 15 + 5

例：
20岁：热身4分钟，整理6分钟
35岁：热身5.5分钟，整理7分钟
50岁：热身7分钟，整理8分钟
```

### 3.2 热身的内容（不是"跑两圈"）

| 阶段 | 时间占比 | 做什么 | 目的 |
|:-----|:--------:|:-------|:-----|
| 激活 | 30% | 弹力带激活肩袖 + 臀中肌激活 | 唤醒要用的关节 |
| 动态拉伸 | 30% | 手臂绕环、腿摆动、胸椎旋转 | 活动活动范围 |
| 心率准备 | 40% | 开合跳/高抬腿/原地小跑 | 提高心率和体温 |

### 3.3 主训练的内容分配

```
技术训练（40%总时间）：
- 第一组：慢速、找感觉（不用力）
- 第二组：正常速度
- 第三组：应用速度

力量训练（30%总时间）：
- 先练全身复合动作（深蹲/弓步等）
- 再练稳定训练（肩/膝）
- 最后练核心

恢复训练（30%总时间）：
- 筋膜放松（泡沫轴/筋膜球）— 50%
- 静态拉伸 — 30%
- 呼吸调整 — 20%
```

### 3.4 整理放松的内容

```
1. 筋膜放松（5-10分钟）
   顺序：足底→小腿后侧→大腿前侧→臀部→背部
   方法：每个部位找到酸痛点，保持30秒深呼吸

2. 静态拉伸（3-5分钟）
   今天练到的每个部位拉伸30秒

3. 呼吸调整（2-3分钟）
   4-7-8呼吸法：吸4秒、屏7秒、呼8秒，重复4次
```

## 第四章：训练内容的选择——不是固定菜单

### 4.1 选择今天练什么的原则

```
你今天练什么，由三个因素决定：

因素1：你上周的薄弱环节是什么？
  - 单足站立还是不到10秒？→ 今天本体感觉优先
  - 膝盖还是会内扣？→ 今天膝关节训练优先
  - 注意力容易分散？→ 加入注意力训练

因素2：你的恢复状态是什么？
  - 全身状态好 → 可以练A型完整训练
  - 某部位还有酸痛 → 跳过该部位训练
  - 精神状态差但身体好 → 做B型训练，不做A型

因素3：你上次练了什么？
  - 上次练了上肢 → 今天练下肢
  - 上次练了左腿 → 今天先练右腿（不对称要补）
  - 上次练了大重量 → 今天做技术训练
```

### 4.2 初学者（0-3个月）的模块轮转模板

不是"A周一B周三C周五"。是按模块轮转：

```
第一次训练：神经控制模块（本体感觉+核心稳定+步法基础）
第二次训练：结构性力量模块（肩关节+膝关节+基础力量耐力）
第三次训练：神经心理模块（注意力+决策）+ 动力链训练

休息一天后：
第四次训练：从神经控制模块开始，但强度/量要有提升
```

**每次训练的"量"怎么定：**

```
每个模块内选2-3个核心动作
每个动作的组数=01-核心内容中已计算的组数
每个动作的次数=按基线测的60-70%
组间休息 = 训练者年龄÷5 + 15秒
  （例：30岁 → 30÷5+15=21秒 → 约20-30秒）
```

### 4.3 进阶标准——不是"第几周了"，是"能不能了"

```
从"神经控制"模块进阶到"结构性力量"模块的标准：
不是练了2周了所以该换。

是：
☐ 单足站立闭眼 > 15秒（每侧）
☐ 死虫式能完成15次标准动作
☐ 平板支撑 > 45秒
☐ 分腿蹲动作标准（不晃动、膝盖不内扣）
全部达到 → 可以进入结构性力量为主的训练阶段
任一项未达到 → 保持神经控制训练为主
```

## 第五章：减量和休息——不是偷懒

### 5.1 什么时候需要减量

| 信号 | 怎么做 | 持续多久 |
|:-----|:-------|:---------|
| 连续3次训练动作质量都在下降 | 下次训练减量50% | 1次训练后恢复即可回正常 |
| 训练后48小时还酸痛 | 减量50%或换成恢复训练 | 直到恢复时间缩短到24-48小时 |
| 精力水平连续1周<5/10 | 停训2天+改善睡眠 | 恢复后重新开始 |
| 对训练产生抵触情绪 | 减量50%，如果还抵触就休息 | 3-7天 |
| 同一个部位连续3次训练都痛 | 停这个部位的训练 | 换替代动作，痛消失后再回来 |

### 5.2 减量周不是可选的

```
每4-6周安排一次减量周：
训练量：正常训练量的40-50%
训练频率：正常频率的60-70%
训练强度：用最轻的阻力/自重

减量周的目的不是"变弱"，是让身体吸收前面几周的训练成果。
不安排减量周 → 3-4个月后必然遇到平台期或过度训练。
```

### 5.3 恢复训练日（R型）的具体安排

```
时间：15-20分钟

1. 全身泡沫轴放松（8分钟）
   足底→小腿→大腿前/后/外→臀部→背部
   每个部位1分钟

2. 主要关节活动（5分钟）
   肩关节绕环：正反各10次
   髋关节绕环：正反各10次
   胸椎旋转：每侧8次
   踝关节活动：每侧10次

3. 呼吸调整（3分钟）
   4-7-8呼吸法 × 4次

4. 评估（2分钟）
   今天身体状态自评：
   恢复程度____/10
   明天想练什么？____
```

## 第六章：教练怎么用这个框架给学员安排训练

### 6.1 第一次见学员要问的四个问题

```
1. 你之前练过吗？具体练了多久？练了什么？
   → 确定训练年限修正系数

2. 你现在身上有没有伤？
   → 有伤 → 先处理伤，训练要绕开受伤部位
   → 无伤 → 进入下一问

3. 你一周能来几次？
   → 不是"你想练几次"，是"你能来几次"
   → 根据可用时间倒推训练频率

4. 你的目标是什么？
   → 减脂/增肌/提高技术/康复/比赛？
   → 不同目标在前几周的训练比例不同
```

### 6.2 第一个月教练的观察重点

| 周次 | 观察重点 | 需要做调整的信号 |
|:-----|:---------|:-----------------|
| 第1周 | 学员的动作学习速度、代偿模式、注意力持续 | 某个动作完全做不了 → 退到更基础的变式 |
| 第2周 | 训练后的恢复速度、对训练的反应 | 每次训练后都极度疲劳 → 减量 |
| 第3周 | 是否有进步？进步速度如何？ | 毫无进步 → 查训练量或训练方式 |
| 第4周 | 评估是否可以进入下一阶段 | 基线测试是否有明显提升？ |

### 6.3 给出训练量的原则（不是给数字，是给判断方法）

作为教练，你不应该告诉学员"做3组×15次"。

你应该告诉学员：
```
"你今天做深蹲。先做一组试一下，感受一下你今天的体力状态。
从10次开始，能做到第12次动作还行的话就做到12次。
全程膝盖对准第二脚趾。做完3组后告诉我感觉怎么样。"
```

**给判断方法，不给数字。学员学会了自己判断，就不需要每次都等你给指令了。**

4. 每周结束时，回顾"进步评估"，决定下周是否调整
5. 每4-6周安排一次减量周（训练量降至40-50%）

注意：
- 模板不是"让学员按表执行"，是"学员填表的过程就是学习判断的过程"
- 前两周教练可以帮填，第三周开始让学员自己填、教练检查
- 当学员能不看公式直接判断"今天该练什么"——说明他学会了
