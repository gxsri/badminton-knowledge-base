# Level 0：训练计划——自适应框架

> **写给谁**：学员和教练
> **目标**：不是给你28天的固定日程。是教你怎么安排每一周、每一天，根据你自己的恢复状态和进步速度
> **核心理念**：一个好的训练计划不是写在纸上的，是你根据身体反馈每天都在调整的

---

## 第一章：训练计划不是日程表

### 1.1 每周训练频率的决策公式

```
每周训练天数 = 你的恢复能力系数 × 3（基础频率）

恢复能力系数由两个因素决定：
1. 年龄系数：
   < 25岁 → 1.2（一周可以练3-4次）
   25-40岁 → 1.0（一周练3次）
   > 40岁 → 0.8（一周练2-3次）

2. 训练年限修正：
   < 3个月训练经验 → 年龄系数再 × 0.8
   3-12个月 → × 1.0
   > 1年 → × 1.1

综合公式：每周训练天数 = 3 × 年龄系数 × 年限修正

例1：22岁，练了2个月
  每周 = 3 × 1.2 × 0.8 = 2.88 → 2-3次/周

例2：30岁，练了2年
  每周 = 3 × 1.0 × 1.1 = 3.3 → 3次/周

例3：50岁，练了6个月
  每周 = 3 × 0.8 × 1.0 = 2.4 → 2次/周（中间加1次恢复训练）
```

### 1.2 什么决定了你今天练不练（不是"今天是周二，该练了"）

**每次训练前的三问：**

```
第一问：上次训练到现在，恢复了吗？
  ● 完全不酸痛，精力充沛 → 正常训练
  ● 轻微酸痛，但活动开了就消失了 → 可以练，减量20%
  ● 明显酸痛，不碰都疼 → 休息或恢复训练
  ● 某个部位有刺痛 → 休息，不练这个部位

第二问：今天的精力水平（1-10）？
  ● 7-10 → 正常训练
  ● 4-6 → 减量50%
  ● 1-3 → 休息

第三问：今天的训练对上一周的进步有帮助吗？
  ● 有帮助，能感觉到进步 → 继续
  ● 没什么感觉 → 考虑换训练方式
  ● 感觉退步了 → 检查是不是过度训练
```

**只有第一问和第二问都答"可以练"，才能练。**

## 第二章：一周训练的结构——不是随机安排

### 2.1 一周训练的原则（不是日程）

```
原则1：训练和训练之间至少隔24小时
原则2：两次力量训练之间至少隔48小时
原则3：高强度训练后安排低强度或恢复日
原则4：一周至少有一天完全不训练
```

### 2.2 三种训练日类型

| 类型 | 目的 | 内容安排 | 时长 |
|:-----|:-----|:---------|:----:|
| **A型（主训练日）** | 技术/力量进步 | 技术训练 + 主力量训练 | 45-60分钟 |
| **B型（辅助训练日）** | 补充强化 | 辅助力量训练 + 恢复训练 | 25-35分钟 |
| **R型（恢复训练日）** | 主动恢复 | 筋膜放松 + 拉伸 + 基础激活 | 15-20分钟 |

### 2.3 如何排列一周

每周训练天数是2还是3还是4，对应的排列方式不同：

**一周2次（适合 > 40岁或0-3个月新手）：**

```
例：周二 A型 / 周五 A型
周四 R型
```

**一周3次（适合大多数Level 0-1）：**

```
例：周一 A型 / 周三 B型 / 周五 A型
```

**一周4次（适合 < 25岁或恢复能力好）：**

```
例：周一 A型 / 周二 B型 / 周四 A型 / 周五 B型
周三和周末各休息一天
```

## 第三章：每次训练的结构——热身/主训练/整理

### 3.1 热身时间计算公式

```
热身时间(分钟) = 年龄 ÷ 10 + 2
整理时间(分钟) = 年龄 ÷ 15 + 5

例：
20岁：热身4分钟，整理6分钟
35岁：热身5.5分钟，整理7分钟
50岁：热身7分钟，整理8分钟
```

### 3.2 热身的内容（不是"跑两圈"）

| 阶段 | 时间占比 | 做什么 | 目的 |
|:-----|:--------:|:-------|:-----|
| 激活 | 30% | 弹力带激活肩袖 + 臀中肌激活 | 唤醒要用的关节 |
| 动态拉伸 | 30% | 手臂绕环、腿摆动、胸椎旋转 | 活动活动范围 |
| 心率准备 | 40% | 开合跳/高抬腿/原地小跑 | 提高心率和体温 |

### 3.3 主训练的内容分配

```
技术训练（40%总时间）：
- 第一组：慢速、找感觉（不用力）
- 第二组：正常速度
- 第三组：应用速度

力量训练（30%总时间）：
- 先练全身复合动作（深蹲/弓步等）
- 再练稳定训练（肩/膝）
- 最后练核心

恢复训练（30%总时间）：
- 筋膜放松（泡沫轴/筋膜球）— 50%
- 静态拉伸 — 30%
- 呼吸调整 — 20%
```

### 3.4 整理放松的内容

```
1. 筋膜放松（5-10分钟）
   顺序：足底→小腿后侧→大腿前侧→臀部→背部
   方法：每个部位找到酸痛点，保持30秒深呼吸

2. 静态拉伸（3-5分钟）
   今天练到的每个部位拉伸30秒

3. 呼吸调整（2-3分钟）
   4-7-8呼吸法：吸4秒、屏7秒、呼8秒，重复4次
```

## 第四章：训练内容的选择——不是固定菜单

### 4.1 选择今天练什么的原则

```
你今天练什么，由三个因素决定：

因素1：你上周的薄弱环节是什么？
  - 单足站立还是不到10秒？→ 今天本体感觉优先
  - 膝盖还是会内扣？→ 今天膝关节训练优先
  - 注意力容易分散？→ 加入注意力训练

因素2：你的恢复状态是什么？
  - 全身状态好 → 可以练A型完整训练
  - 某部位还有酸痛 → 跳过该部位训练
  - 精神状态差但身体好 → 做B型训练，不做A型

因素3：你上次练了什么？
  - 上次练了上肢 → 今天练下肢
  - 上次练了左腿 → 今天先练右腿（不对称要补）
  - 上次练了大重量 → 今天做技术训练
```

### 4.2 初学者（0-3个月）的模块轮转模板

不是"A周一B周三C周五"。是按模块轮转：

```
第一次训练：神经控制模块（本体感觉+核心稳定+步法基础）
第二次训练：结构性力量模块（肩关节+膝关节+基础力量耐力）
第三次训练：神经心理模块（注意力+决策）+ 动力链训练

休息一天后：
第四次训练：从神经控制模块开始，但强度/量要有提升
```

**每次训练的"量"怎么定：**

```
每个模块内选2-3个核心动作
每个动作的组数=01-核心内容中已计算的组数
每个动作的次数=按基线测的60-70%
组间休息 = 训练者年龄÷5 + 15秒
  （例：30岁 → 30÷5+15=21秒 → 约20-30秒）
```

### 4.3 进阶标准——不是"第几周了"，是"能不能了"

```
从"神经控制"模块进阶到"结构性力量"模块的标准：
不是练了2周了所以该换。

是：
☐ 单足站立闭眼 > 15秒（每侧）
☐ 死虫式能完成15次标准动作
☐ 平板支撑 > 45秒
☐ 分腿蹲动作标准（不晃动、膝盖不内扣）
全部达到 → 可以进入结构性力量为主的训练阶段
任一项未达到 → 保持神经控制训练为主
```

## 第五章：减量和休息——不是偷懒

### 5.1 什么时候需要减量

| 信号 | 怎么做 | 持续多久 |
|:-----|:-------|:---------|
| 连续3次训练动作质量都在下降 | 下次训练减量50% | 1次训练后恢复即可回正常 |
| 训练后48小时还酸痛 | 减量50%或换成恢复训练 | 直到恢复时间缩短到24-48小时 |
| 精力水平连续1周<5/10 | 停训2天+改善睡眠 | 恢复后重新开始 |
| 对训练产生抵触情绪 | 减量50%，如果还抵触就休息 | 3-7天 |
| 同一个部位连续3次训练都痛 | 停这个部位的训练 | 换替代动作，痛消失后再回来 |

### 5.2 减量周不是可选的

```
每4-6周安排一次减量周：
训练量：正常训练量的40-50%
训练频率：正常频率的60-70%
训练强度：用最轻的阻力/自重

减量周的目的不是"变弱"，是让身体吸收前面几周的训练成果。
不安排减量周 → 3-4个月后必然遇到平台期或过度训练。
```

### 5.3 恢复训练日（R型）的具体安排

```
时间：15-20分钟

1. 全身泡沫轴放松（8分钟）
   足底→小腿→大腿前/后/外→臀部→背部
   每个部位1分钟

2. 主要关节活动（5分钟）
   肩关节绕环：正反各10次
   髋关节绕环：正反各10次
   胸椎旋转：每侧8次
   踝关节活动：每侧10次

3. 呼吸调整（3分钟）
   4-7-8呼吸法 × 4次

4. 评估（2分钟）
   今天身体状态自评：
   恢复程度____/10
   明天想练什么？____
```

## 第六章：教练怎么用这个框架给学员安排训练

### 6.1 第一次见学员要问的四个问题

```
1. 你之前练过吗？具体练了多久？练了什么？
   → 确定训练年限修正系数

2. 你现在身上有没有伤？
   → 有伤 → 先处理伤，训练要绕开受伤部位
   → 无伤 → 进入下一问

3. 你一周能来几次？
   → 不是"你想练几次"，是"你能来几次"
   → 根据可用时间倒推训练频率

4. 你的目标是什么？
   → 减脂/增肌/提高技术/康复/比赛？
   → 不同目标在前几周的训练比例不同
```

### 6.2 第一个月教练的观察重点

| 周次 | 观察重点 | 需要做调整的信号 |
|:-----|:---------|:-----------------|
| 第1周 | 学员的动作学习速度、代偿模式、注意力持续 | 某个动作完全做不了 → 退到更基础的变式 |
| 第2周 | 训练后的恢复速度、对训练的反应 | 每次训练后都极度疲劳 → 减量 |
| 第3周 | 是否有进步？进步速度如何？ | 毫无进步 → 查训练量或训练方式 |
| 第4周 | 评估是否可以进入下一阶段 | 基线测试是否有明显提升？ |

### 6.3 给出训练量的原则（不是给数字，是给判断方法）

作为教练，你不应该告诉学员"做3组×15次"。

你应该告诉学员：
```
"你今天做深蹲。先做一组试一下，感受一下你今天的体力状态。
从10次开始，能做到第12次动作还行的话就做到12次。
全程膝盖对准第二脚趾。做完3组后告诉我感觉怎么样。"
```

**给判断方法，不给数字。学员学会了自己判断，就不需要每次都等你给指令了。**

4. 每周结束时，回顾"进步评估"，决定下周是否调整
5. 每4-6周安排一次减量周（训练量降至40-50%）

注意：
- 模板不是"让学员按表执行"，是"学员填表的过程就是学习判断的过程"
- 前两周教练可以帮填，第三周开始让学员自己填、教练检查
- 当学员能不看公式直接判断"今天该练什么"——说明他学会了

## 第七章：羽毛球专项体能训练周期化（NSCA CSCS 框架）

> **写给谁**：已经稳定训练、想通过系统体能训练提升场上表现的学员和教练
> **核心原则**：场上技术训练解决"会不会打"，场下体能训练解决"打不打得动"
> **参考标准**：NSCA CSCS 周期化训练模型、运动生理学适应原理

### 7.1 六种训练适应类型——你需要知道"练的是什么"

每一块肌肉、每一条能量通路，对不同类型的训练产生不同的适应。
以下六种适应是羽毛球专项体能训练的基础，按训练顺序排列。

#### 类型①：肌肥大（Hypertrophy）——先有"量"才有"质"

```
定义：肌纤维横截面积增加（肌肉变大）。
原理：肌肉体积增大 → 产生力量的基础增大。
为什么先练：没有肌肉量，后面的力量、爆发力都没有"材料"可用。

训练参数：
  负荷：60-75% 1RM（8-12RM）
  组数：3-5组
  次数：8-12次
  组间休息：60-90秒
  动作速度：中速，控制性（2秒向心/2秒离心）
  频率：每个肌群每周2次
  持续时间：4-6周

一句话：肌肥大是地基。地基小了，上面盖不了高房子。
```

#### 类型②：最大力量（Max Strength）——有了"量"之后让它"有力"

```
定义：神经肌肉系统在一次最大随意收缩中产生力量的能力。
原理：神经募集更多运动单位 + 肌纤维间的协调改善。
为什么在肌肥大之后：肌肥大给了你"材料"，最大力量训练教你怎么用这些材料。

训练参数：
  负荷：80-90% 1RM（1-5RM）
  组数：3-5组
  次数：1-5次
  组间休息：2-5分钟（必须充分恢复）
  动作速度：爆发性向心（快速推起），控制性离心
  频率：每个肌群每周1-2次
  持续时间：4-6周

一句话：力量训练不让你变壮——让你变"紧"，神经效率更高。
```

#### 类型③：爆发力（Power）——有力之后还要"快"

```
定义：单位时间内产生最大力量的能力（力量 × 速度）。
原理：快速伸缩复合训练（Plyometrics）+ 轻重负荷快速发力。
为什么在力量之后：爆发力需要力量作为基础——没有力量就没有"力"可"爆"。

训练参数：
  负荷：30-60% 1RM（快速发力）
        或自重/轻负荷爆发性动作（跳跃、药球）
  组数：3-5组
  次数：3-6次（必须保证每次都是爆发性）
  组间休息：2-3分钟（爆发力训练需要充分恢复）
  动作速度：尽可能快（向心爆发的、离心快速反弹）
  频率：每个动作每周2次
  持续时间：4-6周

爆发力训练的关键不是"多重"——是"多快"。
如果你做的速度不够快，它就不是爆发力训练。
```

#### 类型④：肌耐力（Muscular Endurance）——能撑住整场比赛

```
定义：肌肉在长时间重复收缩中维持力量输出的能力。
原理：提高毛细血管密度 + 线粒体氧化能力 + 代谢废物清除能力。

训练参数：
  负荷：40-60% 1RM（15-25+RM）
  组数：2-3组
  次数：15-25次或以上
  组间休息：30-60秒
  动作速度：中速，持续
  频率：每个肌群每周2-3次
  持续时间：贯穿全年（与力量/爆发力同期进行）

羽毛球场上，你不需要一次爆发出100%的力量。
你需要的是连续3局还能输出70%的力量。
这就是肌耐力。
```

#### 类型⑤：稳定性（Stability）——控制力量的能力

```
定义：通过核心和关节周围小肌群的协同收缩，维持运动中的姿态和关节对位。
原理：近端稳定是远端发力的前提。核心不稳 → 力量传不上去。

训练参数：
  负荷：自重或轻负荷
  组数：2-3组
  次数：8-15次或30-60秒保持
  组间休息：45-60秒
  动作速度：慢速、控制
  频率：每次训练前作为激活，或每周2-3次单独训练

稳定性训练不产生"可见的力量增长"——
但它是你所有力量能不能用到球场上的关键。
```

#### 类型⑥：神经肌肉训练（Neuromuscular Training）——让身体更快更协调

```
定义：训练神经系统的反应速度、肌肉间的协调模式、本体感觉。
包括：敏捷性训练、反应训练、平衡训练、协调训练。

训练参数：
  负荷：自重为主
  量：低到中（神经训练疲劳快）
  组间休息：充分（神经恢复需要时间）
  频率：每周2-3次
  时机：放在训练课的前段（神经不疲劳时效果最好）

神经训练是连接"练得壮"和"场上打得好"之间的桥梁。
```

### 7.2 训练顺序——为什么先肌肥大、后爆发力

```
NSCA CSCS 周期化训练的核心原则：
训练的排列顺序决定了最终的运动表现水平。

正确顺序（从长期发展角度看）：
  阶段1：肌肥大（4-6周）→  基础材料
  阶段2：最大力量（4-6周）→  神经效率
  阶段3：爆发力+肌耐力（4-6周）→  场上转化
  稳定性+神经训练：贯穿全程，不单独成阶段

为什么不能跳过肌肥大直接练力量？
  肌肉量不够 → 力量训练效果有限
  力量不够 → 爆发力训练效果有限
  爆发力不够 → 场上表现不会提升

反过来说：
  先练了肌肥大 → 力量训练有"材料"可用
  有了力量 → 爆发力有"力"可"爆"
  有了爆发力 → 杀球更快、启动更猛
```

**全年训练中的分配比例（适用于业余到专业）：**

```
             肌肥大  力量  爆发力  肌耐力  稳定性  神经
初学者(第一年)  40%    20%    10%    15%    10%    5%
中级(2-3年)    25%    25%    20%    15%    10%    5%
高级/专业      15%    20%    25%    15%    10%    15%
```

### 7.3 周期化模型——年计划/赛期/备赛期/休赛期

#### 年度周期划分（适用于有赛季的羽毛球选手）

```
         ┌─────────────────────────────────────────────────────┐
         │    休赛期    │   备赛期   │    比赛期    │  过渡期  │
         │  (4-8周)     │  (6-10周)  │  (16-24周)   │  (2-4周) │
         └─────────────────────────────────────────────────────┘
训练重点 ：肌肥大→力量   力量→爆发力    维持+神经   主动恢复
场上训练 ：技术修复      战术构建       比赛节奏    休息/轻量
强度     ：中高          高            中到极高     低
量       ：高            中            低到中       低
```

**休赛期（Off-Season）——储备期**

```
目标：建立力量基础、纠正技术缺陷、
     增加肌肉量（如果需要）、提高肌耐力容量

训练重点：
  前四周：肌肥大为主（8-12RM，3-5组）
  后四周：过渡到最大力量（4-6RM，3-5组）
  肌耐力作为辅助：每周2次（15-20RM，2-3组）
  稳定性训练：每次训练前10分钟
  场上技术训练：每周2-3次，以技术修正为主

时间分配：
  体能训练：每周3-4次
  场上训练：每周2-3次
  每次时长：60-75分钟
```

**备赛期（Pre-Season）——转化期**

```
目标：将休赛期建立的力量基础转化为
     场上需要的爆发力和速度

训练重点：
  前四周：力量维持（5RM，3组）+ 爆发力发展（3-5RM@30-60%，爆发性）
  后四周：力量减量（3RM，2组）+ 爆发力峰值（药球/跳跃，低量高质量）
  肌耐力：继续保持（15-20RM，2-3组）
  神经训练：每周2次——敏捷梯、反应训练、变向训练

时间分配：
  体能训练：每周2-3次
  场上训练：每周3-4次
  每次时长：45-60分钟
```

**比赛期（In-Season）——维持期**

```
目标：维持休赛期/备赛期建立的体能水平，
     以场上表现为优先

训练重点：
  力量：维持性训练（5×5或3×3，中高负荷），每周1-2次
  爆发力：低量高质量（每周1次药球/跳跃）
  肌耐力：通过场上训练维持
  神经训练：每周1-2次，放在场上训练前

关键原则：
  "比赛期不是进步的时候——是维持的时候。"
  赛前48小时不做高强度力量训练。
  比赛间的恢复比训练更重要。
```

**过渡期（Transition）——主动恢复期**

```
目标：生理和心理的主动恢复，为下一周期做准备

训练重点：
  低强度活动：游泳、骑自行车、轻量场上训练
  灵活性和筋膜恢复
  不进行系统性的力量训练（2-4周）
```

### 7.4 三周期进阶模型——从小白到专业

#### 初级三周期模型（第一年）

```
适合人群：无系统力量训练经验的基础学员
总时长：16-18周（3个周期，每周期4-6周+1周减量）

周期1：肌肥大基础期（第1-5周）
  负荷：60-70% 1RM（10-12RM）
  组数：3组
  频率：每周2次全身训练
  动作：基础复合动作为主
        深蹲/分腿蹲、俯身划船、平板卧推、臀桥、
        肩推、引体向上（助力/自重）
  每次训练：6-7个动作
  组间休息：60秒
  第5周：减量（50%训练量）

周期2：力量建立期（第6-10周）
  负荷：75-85% 1RM（5-8RM）
  组数：3-4组
  频率：每周2次全身训练（上下肢分化）
  动作：同上，负荷增加
  组间休息：90-120秒
  加入：核心稳定训练（每次训练前做）
  第10周：减量

周期3：向场上转化期（第11-16周）
  负荷：力量维持（5RM×3组）+ 爆发力（3-5次×3组@30-50%）
  频率：每周2次（1次力量维持+1次爆发力）
  加入：药球侧抛、跳箱、敏捷梯
  肌耐力：每次训练后加2个动作（15-20×3组）
  神经训练：每周1次
  第16周：减量+测试
```

#### 中级五周期模型（2-3年训练经验）

```
适合人群：已经完成1-2年系统训练，基础力量已建立
总时长：24-30周（5个周期，每周期4-6周）

周期1：肌肥大（第1-5周）
  负荷：70-80% 1RM（8-10RM）
  组数：4组
  分化：上下肢分化（每周练4次：上肢2次+下肢2次）
  组间休息：60-75秒
  每部位动作数：3-4个

周期2：力量积累（第6-10周）
  负荷：80-87% 1RM（3-6RM）
  组数：4-5组
  分化：推拉腿分化
  组间休息：2-3分钟
  加入：辅助动作（肩袖、单侧训练）

周期3：力量峰值+爆发力起步（第11-15周）
  负荷：力量日 85-92% 1RM（2-4RM×3-4组）
        爆发力日 50-60% 1RM（3-5次×3-5组，爆发性）
  分化：力量日+爆发力日交替
  组间休息：力量日3分钟，爆发力日2分钟
  加入：跳跃训练（每周2次）

周期4：爆发力峰值+场上转化（第16-20周）
  负荷：力量维持 80-85%（3-5RM×3组）
        爆发力 30-50%（3-5次×3组，尽可能快）
  加入：每周3次神经训练（敏捷梯、反应灯、变向）
        药球旋转抛、侧抛、过顶抛
  组间休息：爆发力训练需要充分恢复（2分钟以上）

周期5：比赛期维持（第21-26周）
  负荷：力量 80% 1RM（5×5），每周1次
        爆发力 30-40%（3-5次×2-3组），每周1次
  频率：每周2次力量+爆发力整合训练
  每次时长：30-40分钟（高效维持）
```

每次训练的参数速查：

### 7.6 训练顺序安排（一次训练课内）

```
一次训练课的正确顺序（NSCA CSCS推荐）：

① 神经激活/敏捷性训练（5-10分钟）
   放在最前面——神经不疲劳时效果最好
   例：敏捷梯、反应训练

② 爆发力训练（15-20分钟）
   放在力量训练之前——需要神经系统保持新鲜
   例：跳箱、药球抛掷

③ 主要力量训练（20-30分钟）
   复合动作先做，辅助动作后做
   例：深蹲→分腿蹲→腿举

④ 辅助力量/肌耐力（10-15分钟）
   单关节动作、肩袖、核心
   例：弹力带外旋、死虫式

⑤ 恢复/拉伸（5-10分钟）
   静态拉伸、筋膜放松

原则：神经系统优先 → 爆发力优先 → 复合动作优先
      从小到大的关节作为热身（踝→膝→髋→腰→肩→腕）
```
