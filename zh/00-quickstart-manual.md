# 第一章：快速上手

## 1.1 今天就开始——新手的第1天

```
如果你是零基础，今天拿起拍子，做这三件事就够了：

① 握拍（5分钟）
  正手握拍：虎口V形对齐拍柄右上棱，掌心是空的
  反手握拍：拇指贴在拍柄斜面上（不是宽面正中间）
  → 详见 [15-技术全解析](15-technical-training.md) 第1章

② 颠球（10分钟）
  用正手握拍，连续颠球，目标是50个不掉
  这个训练让你建立"球感"

③ 自测步法（10分钟）
  从球场中心出发→跑到正手网前→手摸网带→跑回中心
  记录步数。然后反手网前、正手后场、反手后场各测一次
  → 记下你今天的步数，一个月后再测，看有没有变少

第一天训练结束。不贪多。
```

## 1.2 第1周的训练安排

```
如果你的时间：每周可以打2-3次，每次1.5小时

第1次（技术日）：高远球 + 步伐
  热身15分 → 高远球练习30分 → 步伐练习20分 → 整理10分

第2次（综合日）：对打 + 体能
  热身15分 → 半场对打30分 → 间歇跑15分 → 整理10分

第3次（自由日）：比赛或补弱项
  可以根据你的兴趣——打比赛，或者补一下最弱的技术
```

## 1.3 第1个月的目标

```
一个月后，你应该能做到：

技术：
  ☐ 高远球能打到对方底线（不管方向）
  ☐ 正手握拍切换反手握拍不需要看拍子

步伐：
  ☐ 从中心到四个方向都能在3步内到位
  ☐ 知道启动步是什么、怎么做

体能：
  ☐ 能连续跑动20分钟不休息

知识：
  ☐ 知道什么是发力顺序（脚→髋→腰→肩→手）
  ☐ 知道训练前要热身、训练后要拉伸

全部打✓  → 恭喜，你已经入门了。可以进入更系统的训练了。
有没打✓的 → 不要急，下个月接着练。每个人的速度不一样。
```

# 第二章：为什么这么做——核心原则

## 2.1 训练不是"练什么"，是"为什么练"

```
大多数人的训练逻辑："今天去打球"
精英的训练逻辑："今天练高远球的发力顺序，因为上一场比赛发现打不远"

这就是为什么你需要理解原则——理解了原则，你就能自己设计训练方案。
以下四个原则是所有训练的基础，理解了它们，你就理解了整个体系。
```

## 2.2 四大核心原则

### 原则①：动作质量 > 训练数量

```
一句话：练错的动作100次 = 巩固100次错误

为什么：
  你的肌肉和神经系统记住的是你重复最多的模式。
  如果你每次都用错误的方式发力，你不是在"练"——你是在"巩固错误"。

怎么做：
  ☐ 练一个新技术时，先慢速做对，不追求数量
  ☐ 如果动作变形了 → 停下来，不要"做完这组再说"
  ☐ 正确的10次 > 变形的50次

配套工具：A2-技术纠错卡（用于每次技术训练时自检）
配套文档：[01-核心内容](01-core-content.md) 第1章
```

### 原则②：神经肌肉控制 > 力量输出

```
一句话：先学会控制肌肉，肌肉才能发力。顺序不能反。

为什么：
  很多新手一上来就追求"杀球重"，结果动作不对，肩膀痛了。
  这不是力量不够——是神经还没学会怎么控制肌肉。

怎么做：
  ☐ 新的动作先用空挥找感觉（不加球）
  ☐ 然后定点喂球（不跑动，只做动作）
  ☐ 最后才在跑动中做

配套工具：A2-技术纠错卡
配套文档：[15-技术全解析](15-technical-training.md) 第5章
```

### 原则③：预防损伤 > 追求表现

```
一句话：一次受伤=回到起点，恢复时间是训练时间的3-10倍。

为什么：
  一个简单的崴脚，可能需要6周才能恢复。
  在这6周里，你的体能下降、技术生疏、比赛节奏丢失。
  所以，"不受伤"本身就是训练的一部分。

怎么做：
  ☐ 训练前热身不少于15分钟 → [22-热身与整理](22-warmup-cooldown.md)
  ☐ 训练后拉伸不少于10分钟 → [22-热身与整理](22-warmup-cooldown.md)
  ☐ 疲劳时不冲极限 → [24-安全边界](24-safety-guide.md)
  ☐ 膝盖痛/肩痛/腰痛不"忍一下" → [23-诊断索引](23-diagnosis-index.md)

配套工具：D2-伤病追踪表（有伤时记录）、D4-装备检查表（每周检查）
配套文档：[24-安全边界](24-safety-guide.md)
```

### 原则④：长期发展 > 短期进步

```
一句话：神经系统适应需要4-6周，结缔组织适应需要3-6个月。

为什么：
  你想"三个月从零基础打败所有人"——不可能。
  身体有自己的适应节奏，你不能加速。

怎么做：
  ☐ 每4-6周安排一次减量周（训练量降到50%）
  ☐ 不要每周都加量（身体的适应需要时间）
  ☐ 用月度评估表追踪进步 → A4-月评估表

配套工具：A4-月评估表、A3-周打卡表
配套文档：[01-核心内容](01-core-content.md) 第1章、[06-四周计划](06-four-week-plan.md) 第5章
```

## 2.3 训练量的计算公式

```
这是整个体系最核心的公式。记住它，一辈子受用。

起始量 = 基线值 × 60-70%

举例：
  你的深蹲基线=20次（做到动作变形为止）
  起始训练量 = 20 × 65% = 13次/组
  组数 = 基线<10次→2组 / 10-20次→3组 / >20次→4组

进阶条件：连续2次训练顺利完成后，增加5-10%
减量条件：连续2次训练动作质量都在下降 → 减量50%
```

# 第三章：具体怎么做——训练工作流

## 3.1 一次训练的标准流程

```
不管你是初学者还是高手，每一次训练都遵循这个流程：

┌──────────────┐
│  热身15分钟  │  ← 不可跳过。详见 [22-热身与整理](22-warmup-cooldown.md)
├──────────────┤
│  技术训练    │  ← 练什么？看下面的"技术训练工作流"
│  (30-50分钟) │
├──────────────┤
│  体能/对抗   │  ← 按你的需求和目标选择
│  (15-30分钟) │
├──────────────┤
│  整理10分钟  │  ← 不可跳过。详见 [22-热身与整理](22-warmup-cooldown.md)
└──────────────┘

每次训练前问自己三问：
  ① 我今天的目标是什么？（一个具体的技术目标）
  ② 我怎么判断做到了？（量化的标准）
  ③ 如果没做到，明天怎么调整？
```

## 3.2 技术训练工作流

```
练任何一个技术，都按这五步走：

第1步：看（1分钟）
  看正确的动作示范（视频/教练/文档中的图）
  脑中过一遍动作流程

第2步：空挥（5分钟）
  不加球，只做动作
  重点是感受发力顺序（脚→髋→腰→肩→手）
  对着镜子更好

第3步：定点喂球（10分钟）
  球在一个固定位置，你不需要移动
  只做动作，保证每次击球质量

第4步：移动喂球（10分钟）
  从中心跑到击球位再打
  重点是：到位时拍子准备好了

第5步：对抗中使用（-）
  在对抗中有意识地用这个技术
  允许失误——目标是"敢用"，不是"每拍都用好"

卡在第3步上不去？
  → 问题不是"练得不够"，是"基础动作还有问题"。
  → 退回第2步，重新检查动作。

卡在第4步上不去？
  → 问题可能是步伐不到位。
  → 去读 [11-步伐训练](11-footwork-training.md)。
```

## 3.3 一周训练安排工作流

```
一周三次是大多数人的最佳频率。

方案A：技术+技术+对抗
  周一：技术训练（高远球/杀球）
  周三：技术训练（网前/反手）
  周五：对抗比赛（检验技术掌握程度）

方案B：技术+体能+对抗
  周二：技术训练
  周四：体能训练（间歇跑+力量）
  周六：对抗比赛

方案C：技术+综合+自由
  周一：技术训练
  周三：技术50% + 体能30% + 战术20%
  周五：自由安排（比赛/补弱项/休息）

每周日晚上做三件事：
  ① 打卡：填A3-周打卡表
  ② 总结：这周哪次训练效果最好？下周要调整什么？
  ③ 计划：确定下周的训练内容
```

## 3.4 赛前工作流

```
比赛前30分钟——不要浪费这段时间。

赛前30分钟：开始热身（详见 [22-热身与整理](22-warmup-cooldown.md)）
赛前15分钟：热身到出汗，做几次短距离冲刺
赛前10分钟：找个安静的地方，深呼吸5次
              说出本场比赛的战术关键词（如"压反手"）
赛前5分钟：回到场地，做几个空挥，找到手感
上场前：做一个固定的动作（摸拍线/深呼吸/拍三下地）
         告诉你的大脑："开始了"

配套工具：B1-赛前准备卡
配套文档：[07-心理训练](07-psychological-training.md) 第6章
```

## 3.5 赛后工作流

```
打完比赛——你的任务还没结束。

赛后立即（5分钟内）：
  填B3-赛后复盘卡
  写三件做得好的 + 三件可以改进的

赛后30分钟内：
  补充碳水和蛋白质（详见 [08-营养恢复](08-nutrition-recovery.md) 第5章）
  开始整理（静态拉伸+筋膜放松，详见 [22-热身与整理](22-warmup-cooldown.md)）

赛后第2天：
  检查是否有异常疼痛（刺痛/持续痛）
  如果有 → 去读 [24-安全边界](24-safety-guide.md) 和 [23-诊断索引](23-diagnosis-index.md)
  如果只是正常酸痛 → 可以轻度活动促进恢复
```

# 第五章：遇到问题

## 5.1 不要问"我该怎么办"——去查索引

```
训练中遇到问题，最高效的方法不是问人——是按症状查索引。

索引在 [23-诊断索引](23-diagnosis-index.md) 中，
覆盖60+常见问题，每个问题给出可能的原因和对应的文档章节。

比如：

"我杀球没力" →
  ① 可能原因：只用了手臂没用到全身
  ② 去读：15-技术全解析 第2章

"我打完膝盖痛" →
  ① 可能原因：膝盖内扣/臀肌无力/热身不够
  ② 去读：09-力量体能 第4章 + 22-热身与整理 + 检查装备

"我第3局跑不动" →
  ① 可能原因：有氧基础不够/体能分配不合理/碳水没吃够
  ② 去读：09-力量体能 第5章 + 14-比赛策略 第1章 + 08-营养恢复
```

## 5.2 什么情况下该去看医生

```
以下情况不要自己诊断，直接去医院：

☐ 受伤时听到"啪"的响声
☐ 受伤部位完全不能承重/不能活动
☐ 受伤后30分钟内肿胀明显增大
☐ 同一个位置连续3次训练都痛
☐ 训练中有胸闷/头晕/眼前发黑
```

## 5.3 如果你不知道从哪开始

```
从这篇手册开始。
读完第一章，知道今天练什么。
读完第二章，知道为什么这么练。
读完第三章，知道怎么安排训练。
读完第四章，知道遇到问题用哪个工具。
读完第五章，知道去哪里找答案。

这就够了。剩下的24篇文档，你可以在遇到具体问题时按需去读。
不需要一次读完。——就像你不会一次读完一本字典。你会在需要查某个字的时候去翻它。
```
