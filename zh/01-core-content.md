## 第一章：训练哲学——四个不变的原则

不管你是15岁还是50岁，零基础还是复训，以下四个原则不变：

| 原则 | 为什么 | 什么不能做 |
|:-----|:-------|:-----------|
| **动作质量 > 训练数量** | 神经肌肉系统记住的是你重复最多的模式，练错的动作重复100次=巩固100次错误 | 不能用"做了多少次"衡量训练效果 |
| **神经肌肉控制 > 力量输出** | 神经系统先学会控制肌肉，肌肉才能发力。顺序不能反 | 不能在动作模式不稳定时加重量 |
| **预防损伤 > 追求表现** | 一次受伤=倒退回起点，恢复时间往往是训练时间的3-10倍 | 不能在疲劳状态下冲击极限 |
| **长期发展 > 短期进步** | 神经系统适应需要4-6周，结缔组织初步适应约8-12周，完全结构适应需3-6个月 | 不能每周都加量 |

**这四个原则不是建议，是底线。任何训练安排必须同时满足四条才能执行。**

## 第二章：训练前的第一步——基线测试

**不要猜自己是什么水平，测。**

### 2.1 基线测试协议（15分钟，每月重测一次）

| 测试项目 | 测试方法 | 测什么 | 记录 |
|:---------|:---------|:-------|:-----|
| **单足站立（睁眼）** | 赤足，双手叉腰，非支撑脚离地，从脚离地开始计时，支撑脚移动/落地/叉腰手松开即停。每侧3次取最好 | 本体感觉基础 | 左__秒 右__秒 |
| **单足站立（闭眼）** | 同上，闭眼。安全提示：旁边放垫子或有人保护 | 本体感觉进阶（去除视觉代偿） | 左__秒 右__秒 |
| **死虫式耐久** | 仰卧，手脚起始位朝天，呼气时对侧手脚伸直但不落地，吸气收。节奏：2秒出2秒回。至动作变形或无法继续为止 | 核心控制耐力 | __次（记录到动作变形的次数，不是到累趴） |
| **平板支撑** | 前臂撑地，身体成直线，从身体成直线开始计时，至臀部掉/塌腰/无法维持停 | 核心等长耐力 | __秒 |
| **单腿下蹲控制** | 单腿站立，慢速下蹲至膝盖45度再站起，全程膝盖对准第二脚趾。能完成5次不内扣吗？ | 膝关节动态控制 | ☐能完成5次 ☐做不到 |
| **自重深蹲阈值** | 站姿与肩同宽，下蹲至大腿平行地面。能做多少个标准的？节奏1-0-1 | 下肢基础力量耐力 | __次 |
| **跪姿俯卧撑** | 膝盖着地，肩胛收紧，下降至胸接近地面。能做多少个标准的？ | 上肢基础力量耐力 | __次 |

### 2.2 三维分级：确定你的起始档位

| 维度 | 你的数据 | 怎么判断 |
|:-----|:---------|:---------|
| **年龄** | ____岁 | 直接填写 |
| **训练年限** | □ 0-3月 □ 3-12月 □ 1-3年 □ 3年+ | 近6个月规律训练算"训练" |
| **当前基线水平** | □ 入门（大部分测试达不到基准线） □ 基础（达到基准线但离进阶线还远） □ 进阶（接近或达到进阶线） | 对照下面的基准判定 |

**基准线（达到才算"基础"级）：**
- 单足睁眼：每侧≥30秒
- 单足闭眼：每侧≥10秒
- 死虫式：≥15次动作标准
- 平板支撑：≥45秒
- 单腿下蹲：能完成5次不内扣
- 深蹲：≥15次标准
- 跪姿俯卧撑：≥10次标准

> **⚠️ 注意：** 训练年限不代表当前水平。练了两年但断断续续，基线测试可能和练三个月的差不多。**以测试结果为准，不以你觉得自己"应该"什么水平为准。**

### 2.3 不同年龄段的特点与安全限制

| 年龄段 | 生理特点 | 对训练的影响 | 安全限制 |
|:-------|:---------|:-------------|:---------|
| **< 15岁** | 骨骼未闭合，神经系统发育快，力量增长潜力有限 | 动作品质和学习速度最好，但绝对力量增长慢 | 不进行大重量训练，BMI超重的以自重为主 |
| **15-25岁** | 睾酮水平高，恢复最快，神经肌肉适应能力最强 | 适合建立动作模式和力量基础的黄金期 | 容易过度自信导致过量训练 |
| **25-35岁** | 力量峰值期，恢复能力仍在高位 | 技术和力量都可以推进 | 出现旧伤复发的风险开始增加 |
| **35-45岁** | 恢复速度开始下降，结缔组织弹性下降 | 热身和整理时间需要延长到10-15分钟 | 跳跃和急停的训练量需要控制 |
| **45-55岁** | 肌肉流失速度加快（每年1-2%），关节压力增大 | 力量维持比力量增长更重要 | 离心控制训练的比例应提高 |
| **> 55岁** | 平衡能力下降，反应时间延长 | 本体感觉训练优先级最高 | 所有的训练都要有保护措施 |

## 第三章：找到你的起始训练量——通用公式

### 3.1 核心公式：从基线到训练量

```
【第一步】测基准（用2.1节测试）
【第二步】定起始强度 = 基准的 60-70%
【第三步】适用范围：此量安全使用1-2周
【第四步】进阶条件：连续2次训练顺利完成且动作不变形
【第五步】进阶增量：每次增加 5-10%（不是每周都必须加）
```

**举例——死虫式：**
```
基线测试：做了15次动作变形
起始量：15 × 70% = 10次（如果集中注意力能完成10次的量）
进阶条件：连续2次训练都做完10次且动作从第一到最后不变形
进阶后：10 × 110% = 11次
```

### 3.2 为什么是60-70%不是80-90%

这是基于运动学习的"最佳挑战点"理论：
- 太容易（50%以下）→ 不产生适应
- **最佳（60-75%）→ 最大学习效果**
- 太难（85%以上）→ 代偿动作出现，神经肌肉系统学习错误模式

**对零基础学员，宁可低估，不可高估。** 低估的代价是一周后要加量；高估的代价是代偿动作需要4-6周来纠正。

### 3.3 不同年龄段的热身和整理时间公式

```
热身时间(min) = 年龄 ÷ 10 + 2
整理放松时间(min) = 年龄 ÷ 15 + 5

例：
20岁：热身 4分钟，整理 6分钟
40岁：热身 6分钟，整理 8分钟
60岁：热身 8分钟，整理 9分钟
```

**热身内容必须包含：**
- 激活训练部位（如今天练肩→弹力带外旋1组15次）
- 动态拉伸（非静态拉伸，训练前不做静态拉伸）
- 心率准备（从静止到训练心率的50%）

## 第四章：核心训练模块——按原则设计你的训练

### 4.1 模块一：神经肌肉控制

#### 4.1.1 足部本体感觉——你是从哪一级开始的？

| 测试结果（闭眼单足） | 你的起始级别 | 训练方案 |
|:---------------------|:-------------|:---------|
| **< 3秒** | 初级 | ① 睁眼单足站立，手扶墙，逐步减少手指支撑力 → ② 不扶墙睁眼站立 → ③ 闭眼2秒起步 |
| **3-10秒** | 基础 | ① 闭眼站到极限，记录每次进步 ② 不同地面（垫子→地毯→硬地） |
| **10-30秒** | 进阶 | ① 闭眼站+另一侧手上举 ② 闭眼站+接抛球 |
| **> 30秒** | 熟练 | 进入下一个模块 |

**核心原理：**
本体感觉训练的唯一变量是**难度梯度**，不是**训练量**。你不需要做100次单足站立，你需要找到你当前"刚好能完成但需要努力"的难度。

**难度梯度的控制维度：**
```
支撑面大小（双足→单足→单足+软垫）
视觉辅助（睁眼→闭眼→闭眼+头部转动）
上肢干扰（安静→手臂移动→接球）
时间（5秒→15秒→30秒→60秒）
```

**次级进阶原则：每次只改变一个维度，稳定后（连续3次训练达标）再换下一个。**

#### 4.1.2 核心稳定性神经控制

**基准测试：** 死虫式能完成多少次标准动作？

| 基准结果（次） | 起始量 | 组数 | 间歇 | 进阶条件 |
|:--------------:|:------:|:----:|:----:|:---------|
| < 8 | 基准×80% | 3组 | 60秒 | 连续3次训练动作不变形 |
| 8-15 | 基准×70% | 3组 | 45秒 | 同上 |
| > 15 | 基准×60% | 4组 | 30秒 | 同上（增加组数不是次数） |

**判断标准是否变形的自检方法（教你看自己）：**

```
死虫式动作变形的三个标志：
1. 下背部离开地面 → 核心力量不足，减小手脚放下幅度
2. 动作出现"冲刺感"（一快一慢）→ 速度过快，用3秒下放计时
3. 呼吸紊乱（憋气或急促）→ 专注呼气时伸展

如果出现以上任意一个 → 这一次数到变形了，不是你还想再做一次。
```

#### 4.1.3 步法模式

步法训练的核心变量不是"能做多少"，是"能在多大速度下保持稳定"。

| 维度 | 你的级别 | 训练方法 | 进阶信号 |
|:-----|:---------|:---------|:---------|
| **速度** | 慢速 | 每个分腿蹲用3秒下、1秒上、3秒回位 | 能在慢速下保持膝盖不内扣、躯干不晃动 |
| | 中速 | 2秒下、1秒上、2秒回位 | 同上+能感受到重心从后脚到前脚流畅转移 |
| | 快速 | 爆发力输出，0.5秒下、爆发上 | 同上+落地稳定不额外调整步骤 |
| **幅度** | 小幅度 | 步幅为肩宽的1倍 | 全程控制 |
| | 中幅度 | 步幅为肩宽的1.5倍 | 同上 |
| | 大幅度 | 步幅为肩宽的2倍 | 同上+不出现过度前倾 |

**进阶逻辑：先控制幅度，再提升速度。幅度未稳定前不加速。**

#### 4.1.4 上肢动力链

**判断你的动力链效率（不是靠感觉，靠观察）：**

```
药球投掷的自我观察清单：
1. 脚有没有蹬地发力？还是只转了上身？
   - 看投出后脚是否离地或转动 → 有 = 正确发力，没有 = 只用了上肢
2. 力量是从脚到手的顺序，还是"同时"发力？
   - 看投掷动作是否流畅分阶段 → 流畅=好，僵硬同时发力=不对
3. 球出去的方向和身体朝向是否一致？
   - 偏差 >45度 → 核心没有参与稳定
```

如果你做了上面的测试发现：
- **1不过** → 退回到分腿蹲训练，先建立下肢发力意识
- **1过2不过** → 做慢速弹力带模拟，专注于"脚→髋→肩→手"的分阶段发力顺序
- **123都过** → 你的动力链训练可以加入速度变化

### 4.2 模块二：结构性力量

#### 4.2.1 肩关节动态稳定——用力量比诊断，不是用能力猜

**肩关节力量诊断（不是"我感觉还行"）：**

| 测试 | 方法 | 正常值 | 你的结果 |
|:-----|:-----|:-------|:---------|
| 外旋/内旋峰值力量比 | 弹力带外旋最多能做几个 vs 内旋最多能做几个 | 外旋:内旋 = 2:3 | __:__ |
| 肩胛骨控制 | 肩胛俯卧撑能做多少个标准的 | ≥12次 | __次 |

**如果你的力量比偏离2:3：**
```
外旋偏弱（< 2:3）→ 加强弹力带外旋训练，每周3次，每次比上次多做1-2个
内旋偏弱（> 2:3）→ 增加内旋训练，但更常见的是外旋偏弱
差距越大 → 训练比例越偏向弱势侧（如外旋:内旋从1:1开始，而不是3:3）
```

**组数计算公式：**
```
起始组数 = 2组（如果是零基础或康复后返回）
稳定后组数 = 年龄系数 × 力量比差距量

年龄系数：<25=4, 25-40=3, >40=2
差距量：如果你的外旋15次、内旋22次 → 外旋偏弱差距≈30% → 组数=年龄系数×1.3

例：30岁，外旋偏弱30%
组数 = 3 × 1.3 = 约4组外旋训练，2组内旋训练
```

#### 4.2.2 膝关节预防性训练

**膝关节风险自评（训练前必做）：**

| 自检项 | 怎么测 | 正常 | 异常 |
|:-------|:-------|:-----|:-----|
| 膝盖内扣倾向 | 原地慢速下蹲，看膝盖是否对准第二脚趾 | 对准 | 向内扣 |
| 臀中肌激活 | 侧卧抬腿，注意力放在臀部，能感受到臀肌发力吗 | 能 | 大腿外侧或腰部发酸 |
| 单腿平衡 | 单腿站立，膝盖微曲，能稳定10秒吗 | 能 | 晃动明显或需要脚触地 |

**如果你的自检出现异常：**
```
膝盖内扣 → 暂停所有单腿下蹲训练，回到臀中肌激活+蚌式开合
臀中肌不激活 → 每次训练前加2组蚌式开合作为激活
单腿不稳 → 回到模块一的单足站立训练
```

**进阶判定公式（不是看天数）：**

```
可以进阶到下一级膝关节训练 = 满足以下所有条件：
1. 当前动作能连续完成目标次数且动作不变形 × 2次训练
2. 训练后24小时膝关节无不适感
3. 自我评估用力感（不是酸胀感）< 3/10
```

### 4.3 模块三：神经心理训练

#### 4.3.1 注意力——先诊断你的注意力类型

注意力不是"好不好"的问题，是"哪一类注意力需要训练"的问题。

| 注意力类型 | 表现 | 自检方法 | 适合的训练 |
|:-----------|:-----|:---------|:-----------|
| **持续注意** | 长时间保持在一个任务上 | 能专注一个训练多久不分心？<5分钟→需要训练 | 单点凝视训练 |
| **选择性注意** | 在干扰中保持专注 | 旁边有人说话时动作会不会变形？会→需要训练 | 干扰场景训练 |
| **分配注意** | 同时做两个任务 | 边做步法边看教练手势？做不到→需要训练 | 双重任务训练 |

**训练量设定：**

```
起始时间 = 你能保持注意力稳定的时间 × 80%
（例：能专注3分钟 → 每次训练2.5分钟）
进阶量 = 当前时间 + 30秒
进阶条件 = 连续3次训练没有出现注意力中断
```

#### 4.3.2 心理韧性——用压力分级确定你在哪一级

| 压力级别 | 特征 | 心率（相对静息） | 训练场景 |
|:---------|:-----|:-----------------|:---------|
| **L1 无压力** | 一个人在熟悉的环境训练 | 静息+0-10% | 日常训练 |
| **L2 低压** | 有人在看/录像 | 静息+10-20% | 有人旁观的训练 |
| **L3 中压** | 有计时/计分 | 静息+20-30% | 计时考核 |
| **L4 高压** | 有输赢/关键分 | 静息+30-50% | 模拟比赛 |
| **L5 极限** | 高压+疲劳+干扰 | 静息+50%+ | 压力测试 |

**你的起始训练级：站在L1，进入L2时心率上窜超过20%→回到L1再练两周**

**压力适应训练的核心逻辑：**
```
在Lx级别稳定后 → 进入Lx+1级别
在Lx+1级别出现动作变形或心率过高 → 退回Lx
在Lx级别再做1-2周 → 重新尝试Lx+1
```

**不是"硬扛"。硬扛只会巩固紧张状态下的错误模式。**

## 第五章：4周训练计划——不是固定日程，是自适应框架

**每周训练量的计算：**

```
每周训练频率 = 你的恢复能力系数 × 基础频率

基础频率 = 3次/周（最低有效刺激量）
恢复能力系数：
  年龄 < 25岁 → 1.2（可练3-4次）
  年龄 25-40岁 → 1.0（3次）
  年龄 > 40岁 → 0.8（2-3次，中间加一次恢复训练）

例：30岁 → 3 × 1.0 = 3次/周
    22岁 → 3 × 1.2 = 3.6 → 取3-4次
    50岁 → 3 × 0.8 = 2.4 → 2次力量+1次恢复
```

**每周是否增量的判断标准（不是按计划走，是按身体反馈走）：**

```
【绿码】可正常训练：
- 上次训练后24-48小时恢复
- 训练前精力评分≥7/10
- 无疼痛

【黄码】减量50%或改为恢复训练：
- 上次训练后48小时仍有明显酸痛
- 训练前精力评分4-6/10
- 有轻微酸痛感但不是疼痛

【红码】休息：
- 训练前精力评分<4/10
- 任何部位出现刺痛/钝痛
- 睡眠严重不足（<5小时）
- 生病中
```

**第1周和第4周的区别不是内容换了，是阈值变了：**

旧版写法：
```
第1周：神经适应
第2周：结构适应
第3周：整合应用
第4周：巩固提升
```

正确写法（自适应版）：
```
确定你当前在哪个阶段的方法：
1. 看你的基线测试 → 对照"3.1找到起始量"
2. 第一周用起始量训练 → 每天记录"训练完成度"和"训练后恢复状态"
3. 判断能否进阶 → 看"第二章每周是否增量的判断标准"
4. 能进阶 → 增加5-10%
5. 不能 → 维持原量或回到上一级

你不需要在第2周切换成"结构适应"。
你需要做的是：把当前的训练量做到稳定，再做下一个。
四个阶段是原则，不是日历。
```

## 第六章：评估体系——不是打分，是决策工具

### 6.1 动态稳定性评估（教练版）

教练站在学员正前方2米处观察：

| 观察点 | 判断标准 | 对应调整 |
|:-------|:---------|:---------|
| 膝盖轨迹 | 下蹲时膝盖是否对准第二脚趾 | 内扣→退到臀中肌激活 |
| 骨盆稳定 | 下蹲时骨盆是否水平 | 倾斜→核心力量不足 |
| 躯干倾斜 | 身体是否过度前倾 | 前倾>45度→髋部柔韧性问题 |
| 重心位置 | 重心是否在支撑脚中心 | 偏外→踝关节稳定性问题 |

### 6.2 动力学评估（教练版）

| 观察点 | 优秀 | 需要改进 |
|:-------|:-----|:---------|
| 发力顺序 | 脚→髋→肩→手 依次 | 手臂先发力或所有部位同时 |
| 动作连续性 | 流畅无停顿 | 分段脱节 |
| 力的方向 | 与目标方向一致 | 偏离目标方向 >30度 |

### 6.3 学员自评方法（教给学员）

```
【每次训练结束填】

今天训练的项目：___________

1. 动作完成度（与昨天/上次比）：
   □ 更好（动作更流畅/更稳定/能做更多次数）→ 继续保持
   □ 一样 → 正常，不需要每天都进步
   □ 退步（动作更僵硬/晃动更多）→ 看看是不是疲劳了，明天恢复

2. 今天的"最差动作"是哪一次？
   记录下来：___________
   原因猜测：___________

3. 训练后身体感觉：
   □ 感觉很好，有进步感
   □ 正常疲劳
   □ 某个部位有酸痛（不是疼痛）
   □ 某个部位有疼痛 → 下次训练前告诉教练
```

## 第七章：常见训练问题的诊断树

| 你遇到的问题 | 先排查这个 | 再排查这个 | 最后 |
|:-------------|:-----------|:-----------|:-----|
| 动作做标准但练了几周没进步 | 训练量够不够？ | 恢复（睡眠/营养）够不够？ | 是否需要更难的变式？ |
| 动作越练越差（从好变坏） | 是不是疲劳累积？ | 是不是加量太快？ | 回到上一次能稳定完成的量 |
| 训练中某个部位痛 | 刺痛还是酸胀？刺痛=停，酸胀=正常 | 疼痛出现的时间和训练动作的对应关系 | 如果刺痛持续，看医生 |
| 能完成动作但感觉"使不上劲" | 动力链检查（脚-髋-肩-手的顺序对不对） | 是不是太紧张了（握拍太紧/耸肩） | 退到慢速，每步拆开练 |
| 学了新动作后旧动作变形 | 正常，神经系统的资源分配在学新东西 | 每次训练先巩固旧动作，再用20%时间学新 | 一般1-2周后恢复 |

## 第八章：从"教你练"到"你会练"——结语

这份文档的目标不是给你一套训练菜单。菜单吃完就没了。目标是让你掌握：

**五个自己解决问题的能力：**
1. **自测** — 知道自己的基线在哪，而不是猜
2. **自定** — 根据基线算自己的起始量，而不是抄别人的
3. **自检** — 训练中能判断自己的动作对不对，而不是等教练说
4. **自调** — 知道什么时候加量、什么时候减量、什么时候维持
5. **自诊** — 遇到问题能用诊断树找到原因，而不是放弃

> **一个好的教练，不是教你做什么动作，是教你怎么判断"该做什么动作"。**
