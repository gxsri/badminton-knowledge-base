## 第一章：力量训练不是举铁

### 1.1 羽毛球需要的力量类型

| 力量类型 | 定义 | 你在场上什么时候用到 | 训练方法 |
|:---------|:-----|:---------------------|:---------|
| **最大力量** | 你能输出的最大力 | 杀球时 | 大重量低次数（1-5RM） |
| **力量耐力** | 你能重复输出多少次足够大的力 | 第3局还在跑 | 中等重量多次数（15-25RM） |
| **爆发力** | 你能多快输出力 | 蹬地启动、起跳 | 轻重量快速输出 |
| **离心控制** | 你能多好地吸收力 | 落地缓冲、变向制动 | 慢速放下、快速起来 |
| **稳定力量** | 你能在保持稳定的同时输出力 | 移动中击球 | 单侧/不稳定面训练 |

### 1.2 不同阶段的力量训练侧重点

| 训练阶段 | 力量类型优先级 | 为什么 |
|:---------|:---------------|:-------|
| Level 0（0-1月） | 稳定力量 > 离心控制 > 力量耐力 | 先学会控制关节，再学发力 |
| Level 1（1-3月） | 力量耐力 > 离心控制 > 稳定力量 | 能重复动作，才能建立基础 |
| Level 2+（3月+） | 爆发力 > 最大力量 > 力量耐力 | 技术的提升需要力量基础支撑 |

## 第二章：训练前的准备——先找到你的基线

### 2.1 力量训练的三个基线测试

不需要专业设备，自重就能测。

| 测试 | 方法 | 测什么 | 结果记录 |
|:-----|:-----|:-------|:---------|
| **深蹲阈值** | 标准自重深蹲，做到动作变形为止，记录次数 | 下肢力量耐力基线 | __次 |
| **俯卧撑阈值** | 标准俯卧撑（男）/跪姿俯卧撑（女），做到动作变形，记录次数 | 上肢推力基线 | __次 |
| **划船阈值** | 弹力带划船，做到动作变形（肩胛无法收紧为止），记录次数 | 上肢拉力基线 | __次 |

### 2.2 从基线计算起始训练量

```
起始量公式 = 基线值 × 60-70%（和01核心内容同一个公式）

例：
深蹲阈值 = 20次
起始量 = 20 × 65% = 13次/组

组数：
基线 < 10次 → 2组
基线 10-20次 → 3组
基线 > 20次 → 4组（更少的次数、更多的组数）

组间休息：
起始阶段：60-90秒（休息充足保证动作质量）
进阶后：30-60秒（增加代谢压力）
```

### 2.3 不同年龄段的起始量调整系数

| 年龄 | 起始量系数 | 说明 |
|:----:|:----------:|:-----|
| < 20 | 1.0 | 按公式直接算 |
| 20-30 | 0.95 | 轻微下调 |
| 30-40 | 0.85 | 恢复速度下降，起始保守 |
| 40-50 | 0.75 | 结缔组织适应慢 |
| > 50 | 0.6 | 预防损伤为第一优先级 |

## 第三章：肩关节稳定——不是"每天3组"，是"找到你的起始阻力"

### 3.1 弹力带阻力的选择方法

不是"用蓝色弹力带"，是：

```
第一步：选一个你能完成12-15次的阻力
第二步：完成2组后，你的肩部前侧是否有明显的用力感？
  ● 有 → 阻力合适
  ● 完全没有 → 阻力太轻，换更重的
  ● 完成2组后肩部发抖/疼痛 → 阻力太重，换更轻的
第三步：记录你用的弹力带颜色/阻力等级
```

### 3.2 进阶判断

```
你可以加阻力/加次数的条件是：
1. 连续3次训练都能完成目标次数且动作不变形
2. 训练后24小时肩部无不适（不是酸痛，是不适）
3. 自我评估"用力感"在7/10以下（1=太轻松，10=极限）

满足以上3条 → 可以进阶
进阶方式：先加次数（每次加1-2次），次数到了15次稳定后再加阻力
```

### 3.3 肩部稳定训练的周期

| 阶段 | 持续多久 | 训练内容 | 怎么判断进入下一阶段 |
|:-----|:---------|:---------|:---------------------|
| **激活期** | 2-4周 | 低阻力弹力带外旋/内旋、YTWL | 能完成3组×15次标准动作，无代偿 |
| **稳定期** | 4-6周 | 增加阻力、增加训练频率 | 肩部力量比（外旋:内旋）接近2:3 |
| **整合期** | 持续 | 肩部训练融入全身训练 | — |

## 第四章：膝关节预防——不是"做几个"，是"能不能做"

### 4.1 膝关节训练的第一道门槛

**在做任何膝关节训练前，先通过这个测试：**

```
测试：单腿站立，缓慢下蹲到膝盖弯曲45度，再慢慢站起
标准：全程膝盖对准第二脚趾，无内扣，无晃动

结果判断：
☐ 能做，无问题 → 可以进入膝关节力量训练
☐ 能做但膝盖内扣 → 先做臀中肌激活训练2周再回来测
☐ 做不到（站不稳/疼痛） → 需要物理治疗，暂停膝关节训练
```

**如果你的膝盖内扣——不是练腿，是练臀。**

```
臀中肌激活（每天做，直到能通过测试）：
1. 蚌式开合 2组×15次（重点在感受臀部发力，不在次数）
2. 侧卧抬腿 2组×15次（同上）
3. 单腿臀桥 2组×12次（用支撑腿的臀部发力，不是腰）

判断激活成功的方法：
做完激活后，重新做单腿下蹲测试——
膝盖内扣减少了 → 激活有效
膝盖内扣没变化 → 激活做得不对（再检查动作）或需要更长时间
```

### 4.2 膝关节训练的量不是固定的

膝关节训练的变量是**控制质量**，不是**数量**。

| 控制质量 | 你的表现 | 适合的训练量 |
|:---------|:---------|:-------------|
| 差（需要全力集中才能不内扣） | 能做2-3次标准的 | 每次做2-3次、多组（4-6组）、长休息 |
| 中（不需要全力集中也能控制） | 能做5-8次标准的 | 3组×5次 |
| 好（可以边说话边做） | 能做10+次标准的 | 3组×8-10次，可以加负重 |

**原则：膝关节训练的量由控制质量决定，不由"你应该能做多少"决定。**

## 第五章：代谢适应——不是"跑圈"，是按公式算

### 5.1 你的能量系统起始训练量

```
第一步：知道你的"无氧阈值"
  测法：高抬腿30秒→测10秒心率→×6=每分钟心率
  你的无氧阈值 ≈ HRmax × 0.88
  
第二步：确定你的训练区间
  有氧训练：心率 = HRmax × 0.6-0.7
  无氧训练：心率 = HRmax × 0.8-0.9
  
  HRmax 估算（两种常用公式）：
  • Fox公式（最通用）：HRmax = 220 - 年龄（简单但个体标准差 ±10-15）
  • Tanaka公式（更精确）：HRmax = 208 - 0.7 × 年龄（适用更广年龄范围）
  实际训练中以主观疲劳感（RPE）结合心率为准。
  
第三步：持续时间
  有氧起始：15分钟（能在这个心率区间维持15分钟）
  间歇起始：10秒工作+50秒休息×6轮（1:5比例）
```

### 5.2 间歇训练的核心变量

间歇训练不是"做几组、休息多久"，是四个可以调的变量：

| 变量 | 调什么 | 怎么调 |
|:-----|:-------|:-------|
| **工作强度** | 你在工作期间多努力 | 从80%到95% |
| **工作时间** | 每次工作多久 | 从10秒到60秒 |
| **休息时间** | 休息多久 | 从1:5到1:1 |
| **总组数** | 总共几组 | 从4组到12组 |

**初学者（Level 0-1）：只调一个变量——时间。**
- 第一周：10秒工作/50秒休息 × 4组
- 第二周：10秒工作/50秒休息 × 6组（只调总组数）
- 第三周：15秒工作/50秒休息 × 6组（只调工作时间）
- 第四周：15秒工作/45秒休息 × 6组（只调休息时间）

## 第六章：训练周期化——不是给一份12周计划

### 6.1 周期性训练的核心决策树

```
你练了2-3周力量训练——

问自己：力量在上升还是停滞？
  ● 上升 → 继续当前模式
  ● 停滞 → 进入下一步

问自己：训练后48小时能恢复吗？
  ● 能 → 试试增加训练量（加组数/次数）
  ● 不能 → 减量一周（50%训练量）再回来

问自己：技术训练中力量有体现吗？
  ● 有 → 力量训练继续
  ● 没有 → 调整力量训练的动作模式，更接近技术动作

问自己：有没有疼痛？
  ● 无 → 正常训练
  ● 有（同一个位置连续3次训练都痛）→ 停掉这个动作，换替代动作
```

### 6.2 力量训练的4周周期模板（不是固定计划）

```
【第1周】适应期
目标：学会动作，建立神经连接
量：起始量的70%
强度：轻
感觉：应该觉得"太轻了"，而不是"好难"

【第2周】建立期
目标：稳定动作，增加肌肉耐力
量：起始量的85%
强度：中轻
感觉：稍微有点挑战，但能完成

【第3周】发展期
目标：力量增长
量：起始量的100%
强度：中
感觉：有挑战，最后2-3次需要努力

【第4周】巩固/减量期
目标：巩固胜利，恢复
量：起始量的50%
强度：轻到中
感觉：轻松，为下一周期蓄力

注意：这不是日历。如果你第1周做70%都觉得动作不稳定，
就维持在70%直到动作稳定，不要为了"按计划走"而加量。
```

## 第七章：精英运动员的体能特征与训练方法

### 7.1 精英羽毛球运动员的生理数据

> 以下数据来自 Phomsoupha & Laffaye (2015, *Sports Medicine*) 对国际级羽毛球运动员的系统综述。
> **理解这些数据的意义：它们告诉你"顶尖水平"的体能标准是什么样的。**

| 指标 | 精英男性 | 精英女性 | 业余男性 | 说明 |
|:-----|:--------:|:--------:|:--------:|:------|
| **VO₂max** (mL/kg/min) | 60-70 | 50-58 | 40-50 | 反映有氧耐力水平 |
| **无氧功率** (W/kg) | 14-16 | 10-12 | 8-10 | 反映爆发力水平 |
| **体脂率 (%)** | 8-12 | 15-20 | 15-25 | 反映身体成分 |
| **握力** (kg, 持拍手) | 45-55 | 30-38 | 30-40 | 反映前臂力量 |
| **垂直纵跳** (cm) | 55-65 | 40-50 | 35-45 | 反映下肢爆发力 |

> **VO₂max = 60-70 是什么概念？**
> 一般健康男性的 VO₂max 约 40-45。精英羽毛球运动员的数值接近马拉松运动员（70-80）的 85-90%，
> 这说明羽毛球是一项"有氧基础、无氧爆发"的运动——你必须有很强的有氧心肺才能在第3局还在跑。

### 7.2 羽毛球比赛的能量消耗结构

比赛中，你的身体不是"一直在跑"——是"冲一阵、歇一阵"：

```
一场精英级别的比赛（三局两胜）：
- 平均每分时长：7-15秒
- 每分间休息：25-35秒（捡球、发球准备）
- 实际运动时间占总时间的 20-30%（其余是间歇）
- 总时长：45-90分钟
- 总运动时间：15-25分钟
- 一场比赛消耗能量：约 600-800 kcal

间歇特征（关键训练依据）：
  │  工作（7-15秒）  →  休息（25-35秒）  →  工作
  │  85-95% HRmax    →  60-65% HRmax    →  再冲
  │  乳酸快速堆积    →  不完全清除        →  逐渐累积到第3局
```

> **这对训练设计的启示：**
> - 间歇训练的"工作:休息比"应该从 1:3（初学者）逐渐到 1:2（中级）再到 1:1（高级）
> - 单次工作长度从 10秒到 30秒——超过 30秒的全力冲刺在羽毛球中很少出现
> - 有氧基础（VO₂max）决定了你在第3局能不能"恢复得回来"

### 7.3 李宗伟的踝关节稳定性训练哲学

> 李宗伟的职业生涯以"步伐灵活、变向无痕"著称。
> 他的体能教练透露了一个关键细节：
> **"大部分球员练步伐时只练了'怎么移动'，李宗伟练了'怎么落地'。"**

**精英球员的踝关节训练要点：**

```
1. 落地控制优先于移动速度
   每次落地用前脚掌着地 → 膝盖对准脚尖 → 重心在足中
   不在地面上"砸"（全脚掌着地）→ 那会让力量被地面吸收，而不是被身体利用

2. 踝关节周围小肌群的训练
   不是只练小腿肌肉（腓肠肌/比目鱼肌）
   练：胫骨前肌（控制落地时脚掌的稳定性）
      腓骨长短肌（控制踝关节内外翻，防扭伤）

3. 李宗伟的训练中包含的踝关节练习：
   - 单腿跳→落地保持3秒稳定→再跳（20次/组）
   - 不稳定面（软垫/平衡垫）上的步伐练习
   - 赤足训练（在草地/软地上做步伐移动）
```

### 7.4 精英 vs 业余的体能训练差异

| 对比维度 | 业余常见做法 | 精英的做法 | 为什么精英不同 |
|:---------|:-------------|:-----------|:---------------|
| 有氧训练 | 慢跑30-40分钟 | 高强度间歇（10-30秒工作/间歇） | 羽毛球是间歇性运动，慢跑不模拟比赛能量结构 |
| 力量训练 | "增肌"导向（大重量、慢速） | "弹性"导向（中重量、快速、反应性） | 羽毛球的肌肉需要快速收缩和弹性回缩，不是最大收缩 |
| 训练频率 | 每周1-2次力量 | 每周3-4次分散在不同训练日 | 每次训练后神经系统需要恢复，高频低量的效果优于低频高量 |
| 预防训练 | 不痛不练 | 每天10-15分钟预防训练（肩/膝/踝） | 精英知道等痛了再处理已经晚了 |

> **核心差异一句话：业余练"能用就行"，精英练"能赢且不伤"。**
