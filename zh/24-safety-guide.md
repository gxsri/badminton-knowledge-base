# 训练安全边界指南

> **写给谁**：所有羽毛球爱好者、教练  
> **核心理念**：受伤不是训练的一部分。知道"什么情况下不练"和知道"练什么"同等重要  
> **参考来源**：NSCA训练安全指南、ACSM运动禁忌症、运动损伤急诊处理

---

## 第一章：训练前的安全自检——今天能不能练？

### 1.1 颈部自检

```
每天早上花30秒做这个检查：

☐ 头能不能正常左右转到最大范围？  是→继续  否→今天不训练
☐ 低头下巴能不能碰到锁骨？        是→继续  否→今天不训练
☐ 有没有脖子僵硬+发烧？           有→看医生  无→继续

如果以上任何一个"否"→ 今天不训练。
可能的原因：落枕/颈椎问题/感冒前兆。
休息1-2天，恢复后再练。
```

### 1.2 心脏安全筛查

```
如果你符合以下任何一条，在开始系统训练前请先看医生：

☐ 你有高血压/心脏病史
☐ 你直系亲属中有人在50岁前因心脏病去世
☐ 你在运动中有过胸闷/气短/晕眩/心跳异常
☐ 你超过40岁并且之前几乎没有运动习惯
```

### 1.3 训练前的身体扫描

```
每次训练前花1分钟做这个扫描：

① 当前有没有哪个部位在痛？
   □ 无痛 → 正常训练
   □ 有刺痛/锐痛 → 停掉这个部位的训练
   □ 有酸痛（昨天训练后的正常酸痛）→ 可以练，但热身要更充分

② 当前精力水平（1-10）？
   □ 5以上 → 正常训练
   □ 3-4 → 建议减量或做恢复训练
   □ 1-2 → 今天休息，不练

③ 昨晚睡眠质量？
   □ 7小时+ → 正常训练
   □ 5-6小时 → 减量
   □ <5小时 → 休息
```

## 第二章：急性损伤的RICE处理

### 2.1 RICE原则——受伤后第一时间做什么

```
羽毛球中最常见的急性损伤：崴脚、拉伤、撞伤。

受伤后立即执行RICE（不是继续打）：

R — Rest（休息）
  立即停止运动。不要"活动一下看能不能走"。
  继续运动会加重损伤。

I — Ice（冰敷）
  用冰袋/冰水混合物敷在受伤处
  每次15-20分钟
  每2-3小时一次
  不要直接把冰贴在皮肤上（隔一层毛巾）
  受伤后48小时内冰敷（不是热敷！）

C — Compression（加压）
  用弹性绷带包扎受伤部位
  不要包太紧（如果手指/脚趾变紫了 → 太紧了）
  目的是：减少肿胀

E — Elevation（抬高）
  把受伤部位抬高到心脏水平以上
  目的是：利用重力减少肿胀
```

### 2.2 什么时候该去医院

```
以下情况不要自己处理，直接去医院：

☐ 受伤时听到"啪"的响声
☐ 受伤部位完全不能承重/不能活动
☐ 受伤后30分钟内肿胀明显增大
☐ 受伤部位变形（和另一侧不一样了）
☐ 受伤后24小时疼痛没有减轻
☐ 受伤后有麻木感/刺痛感
```

### 2.3 48小时后的处理

```
48小时后：
  冰敷 → 可以换成热敷（促进血液循环）
  冰敷和热敷的区别：
    冰敷：适用于急性期（48小时内），目的是减少肿胀和疼痛
    热敷：适用于恢复期（48小时后），目的是促进血液循环和组织修复

  可以开始轻度活动（在不痛的范围内轻微活动）
  不要：完全不动（会导致关节僵硬）
  也不要：恢复到正常训练（过早负重会延长恢复期）
```

## 第三章：什么情况下绝对不能练

### 3.1 红色警报——立即停止训练

```
训练中出现以下任何一条，立即停止，不要等：

⚠️ 胸痛/胸闷     → 可能的心血管问题，立即就医
⚠️ 头晕/眼前发黑 → 大脑供血不足，坐下休息
⚠️ 关节"卡住"    → 可能是半月板/软骨问题
⚠️ 同一个位置连续3次训练都痛 → 不要"忍一下"，停
⚠️ 发烧（体温>37.5℃）→ 发烧时运动可能诱发心肌炎
```

### 3.2 黄色警报——需要减量

```
以下情况不要完全休息，但要减量：

🟡 前一天训练后还有明显酸痛（>72小时） → 减量50%
🟡 睡眠不足（<5小时）                  → 减量或做恢复训练
🟡 精神压力大/情绪低落                 → 减量，不要用训练发泄
🟡 轻微感冒症状（流鼻涕/喉咙痒）        → 减量50%（不发烧可以轻练）
  "颈线法则"：症状在脖子以上→可以轻练
              症状在脖子以下（胸闷/咳嗽/全身酸痛）→休息
```

### 3.3 女性特殊安全事项

```
🟡 月经期：如果出血量大+下腹痛，不练。不是"意志力问题"
🟡 排卵期前后：ACL损伤风险增高3-4倍，注意落地控制
   （详见 [21-女性训练专项](../zh/21-women-training.md) 第2章）
🟡 孕期：经医生许可后才能运动
   （本体系中的训练方案不适用于孕期）
```

## 第四章：重返运动的分级标准

### 4.1 五级重返流程

```
受伤后，不要跳过任何一级。

第一级：无痛日常活动（第1-3天）
  目标：走路/上下楼梯不痛
  检查：☐ 走路不痛  ☐ 上下楼不痛  ☐ 轻压不痛

第二级：无痛轻度训练（第4-7天）
  目标：可以做基础热身不痛
  检查：☐ 慢跑不痛  ☐ 动态拉伸不痛

第三级：无痛技术训练（第7-14天）
  目标：可以开始轻度技术训练
  检查：☐ 50%力量空挥不痛
        ☐ 定点高远球（不跑动）不痛

第四级：无痛全场训练（第14-21天）
  目标：可以恢复大部分训练内容
  检查：☐ 全场步伐不痛
        ☐ 70%强度对抗不痛

第五级：重返比赛（21天+）
  目标：可以正常比赛
  检查：☐ 100%强度训练不痛
        ☐ 比赛后疼痛没有加重
```

### 4.2 重返运动的"24小时规则"

```
重返每一级时，遵守"24小时规则"：

你今天做了第三级训练（50%力量空挥）→
24小时后检查：
  ☐ 训练部位没有疼痛加重 → 可以进入下一级
  ☐ 疼痛有加重 → 退回上一级，再等2天
  ☐ 疼痛明显加重（比训练前更痛）→ 退两级或看医生

这个规则防止了最常见的错误：
"今天练了不痛=我已经好了 → 明天大强度练 → 又伤了"
```

## 第五章：训练中的常见危险动作

| 危险动作 | 风险 | 替代方案 |
|:---------|:-----|:---------|
| 疲劳状态下跳杀落地 | 踝关节/膝关节扭伤 | 感觉到累了就停止跳杀，改打高远球 |
| 不热身直接打对抗 | 肌肉拉伤/关节扭伤 | 至少热身10分钟再打对抗（详见22-热身） |
| 用羽毛球鞋打篮球 | 崴脚（羽毛球鞋侧向支撑不适合篮球） | 篮球穿篮球鞋，羽毛球穿羽毛球鞋 |
| 断线了继续打 | 拍框变形/断裂 | 断线后立即剪线（从中间向四周剪） |
| 受伤后"活动一下看能不能走" | 加重损伤 | 受伤后不要动，立即RICE |
