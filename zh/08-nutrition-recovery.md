# 营养恢复与训练后恢复指南

> **写给谁**：教练和学员自己
> **核心理念**：营养方案不是食谱，是公式+原则。训练刺激身体，恢复让身体变强。
> **两部分**：第一部分讲营养计算，第二部分讲训练后恢复

# 第一部分：营养计算

## 第一章：能量——从计算开始

### 1.1 每日总能耗（TDEE）计算

一切营养方案的第一步，是算出你一天到底消耗多少热量。

**第一步：算基础代谢率 BMR**

公式（Mifflin-St Jeor，目前最准确）：

```
男性：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄 + 5
女性：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄 - 161
```

**举例：** 70kg男性，175cm，25岁
BMR = 10×70 + 6.25×175 - 5×25 + 5 = 700 + 1094 - 125 + 5 = **1674 kcal/天**

**第二步：乘活动系数得 TDEE**

| 活动水平 | 描述 | 系数 | 适用人群 |
|:---------|:-----|:----:|:---------|
| 久坐 | 几乎不运动 | 1.2 | 受伤恢复期 |
| 轻度 | 每周1-3次低强度训练 | 1.375 | Level 0-1 非训练日 |
| 中度 | 每周3-5次中强度训练 | 1.55 | Level 0-1 训练日 |
| 高度 | 每周6-7次高强度训练 | 1.725 | Level 2+ |
| 极高 | 每天2次训练/体力劳动者 | 1.9 | 专业运动员 |

**续上例：** 中度活动（1.55）
TDEE = 1674 × 1.55 = **2595 kcal/天**

### 1.2 根据目标调整能量摄入

| 目标 | 热量调整 | 说明 |
|:-----|:---------|:-----|
| 保持体重 | TDEE × 1.0 | 维持当前体重 |
| 减脂（慢速） | TDEE - 300kcal | 每周减0.25kg，适合赛季中 |
| 减脂（快速） | TDEE - 500kcal | 每周减0.5kg，适合休赛期 |
| 增肌（慢速） | TDEE + 200kcal | 干净增肌，适合赛季 |
| 增肌（快速） | TDEE + 500kcal | 适合休赛期/青少年生长期 |

**⚠️ 减脂底线：**
- 男性不低于 1500 kcal/天
- 女性不低于 1200 kcal/天
- 低于此线，代谢适应会大幅降低效果

## 第二章：三大营养素——按体重算

### 2.1 蛋白质：最简单也最重要

**计算公式：**

| 目标 | 蛋白质 g/kg体重/天 | 70kg人每天需要 |
|:-----|:-----------------:|:--------------:|
| 一般维持 | 1.2-1.6 g/kg | 84-112g |
| 增肌 | 1.6-2.0 g/kg | 112-140g |
| 减脂期（保留肌肉） | 2.0-2.4 g/kg | 140-168g |
| 青少年运动员 | 1.8-2.2 g/kg | 126-154g |

**分配原则（不是一次吃完）：**
- 每餐20-40g蛋白质（单次肌蛋白合成效率最高的区间）
- 训练后30分钟内补充20-30g快速吸收蛋白
- 睡前20-30g慢速蛋白（酪蛋白/酸奶）

**如何计算食物中的蛋白质：**
```
100g鸡胸肉  ≈ 31g蛋白质
1个全蛋     ≈ 6-7g蛋白质
100g三文鱼  ≈ 20g蛋白质
100g豆腐    ≈ 8g蛋白质
100g希腊酸奶 ≈ 10g蛋白质
1勺乳清蛋白 ≈ 25g蛋白质
```

**算出你自己的数字：**
```
你的体重：____ kg
你的目标：____（维持/增肌/减脂）
每kg需要：____ g
每天总蛋白质：____ × ____ = ____ g
分____餐：每餐约 ____ g
```

### 2.2 脂肪：不是敌人，看类型

**计算公式：**

| 目标 | 脂肪 g/kg体重/天 | 占热量比例 | 70kg人每天 |
|:-----|:----------------:|:----------:|:----------:|
| 一般 | 0.8-1.0 g/kg | 20-25% | 56-70g |
| 增肌 | 0.8-1.2 g/kg | 20-30% | 56-84g |
| 减脂 | 0.6-0.8 g/kg | 15-20% | 42-56g |

**脂肪类型比例：**
```
饱和脂肪（动物油、椰子油）：      ≤10% 总热量
单不饱和脂肪（橄榄油、牛油果）：   ≥10% 总热量
多不饱和脂肪（Omega-3/6，鱼油）：  ≥10% 总热量
反式脂肪：                       尽可能为0
```

**如何判断自己缺脂肪：**
- 皮肤干燥、关节响声增加
- 女性月经周期异常
- 训练恢复变慢
- 注意力难以集中

### 2.3 碳水化合物：最重要的训练燃料

**计算公式：**

| 训练强度 | 碳水 g/kg体重/天 | 70kg人每天 | 适用阶段 |
|:---------|:----------------:|:----------:|:---------|
| 低强度/休息日 | 2-3 g/kg | 140-210g | Level 0 休息日 |
| 中强度训练日 | 3-5 g/kg | 210-350g | Level 0-1 训练日 |
| 高强度训练日 | 5-7 g/kg | 350-490g | Level 2+ |
| 极高强度/2次训练 | 7-10 g/kg | 490-700g | 专业运动员 |

**碳水类型选择（按GI值/吸收速度）：**

| 时机 | 碳水类型 | GI值 | 例子 |
|:-----|:---------|:----:|:-----|
| 训练前2-3小时 | 低GI | <55 | 燕麦、全麦面包、红薯 |
| 训练前30分钟 | 中GI | 55-70 | 香蕉、全麦饼干 |
| 训练中（>60分钟） | 高GI快速补糖 | >70 | 运动饮料、葡萄糖凝胶 |
| 训练后30分钟内 | 高GI | >70 | 白米饭、土豆、蜂蜜 |
| 训练后1-2小时 | 中GI | 55-70 | 全麦意面、糙米 |

**⚠️ 关键原则（很多人搞反）：**
- **训练前**：低GI，提供稳定能量
- **训练后**：高GI，快速补充肌糖原
- **睡前**：低GI或不吃，避免血糖波动影响生长激素

### 2.4 实操：算出你自己的三大营养素分配

```
【你的个人信息】
体重：____ kg
训练日/休息日：____
目标：____

步骤1：算总热量
TDEE = ____ kcal
调整后 = ____ kcal

步骤2：先定蛋白质（最严格）
蛋白质 = 体重 × ____ g/kg = ____ g
蛋白质热量 = ____ × 4 = ____ kcal

步骤3：再定脂肪（第二严格）
脂肪 = 体重 × ____ g/kg = ____ g
脂肪热量 = ____ × 9 = ____ kcal

步骤4：剩下的给碳水
碳水热量 = 总热量 - 蛋白热量 - 脂肪热量 = ____ kcal
碳水量 = ____ ÷ 4 = ____ g
碳水量 ÷ 体重 = ____ g/kg ✅ 核对是否在合理范围内

【结果】训练日：
蛋白质 ____g · 脂肪 ____g · 碳水 ____g
总热量 ____ kcal
```

## 第三章：不同体型的策略差异

> ⚠️ **注意**：以下体型分类（外胚/中胚/内胚）源自 Sheldon (1940年代) 的体质学分类，
> 现代运动营养学指南（ACSM, ISSN）建议以实测数据（体重、体脂率、训练量）而非体型分类作为营养处方依据。
> **此处仅供参考**，实际方案应基于你的身体反馈调整。

### 3.1 三种体型分类（参考）

| 体型 | 特征 | 代谢特点 | 营养策略侧重 |
|:-----|:------|:---------|:-------------|
| **外胚型**（瘦长型） | 骨架小、体脂低、难长肉 | 代谢快，热量消耗大 | 碳水比例偏高（总量+），总热量+300 |
| **中胚型**（运动型） | 骨架适中、易长肌肉、容易减脂 | 代谢正常 | 按标准公式即可 |
| **内胚型**（丰满型） | 骨架大、易囤脂、长肌肉也不明显 | 代谢慢，对碳水敏感 | 碳水比例偏低，控制GI值，总热量-200 |

**如何判断：** 观察你的"自然状态"
- 年轻时不怎么运动也很瘦→外胚型
- 运动一下肌肉线条就出来了→中胚型
- 不吃也胖、减下来也容易反弹→内胚型

### 3.2 体型调整系数

| 调整项 | 外胚型 | 中胚型 | 内胚型 |
|:-------|:------:|:------:|:------:|
| 总热量调整 | +15-20% | 0% | -10% |
| 碳水比例 | 60% → 增加 | 50-55% | 40-45% |
| 脂肪比例 | 20% | 25% | 30-35% |
| 蛋白比例 | 20% | 20-25% | 25-30% |
| 碳水选择 | 低GI为主，偶尔高GI | 按时机选择 | 严格要求低GI |

## 第四章：训练周期中的营养调整

### 4.1 训练日 vs 休息日

不应该是同样的吃法。这是最大的误区。

| 项目 | 训练日 | 休息日 |
|:-----|:-------|:-------|
| 总热量 | TDEE + 消耗 | TDEE × 1.2（久坐系数） |
| 碳水 | 公式高限 | 公式低限（2g/kg也够） |
| 蛋白质 | 公式中限 | 公式低限 |
| 脂肪 | 公式低限 | 公式高限 |

**原则：训练日多碳水，休息日多脂肪。蛋白质不变。**

### 4.2 减量周（Deload Week）营养调整

减量周训练量降低50%，营养也应调整：

```
碳水：降低30%（少了那么多训练，不需要那么多燃料）
蛋白质：保持不变（修复仍需进行）
脂肪：略微增加（补充碳水的热量缺口）
总热量：减少20%（因为训练消耗也减少了）
```

### 4.3 赛季 vs 休赛期

| 阶段 | 目标 | 营养策略 |
|:-----|:-----|:---------|
| 休赛期（增肌期） | 增加瘦体重 | TDEE + 300-500，碳水高限 |
| 准备期（训练期） | 提高运动表现 | TDEE + 0-200，碳水按训练调整 |
| 赛季（比赛期） | 保持体重+表现 | TDEE + 0，碳水集中在比赛前后 |
| 过渡期（休整期） | 恢复+减脂 | TDEE - 300，碳水低限+高质量 |

## 第五章：营养素时机——不吃对等于没吃

### 5.1 训练前营养

| 时间 | 作用 | 吃什么 | 公式 |
|:-----|:-----|:-------|:-----|
| 训练前2-3小时 | 主餐，提供持续能量 | 低GI碳水 + 中等蛋白 + 低脂肪 | 碳水 1-2g/kg + 蛋白 0.3g/kg |
| 训练前30-60分钟 | 加餐，提升训练表现 | 中GI碳水 + 少量蛋白 | 碳水 0.3-0.5g/kg |
| 训练前10分钟内 | 快速能量 | 快速碳水（香蕉/葡萄糖） | 碳水 0.1-0.2g/kg |

**计算：70kg运动员，训练前2小时**
- 碳水：70 × 1.5 = 105g ≈ 1碗半燕麦 + 1根香蕉
- 蛋白：70 × 0.3 = 21g ≈ 1勺乳清蛋白或3个蛋清
- 脂肪：尽量少（脂肪消化慢，会拖累训练表现）

### 5.2 训练中营养

| 训练时长 | 需要补充吗 | 方案 |
|:---------|:----------|:-----|
| < 45分钟 | 不需要，喝水就行 | 每15分钟 150-200ml 水 |
| 45-75分钟 | 低强度不需要/高强度可补 | 运动饮料 300-500ml/小时 |
| > 75分钟 | 必须补充 | 30-60g碳水/小时 + 电解质 |

**运动饮料配方（自己调，省钱又好用）：**
```
1L 水
盐 0.5-1g（看出汗量，气温高就多）
蜂蜜或麦芽糊精 30-60g（看训练时长）
柠檬汁少许（调味+维生素C）
```

**为何自己调而不是买：**
- 市售运动饮料碳水浓度通常6-8%，太浓会影响水分吸收
- 你可以根据出汗量和训练时长调节盐和糖的比例
- 便宜10倍

### 5.3 训练后营养：黄金窗口

**事实与误区澄清：**
- "30分钟黄金窗口"：对于一天只练一次的业余爱好者，窗口是1-2小时，不是30分钟
- "立即喝蛋白粉"：如果你训练前2小时吃了正餐，训练后1小时内补碳水更重要
- 真正需要重视窗口的是：一天练2次、增肌期、或空腹训练后

**训练后补什么：**

| 成分 | 量 | 作用 | 来源 |
|:-----|:--:|:-----|:-----|
| 快速碳水 | 1-1.2g/kg体重 | 补肌糖原 | 白米饭、土豆、白面包、蜂蜜 |
| 快速蛋白 | 0.3-0.4g/kg体重 | 启动肌肉修复 | 乳清蛋白、蛋清、瘦肉 |
| 水分 | 减重×1.5倍 | 补液 | 清水/电解质水 |

**70kg训练后计算：**
- 碳水：70 × 1.2 = 84g ≈ 2碗白米饭
- 蛋白：70 × 0.4 = 28g ≈ 1勺乳清 + 1个蛋
- 水分：如果训练后体重轻了0.5kg → 0.5 × 1.5 = 750ml

## 第六章：减脂/增肌的周期化

### 6.1 减脂期的营养微调

减脂不是"少吃就行"，减的是脂肪不是肌肉。

**减脂期的蛋白质：不降反升**
```
平时：1.6g/kg
减脂：2.0-2.4g/kg（保护肌肉不被分解）
```

**减脂期的碳水：从训练周围砍**
```
不砍训练前后（这些是维持训练质量的）
砍睡前碳水和休息日碳水
先砍200kcal碳水试一周，不掉称再砍200
```

**减脂期监控指标：**
- 每周称一次体重（同一时间、同一条件）
- 每周量一次腰围
- 力量水平是否下降（力量掉太快 → 减太快了或蛋白不够）
- 训练后恢复是否变差

### 6.2 增肌期的营养要点

| 要点 | 说明 |
|:-----|:------|
| 热量盈余200-500kcal足够 | 超过500kcal/天，长的大半是脂肪不是肌肉 |
| 每kg体重增肌约需额外5000-7000kcal | 所以一个月长0.5-1kg纯肌肉已经算很好 |
| 蛋白质不是越多越好 | >2.2g/kg后增量效果递减 |
| 睡前的蛋白很重要 | 夜间是生长激素高峰，睡前20-30g酪蛋白 |

## 第七章：水合——精确计算

### 7.1 日常水合公式

```
基础需要：体重(kg) × 33ml
训练增加：训练时长(min) × 12ml
高温增加：环境温度 >30°C 时 +20%
```

**70kg运动员一天：**
- 基础：70 × 33 = 2310ml
- 训练60分钟：+ 720ml
- 总：约 3000ml

### 7.2 判断水合状态

| 方法 | 标准 |
|:-----|:------|
| 尿液颜色 | 淡柠檬色 = 良好；深黄色 = 缺水；无色 = 喝水过多 |
| 口渴感 | 感到口渴时已经缺水1-2%，不能等口渴再喝 |
| 训练前后体重差 | 每减重1kg → 需要1.5L水补回 |
| 皮肤弹性 | 捏手背皮肤，松开后回弹速度 |

### 7.3 电解质的补充条件

| 条件 | 需要补充电解质 | 不需要 |
|:-----|:--------------|:-------|
| 训练时长 | > 60分钟高强度 | < 60分钟 |
| 出汗量 | 明显出汗、衣服湿透 | 不出汗或微汗 |
| 环境温度 | > 28°C | < 25°C |
| 一天多次训练 | 每次训练后都需要 | 单次训练 |

## 第八章：常用营养素——按需计算用量

### 8.1 Omega-3（EPA+DHA）

**谁需要：** 所有运动员。Omega-3不是可选的，是必需的。

**计算用量：**

| 目的 | 剂量 | 70kg用量 |
|:-----|:----:|:---------|
| 维持神经健康 | 500mg EPA+DHA/天 | 同左 |
| 抗炎/恢复 | 1-2g EPA+DHA/天 | 同左 |
| 治疗级（医嘱） | 2-4g EPA+DHA/天 | 遵医嘱 |

**⚠️ 看标签方法：**
- 鱼油胶囊标签写"1000mg鱼油"不等于1000mg EPA+DHA
- 看背面："EPA 300mg / DHA 200mg" → 每粒有效500mg
- 你需要的是EPA+DHA的总量，不是鱼油总量

### 8.2 镁

**缺镁的症状自查表：**

| 症状 | 与镁的关系 |
|:-----|:-----------|
| 睡前难以放松 | 镁调节副交感神经 |
| 肌肉容易抽筋 | 镁参与肌肉收缩-放松循环 |
| 训练后恢复慢 | 镁参与ATP合成 |
| 睡眠质量差 | 镁促进深度睡眠 |
| 有2条以上 → 大概率缺镁 |

**计算用量：**

| 类型 | 剂量 | 服用时间 | 说明 |
|:-----|:----:|:---------|:-----|
| 维持 | 200mg/天 | 睡前 | — |
| 训练期 | 300-400mg/天 | 睡前 | 出汗会流失镁 |
| 纠正缺乏 | 400-600mg/天 | 分次服用 | 建议从低开始逐渐加 |

**不同类型镁的吸收率：**
```
甘氨酸镁：吸收率最高，对睡眠最好 ✅ 首选
柠檬酸镁：吸收好，有通便作用 ✓ 
氧化镁：吸收率最低（约4%），便宜但效果差 ✗ 
苏糖酸镁：可通过血脑屏障，最贵，对认知好
```

### 8.3 维生素D

**为什么对运动员重要：**
- 80%的人维生素D不足（尤其室内训练的）
- 维生素D不足会影响：肌肉力量、恢复速度、免疫力、骨密度

**计算用量：**

| 情况 | 剂量 | 说明 |
|:-----|:----:|:-----|
| 每天户外15分钟以上 | 1000IU/天 | 维持 |
| 室内训练为主（大多数） | 2000-3000IU/天 | 补充 |
| 检测显示缺乏 | 5000IU+/天 | 遵医嘱 |
| 冬季/北方 | 3000-5000IU/天 | 无法靠日晒 |

## 第九章：让学员自己动手——咨询模板

| 评估项 | 好 | 需调整 |
|:-------|:---|:-------|
| 训练表现 | 力量/耐力在上升或维持 | 持续下降 |

# 第二部分：训练后恢复

## 第一章：训练后的时间轴——24小时内该做什么

### 1.1 恢复不是"练完了休息"——是有时间线的

```
训练结束的那一刻，恢复就已经开始了。
不是你回到家躺下才开始，是你在场上放下拍子的那一刻。

24小时内，有几个关键的"恢复窗口"：

┌─────────────────────────────────────────────────────────┐
│  训练结束 → 30分钟内：营养窗口 + 整理拉伸               │
│  30分钟 → 2小时：正餐 + 补水                             │
│  2小时 → 睡前：轻度活动 + 筋膜放松 + 准备睡眠            │
│  睡觉（7-9小时）：生长激素分泌 + 组织修复 — 不可替代    │
│  第二天早上：评估恢复状态 → 决定今天的训练强度            │
└─────────────────────────────────────────────────────────┘
```

### 1.2 训练后立即（0-30分钟）

```
训练结束后的30分钟，是恢复的"黄金窗口"。

① 冷身（2-3分钟）
  慢跑/慢走，让心率从运动水平降到<100bpm
  不要突然坐下或躺下——血液会淤积在下肢，可能头晕

② 静态拉伸（5-8分钟）
  每个动作保持20-30秒，不要弹振
  优先拉伸：小腿后侧、大腿后侧、髋屈肌、胸肌、前臂
  → 详见 [22-热身与整理](22-warmup-cooldown.md) 第2章

③ 营养补充（训练后30分钟内完成）
  快速碳水：1-1.2g/kg体重（70kg→约84g = 2碗米饭）
  快速蛋白：0.3-0.4g/kg体重（70kg→约28g = 1勺乳清+1个蛋）
  水分：体重每减轻0.5kg → 补充750ml水
  → 详见 [08-营养恢复](08-nutrition-recovery.md) 第5章
```

### 1.3 训练后2小时内

```
① 正餐
  如果你在30分钟内补充了快速碳水和蛋白，
  这顿正餐可以正常吃（碳水+蛋白+蔬菜）

② 补水
  不要一次性喝大量水——分次喝
  判断标准：尿液颜色 — 淡黄色=补水到位 / 深黄色=继续喝 / 无色=水喝多了

③ 轻度活动（可选）
  如果感觉肌肉很紧，可以做一些轻度的活动（散步/慢骑自行车）
  不要完全不动——完全不动会让肌肉更僵硬
```

### 1.4 训练后睡前

```
① 筋膜放松（10-15分钟）
  用泡沫轴或筋膜球放松主要肌群
  顺序：小腿→大腿前侧→大腿外侧（髂胫束）→臀部→背部
  每个部位滚动30-60秒，找到酸痛点停留20秒
  → 详见 [22-热身与整理](22-warmup-cooldown.md) 第2.3节

② 热水澡/淋浴（不是冰水）
  温水促进血液循环，帮助代谢废物排出
  如果有特定部位特别酸痛，可以局部冷敷（15分钟）

③ 准备睡眠（睡前的30-60分钟）
  减少屏幕时间（蓝光抑制褪黑素分泌）
  房间温度：18-22℃（凉爽的环境有助于入睡）
  如果难以入睡：4-7-8呼吸法（吸气4秒→屏气7秒→呼气8秒）
  → 详见 [07-心理训练](07-psychological-training.md) 第6章
```

### 1.5 睡眠——最重要的恢复手段（不可替代）

```
没有任何恢复手段可以替代睡眠。
你吃再好的补剂、做再多的拉伸，睡不好，恢复就打折。

数据：
  睡眠<6小时 → 糖原合成效率下降30%
  睡眠<5小时 → 皮质醇升高 → 肌肉分解 → 脂肪堆积
  连续3天睡眠<6小时 → 反应速度下降15-20%（等于喝了2瓶啤酒）

羽毛球选手的睡眠建议：
  ☐ 每晚7-9小时
  ☐ 规律作息（每天同一时间睡+同一时间起）
  ☐ 睡前1小时不看手机/电脑
  ☐ 如果睡不着，不要躺着焦虑——起来看书/听音乐，困了再睡
```

## 第二章：为什么恢复能让身体变强——超量恢复原理

### 2.1 训练→恢复→变强，不是训练→变强

```
大多数人的理解：
  训练 → 变强 ✗

正确的理解：
  训练 → 身体变弱（肌肉纤维撕裂、糖原消耗）→ 休息 → 
  身体不仅恢复原状，还变得比之前更强一点点 → 变强 ✓

这个过程叫"超量恢复"（Supercompensation）。
```

**超量恢复曲线：**

```
       实力水平
         ↑
   超出原水平 ────→ 超量恢复（变强）
         ↑              ↑
    原水平 ──→ 训练后下降 ──→ 恢复期 ──→ 下次训练的最佳时机
         ↓
   低于原水平 ──→ 疲劳期（肌肉酸痛、糖原耗尽）
         
         ─────────────────────────────→ 时间
         ↑训练        ↑休息           ↑下次训练
```

### 2.2 关键结论——什么时候练下一课？

```
从超量恢复曲线可以得出一个关键结论：
  练得太频繁（还没恢复就练）→ 在疲劳期积累疲劳 → 过度训练
  练得太少（超量恢复消退后才练）→ 回到原点 → 没有进步
  练得时机对（超量恢复峰值时练）→ 每次都在变强

不同训练类型的恢复时间——决定了你的训练频率：

| 训练类型 | 恢复时间 | 建议频率 | 说明 |
|:---------|:--------:|:--------|:------|
| **纯技术训练**（多球/定点） | 4-8小时 | 每天都可以练 | 神经疲劳为主，身体消耗小 |
| **步伐训练** | 24-36小时 | 隔天练 | 下肢肌肉+神经系统的双重消耗 |
| **力量训练**（大重量） | 48-72小时 | 每周2-3次 | 肌肉纤维需要修复和重建 |
| **高强度间歇** | 48-72小时 | 每周2次 | 对神经系统和能量系统的双重消耗 |
| **对抗/比赛** | 48-72小时 | 每周1-2次 | 身体+心理的双重消耗 |
| **极限体能训练** | 72-96小时 | 每周1次 | 全身系统消耗 |

**混合训练的安排原则：**
  周一：力量训练（48-72小时后→周四再练力量）
  周二：技术训练（4-8小时后→周三可以再练技术）
  周三：步伐训练（24小时后→周五可以再练步伐）
  → 不同类型训练可以交替进行，不冲突
```

### 2.3 不要什么训练都等48小时

```
很多人的错误是："不管练了什么，都要休息一天再练。"
这是错的。

纯技术训练（比如定点高远球）对身体的消耗很小。
你不需要"等肌肉恢复"，因为肌肉几乎没被消耗。
你需要等的是"神经系统不疲劳了"——这通常只要几个小时。

所以：
  今天上午练了技术 → 下午可以再练（不同技术）
  今天练了力量 → 明天不要练同一个肌群
  今天打了比赛 → 休息24-48小时
```

## 第三章：怎么知道自己恢复好了

### 2.1 主观评估法（30秒自检）

```
每天早上起床后，花30秒做这个评估：

① 静息心率
  和正常值相比：□一样 □高了5次以上（高了→没恢复好）
  如果你有心率表，数据最客观

② 身体感觉
  □ 精力充沛、想动 → 恢复好了
  □ 不怎么想动、懒洋洋 → 还在恢复中
  □ 身体沉重、全身不想动 → 还没恢复好

③ 睡眠质量
  □ 睡了7小时+，醒来感觉休息好了
  □ 睡了但醒来还是累
  □ 没睡好（失眠/多梦/醒来多次）

④ 前一天的训练部位
  □ 没有明显感觉
  □ 有轻微酸痛但活动开了就消失了
  □ 有明显酸痛，不碰都疼
  □ 有刺痛/锐痛（和正常酸痛不一样——可能是伤）

评估结果：
  ①-④都正常 → 可以正常训练
  1-2项不正常 → 减量训练或做恢复训练
  3项以上不正常 → 休息一天
  有刺痛 → 停掉这个部位的训练 → [24-安全边界](24-safety-guide.md)
```

### 2.2 客观评估法（进阶使用）

```
如果你有心率表，可以每天早晨记录：

晨脉（静息心率）：
  连续记录7天，取平均值作为你的基准线
  如果某天晨脉比基准线高5次以上 → 没有完全恢复

心率变异性（HRV）：
  如果HRV比基准线显著下降 → 没有完全恢复
  （需要心率表支持）

睡眠时长：
  <6小时 × 连续2天 → 今天建议减量
```

### 2.3 恢复阶段判断

```
完全恢复（可以正常训练）：
  ☐ 晨脉正常
  ☐ 精力充沛
  ☐ 睡眠充足
  ☐ 没有酸痛

部分恢复（建议减量20-30%）：
  ☐ 晨脉偏高
  ☐ 感觉懒洋洋
  ☐ 有轻微酸痛

未恢复（建议休息或做恢复训练）：
  ☐ 晨脉明显偏高
  ☐ 全身沉重
  ☐ 酸痛明显
  ☐ 睡眠不足

⚠️ 疲劳累积警告：
  连续3天以上感觉"没有完全恢复" → 说明你的训练量超过了身体的恢复能力
  解决方案：安排2-3天的完全休息，或减量50%持续一周
```

## 第四章：恢复手段的真相

### 3.1 什么有用、什么时候用

| 手段 | 效果 | 什么时候用 | 怎么做 | 证据等级 |
|:-----|:-----|:-----------|:-------|:--------:|
| **睡眠** | ⭐⭐⭐ 最重要 | 每晚 | 7-9小时，规律作息 | 极强 |
| **营养补充** | ⭐⭐⭐ 训练后30分钟内 | 每次训练后 | 碳水+蛋白 | 极强 |
| **静态拉伸** | ⭐⭐ 减轻酸痛 | 训练后立即 | 每个动作20-30秒 | 中等 |
| **泡沫轴** | ⭐⭐ 减轻酸痛、改善活动度 | 训练后/休息日 | 每个部位30-60秒 | 中等 |
| **冷敷（冰敷）** | ⭐⭐ 减轻急性炎症 | 受伤后48小时内 | 每次15-20分钟 | 强 |
| **冷热水交替** | ⭐⭐ 促进血液循环 | 训练后/比赛后 | 热水1分+冷水30秒×3轮 | 中等 |
| **压缩袜/压缩裤** | ⭐ 可能减轻酸痛感 | 训练后/长途飞行 | 穿2-4小时 | 弱-中等 |
| **按摩** | ⭐⭐ 减轻酸痛、放松 | 训练后/休息日 | 专业按摩30-60分钟 | 中等 |
| **热敷/热水澡** | ⭐⭐ 放松肌肉 | 训练后2小时+ | 10-15分钟 | 中等 |
| **主动恢复** | ⭐⭐⭐ 促进血液循环 | 休息日 | 散步/游泳/骑车（低强度） | 强 |

### 3.2 常见误区

```
误区①："训练后越痛说明练得越有效"
  事实：极度酸痛≠效果好。可能是训练量超出身体适应能力。
       正常酸痛应该24-48小时内消退。超过72小时还在痛→量太大了。

误区②："每次训练后都要冰敷"
  事实：冰敷适用于急性损伤（48小时内）。
       常规训练后的酸痛，不需要冰敷。温水澡+拉伸效果更好。

误区③："恢复=躺着不动"
  事实：完全不动会让血液循环变慢，反而延长恢复时间。
       主动恢复（低强度活动）比被动恢复效果更好。

误区④："泡沫轴越痛越有效"
  事实：泡沫轴放松应该是"酸爽"不是"剧痛"。
       如果痛到肌肉不自主收缩——你按太重了，放松一点。

误区⑤："运动饮料是恢复必需品"
  事实：大多数业余训练（<60分钟）喝水就够了。
       只有高强度训练>75分钟或一天两练时，才需要运动饮料。
```

### 3.3 泡沫轴使用指南

```
泡沫轴是成本最低、最容易使用的恢复工具之一。
但很多人用错了。

正确用法：
  ① 每个部位滚动30-60秒
  ② 找到酸痛点后，停在那个点上深呼吸20秒（不是来回猛滚）
  ③ 整体力度：感觉"酸爽"不是"剧痛"
  ④ 不要在骨头上滚（膝盖、肘关节、脊柱）

滚动顺序（从下到上）：
  足底（用筋膜球）→ 小腿后侧 → 大腿前侧 → 大腿外侧（髂胫束）
  → 臀部 → 背部 → 前臂

什么时候滚：
  ✓ 训练后整理阶段（作为拉伸的补充）
  ✓ 休息日（促进血液循环）
  ✓ 感觉肌肉紧的时候

什么时候不要滚：
  ✗ 急性损伤期（48小时内）
  ✗ 有血肿/肿胀的部位
  ✗ 骨折/韧带撕裂未愈
```

## 第四章（续）：不同年龄段的恢复策略

### 4.1 年龄越大，恢复越慢——具体差多少

| 年龄段 | 力量训练恢复时间 | 高强度间歇恢复 | 技术训练恢复 | 建议调整 |
|:------|:---------------:|:--------------:|:-----------:|:---------|
| <25岁 | 24-48小时 | 24-36小时 | 4-6小时 | 正常训练即可 |
| 25-35岁 | 48-72小时 | 36-48小时 | 6-8小时 | 每4周安排减量周 |
| 35-45岁 | 72-96小时 | 48-72小时 | 8-12小时 | 减量周缩短到3周一次 |
| 45-55岁 | 96-120小时 | 72-96小时 | 12-24小时 | 增加恢复日，减少力量训练频率 |
| 55岁+ | 120+小时 | 96+小时 | 24+小时 | 以技术训练为主，力量训练每周1次 |

### 4.2 年龄增长后要做的调整

```
35岁以后，你的恢复策略需要主动调整——不是"扛不住"，
是"身体的需求变了"。

调整①：热身时间延长
  25岁：热身10分钟就够
  35岁：热身需要15分钟
  45岁+：热身需要20分钟以上
  原因：结缔组织的弹性和关节滑液分泌随年龄下降

调整②：力量训练频率降低，但每次质量不降
  25岁：一周3次力量
  35岁：一周2次力量（增加1次主动恢复）
  45岁+：一周1-2次力量（以稳定和耐力为主）

调整③：重视睡眠
  年龄越大，睡眠质量越容易下降
  如果自然睡眠不足7小时 → 午休20分钟补
  不要靠咖啡硬撑——咖啡因只会掩盖疲劳，不会消除疲劳

调整④：倾听身体的信号
  20岁时："有点累，但练一练就好了" ✓
  40岁时："有点累，但练一练就好了" ✗ → 可能是疲劳累积的信号
  年龄越大，越要重视"今天不想练"这个信号
```

## 第五章：比赛期间的恢复策略

### 4.1 多天比赛的恢复

```
比赛和训练不同——你不能"累了就减量"。
比赛必须全力以赴，但两场比赛之间你可以做很多。

比赛日之间的恢复工作流：

① 比赛结束后立即（0-30分钟）：
  补充碳水和蛋白（同训练后）
  开始补水（比赛中的减重×1.5倍）

② 回到住处后（1-2小时内）：
  冷热水交替淋浴（热水1分→冷水30秒→重复3轮）
  筋膜放松（重点放松比赛中使用最多的肌群）
  正餐（碳水为主）

③ 睡前：
  拉伸（重点：小腿、髋屈肌、肩部）
  确保睡眠环境凉爽
  如果肌肉特别酸痛 → 局部冷敷15分钟（再睡觉）

④ 第二天赛前：
  动态热身时间比平时延长5分钟
  检查恢复状态（晨脉）→ 调整当天战术（体能下降就多打控制）
```

### 4.2 一天多场比赛

```
如果你一天打2-3场比赛：

第一场和第二场之间（如果有间隔）：
  □ 立即补充碳水和蛋白（香蕉+乳清蛋白是最方便的）
  □ 换干衣服（湿衣服会加速疲劳）
  □ 用泡沫轴快速放松（5分钟，重点放松比赛肌肉）
  □ 抬高双腿休息（10-15分钟）
  □ 不要睡着（20分钟以上的睡眠会让你醒来后更困）

第二场和第三场之间：
  □ 重复以上流程
  □ 如果感觉疲劳明显 → 调整战术（减少不必要的跑动）
```

### 4.3 比赛后的全面恢复

```
比赛全部结束后——大多数人的错误是"终于打完了，吃顿好的就完事了"。

比赛后的48小时是身体修复的关键期：

比赛后当天：
  □ 营养补充（比训练后多20%的碳水）
  □ 温水澡+拉伸
  □ 早点睡觉

比赛后第1天（主动恢复日）：
  □ 不要完全躺着不动
  □ 轻度活动（散步30分钟/游泳/骑车）
  □ 如果特别酸痛 → 可以泡沫轴放松
  □ 正常饮食+多喝水

比赛后第2天：
  □ 评估恢复状态
  □ 如果恢复了 → 可以开始轻度训练
  □ 如果还没恢复 → 继续主动恢复一天
```

## 第五章（续）：心理恢复——被忽视的一半

### 5.1 心理疲劳和身体疲劳是两回事

```
身体疲劳：肌肉酸痛、没力气 → 睡一觉能恢复大半
心理疲劳：不想动、对训练失去兴趣、注意力无法集中
  → 睡一觉不一定能恢复

心理疲劳的典型信号：
  ☐ 训练时频繁看手机/看时间
  ☐ 对训练内容提不起兴趣
  ☐ 训练质量下降但身体不累
  ☐ 想到"今天要训练"就觉得烦
  ☐ 以前能轻松完成的训练现在觉得"好难"

如果你有3条以上符合 → 你的问题不是身体疲劳，是心理疲劳。
```

### 5.2 心理恢复的方法

```
① 换训练内容（不是不练，是换着练）
  如果你对高远球练习感到厌倦：
  ✗ 强迫自己继续练高远球（质量越来越差）
  ✓ 换成打比赛、练步伐、或者练体能
  换了内容后，心理疲劳感通常会消失

② 减量不减频（保留习惯，降低强度）
  如果你不想去球场：
  ✗ 强迫自己去（去了也练不好）
  ✓ 告诉自己"去热热身就行，打不好就回家"
  到了球场后，通常不会只热身——心理的"入场障碍"比身体更大

③ 训练伙伴（最有用的心理恢复工具）
  一个人训练时最容易放弃
  有伙伴在：你不想练也会去 → 去了就能练好
  如果你发现自己频繁不想练 → 找一个训练伙伴

④ 完全断开（终极方案）
  如果以上方法都无效 → 说明你需要一次真正的"断联"
  完全不碰球拍3-7天
  这期间不要看羽毛球视频、不要想训练的事
  通常3天后你会开始"想打球"——这才是恢复好了的信号
```

## 第六章：一周恢复计划模板

### 5.1 恢复不是"不用练的那天"——是"主动恢复的那天"

```
大多数人的一周：
  练练练 → 累了 → 休息 → 练练练 → 累了 → 休息

正确的一周：
  练 → 恢复 → 练 → 练 → 恢复 → 练 → 完全休息
```

### 5.2 一周恢复安排模板

```
周一：训练日
  训练后：拉伸+营养补充+泡沫轴（15分钟）

周二：训练日
  训练后：拉伸+营养补充
  睡前：热水澡

周三：主动恢复日
  上午：散步30分钟或游泳20分钟
  下午：泡沫轴放松（全身15-20分钟）
  晚上：早点睡（争取8小时以上）

周四：训练日
  训练后：拉伸+营养补充+泡沫轴

周五：训练日
  训练后：拉伸+营养补充

周六：比赛/对抗日
  比赛后：营养补充+冷热水交替+拉伸+早睡

周日：完全休息日
  不做任何训练
  可以轻度散步，但不需要"刻意恢复"
  让身体自然修复
```

### 5.3 恢复的"二八法则"

```
80%的恢复效果来自三件事：
  ① 睡眠（7-9小时/晚）
  ② 营养（训练后30分钟内补充碳水和蛋白）
  ③ 主动活动（不是躺着不动）

20%的恢复效果来自各种手段：
  泡沫轴、冰敷、按摩、压缩袜等

先做好80%，再考虑20%。
不要花100块钱买压缩袜，但每天只睡6小时——顺序搞反了。
```
