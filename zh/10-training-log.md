### 3.3 Level 0 毕业评估

完成4周训练后，评估以下标准：

| 评估维度 | 评估方法 | 达标标准 | 结果 |
|:---------|:---------|:--------:|:----:|
| 神经肌肉控制 | 单腿下蹲稳定性 | 膝盖不内扣，骨盆稳定 | □ 达标 □ 未达标 |
| 动力链效率 | 药球投掷（2kg） | 全身协调发力流畅 | □ 达标 □ 未达标 |
| 基础力量 | 自重深蹲 | 30次以上，动作标准 | □ 达标 □ 未达标 |
| 核心耐力 | 平板支撑 | 60秒以上 | □ 达标 □ 未达标 |
| 心理准备 | 自我评估 | 注意力自评≥6/10 | □ 达标 □ 未达标 |
| 出勤率 | 4周训练记录 | 至少完成12次训练 | □ 达标 □ 未达标 |

**总评：**
- □ **全部达标** → 可进入 Level 1 训练
- □ **大部分达标（4-5项）** → 可进入 Level 1，但需继续强化薄弱项
- □ **未达标（≤3项）** → 建议重复Level 0，重点训练未达标项目

| 睡眠质量如何？ | /10 | |
| 训练后的疲劳恢复情况？ | /10 | |

| 有无关节不适？ | /10 | (1=无 10=严重) |

| 饮食规律性？ | /10 | |

**评分规则：**
- 总分 > 50/70：状态良好，可正常训练
- 总分 35-50/70：注意恢复，适当减量
- 总分 < 35/70：建议休息或就医

---

## 六、使用说明

1. **每日训练日志** — 每次训练后填写，不超过5分钟
2. **每周评估** — 每周日填写，回顾一周训练（10分钟）
3. **Level阶段评估** — 每个Level开始和结束时填写
4. **月度总结** — 每月底填写（15分钟）
5. **身体状态自评** — 每周一次，在周评估中同步完成

> **提示**：这些日志模板可以打印出来使用，也可以复制到笔记软件中。坚持记录是进步最快的方式。
