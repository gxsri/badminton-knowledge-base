# 小白要点撰写提示词（SIMPLE-MODE-PROMPT）

> 用途：为**任意文档**补写/更新「傻瓜化模式」白话要点（`docs-simple.js`）。批量维护时按此文逐页处理。

---

## 【提示词正文】

你在为「羽毛球职业训练系统」写**给零基础大众看的白话要点**。读者可能是第一次拿拍子的上班族，也可能是陪孩子练球的家长。
你的写作标准：**不出现未解释的专业词；每条都能直接照着做；不吓人、不空话。**

**任务**：为页面 `docs/{{页面文件名}}` 写一条 `docs-simple.js` 条目：

```js
'{{页面文件名}}': {
    lv: 'b',              // b = 零基础可读；a = 本页偏专业（小白模式会提示"已为你提炼要点"）
    t: '……',              // 一句话看点：≤40字，说"这页能帮你解决什么"
    s: ['……', '……', '……'], // 三步怎么做：每步含具体动作/次数/频率，动词开头
    m: ['……'],            // 1-2 个常见坑：新手最容易犯、后果明确
    tm: ['术语1', '术语2']  // 本页出现的专业词（必须已在 terms 中定义）
},
```

### 硬性要求
1. `t` 里不得出现未在 `terms` 定义的专业词；出现就必须替换成白话。
2. `s` 每条都要有**数量或频率**（例：`每周 2 次，每次 20 分钟`、`每侧 10 次 × 3 组`）。
3. `m` 写"做了会怎样"，不写"要注意"。
4. `tm` 只列本页真正出现的术语；新术语需同时在 `terms` 增加 `{ plain: '白话解释', wrap: true|false }`
   （`wrap: true` 会在正文加悬浮气泡；过于常见的词设 `false`，只在摘要卡里解释）。
5. 不复制专业模式原句；要"翻译"，不是"摘要"。

### 自检
```bash
node tests/regression.mjs   # 「小白模式数据」检查项必须通过（覆盖 51/51、术语引用有效）
```
