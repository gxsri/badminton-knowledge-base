🎯 目标

实现技术自动化，能够在高速下稳定执行。掌握技术变化，建立简单战术意识。

核心理念：这个阶段是"从会打到打好"的过渡期。技术需要在实战中反复应用，形成肌肉记忆。

🏸 技术进阶

训练1：网前搓球
组数：3组 次数：30次/组 频率：隔天
  1. 放松握拍，靠手指控制
  2. 击球点在网前最高点
  3. 拍面切削球托侧面
  4. 轻柔发力，靠手感

关键：抢高点，动作小，手感细腻。

训练2：反手技术
组数：3组 次数：20次/组 频率：隔天
  1. 握拍转换：拇指顶到拍柄宽面
  2. 发力：拇指顶推+手腕外旋
  3. 击球点：身体侧前方
  4. 落点控制：后场两角

常见错误：只用手腕甩，没有用拇指顶推。

训练3：假动作入门
组数：2组 次数：15次/组 频率：每周2次
  1. 动作一致性：准备动作相同
  2. 出手变化：最后时刻改变拍面
  3. 节奏变化：快慢结合
  4. 落点变化：调动对手

🧠 战术意识

训练4：单一战术套路
组数：3组 时间：5分钟/组 频率：每周2次
  1. 高远球+吊球组合
  2. 后场两角调动
  3. 网前+后场结合
  4. 杀球+吊球变化

目标：建立2-3个常用的战术套路。
