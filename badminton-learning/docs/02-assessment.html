02

基线评估

5个测试 · 5分钟完成 · 了解你的起点

为什么要做基线评估？了解你的当前水平，才能制定合适的训练计划。每个月重测一次，追踪你的进步。

📝 5个核心测试

1
单足站立（本体感觉）
测试方法
  1. 赤足站立，双手叉腰
  2. 抬起一只脚，开始计时
  3. 支撑脚移动/落地/手松开即停止
  4. 每侧3次，取最好成绩
分数睁眼标准闭眼标准
4分>60秒>30秒
3分30-60秒10-30秒
2分10-30秒3-10秒
1分<10秒<3秒
2
死虫式（核心稳定性）
测试方法
  1. 仰卧，手脚举起朝天
  2. 呼气时对侧手脚伸直（不落地）
  3. 吸气时还原
  4. 节奏：2秒出，2秒回
  5. 做到动作变形为止
分数标准
4分>25次标准动作
3分15-25次
2分8-15次
1分<8次
3
单腿下蹲（下肢控制）
测试方法
  1. 单腿站立，双手前平举
  2. 慢速下蹲至膝盖约90度
  3. 全程膝盖对准第二脚趾
  4. 记录能做多少次不晃
分数标准
4分>10次不晃
3分5-10次
2分1-5次
1分做不到或晃动明显
4
俯卧撑（上肢力量）
测试方法
  1. 标准俯卧撑姿势
  2. 下降至胸部接近地面
  3. 推起至手臂伸直
  4. 做到动作变形为止
分数男性标准女性标准
4分>30次>20次
3分20-30次12-20次
2分10-20次5-12次
1分<10次<5次
5
肩关节活动度（灵活性）
测试方法
  1. 站立，一手从上方、一手从下方
  2. 双手在背后尽量靠近
  3. 测量两手中指间的距离
分数标准
4分双手能触碰或重叠
3分距离<5cm
2分距离5-15cm
1分距离>15cm
