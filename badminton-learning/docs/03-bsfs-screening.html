BSFS v1.0

羽毛球专项功能筛查

Badminton-Specific Functional Screening · 6个测试 · 10分钟完成 · 每月重测

为什么要做功能筛查？识别身体薄弱环节，预防运动损伤，制定个性化训练计划。这个筛查专门为羽毛球运动设计，比通用筛查更有效。

📋 6个核心测试

1
动态平衡测试（Y-Balance）
评估下肢动态平衡和稳定性
测试方法
  1. 单腿站立，双手叉腰
  2. 另一腿分别向前、后内、后外三个方向伸展
  3. 记录每个方向的最大伸展距离（厘米）
  4. 计算：(前方+后内+后外)÷(3×腿长)×100
分数标准羽毛球关联
3分>90%步法稳定，变向灵活
2分80-90%步法基本稳定
1分70-80%步法需要加强
0分<70%步法不稳定，需康复
2
单腿跳跃测试
评估下肢爆发力和稳定性
测试方法
  1. 单腿站立，向前跳跃
  2. 测量跳跃距离（厘米）
  3. 计算：跳跃距离÷腿长
  4. 每侧3次，取最好成绩
分数标准羽毛球关联
3分>1.5起跳有力，杀球有力量
2分1.3-1.5起跳能力正常
1分1.1-1.3起跳需要加强
0分<1.1起跳能力弱
3
侧向移动测试
评估侧向移动能力
测试方法
  1. 双脚并拢，站在一条线旁边
  2. 侧向跳跃过线，再跳回来
  3. 记录30秒内跳跃次数
  4. 计算：总次数×2（换算成每分钟）
分数标准羽毛球关联
3分>80次/分钟侧向移动快，防守好
2分60-80次/分钟侧向移动正常
1分40-60次/分钟侧向移动需要加强
0分<40次/分钟侧向移动慢
4
肩关节稳定性测试
评估肩关节稳定性
测试方法
  1. 双手举过头顶，保持平衡
  2. 另一人轻推其手臂
  3. 观察是否能保持稳定
  4. 双侧都测
分数标准羽毛球关联
3分完全稳定击球稳定，不易受伤
2分轻微晃动击球基本稳定
1分明显不稳定需要肩袖强化训练
5
核心耐力测试（侧桥）
评估核心耐力
测试方法
  1. 侧桥姿势，身体成一条直线
  2. 记录保持时间
  3. 双侧都测，取较差值
分数标准羽毛球关联
3分>60秒核心稳定，力量传递好
2分45-60秒核心耐力正常
1分30-45秒核心需要加强
0分<30秒核心耐力差
6
髋关节灵活性测试（Thomas Test）
评估髋屈肌柔韧性
测试方法
  1. 仰卧在桌子边缘，一腿抱向胸口
  2. 另一腿自然下垂
  3. 观察大腿是否能接触桌面
分数标准羽毛球关联
3分正常步法幅度大，弓步深
2分轻度紧张步法幅度正常
1分明显紧张需要拉伸训练
