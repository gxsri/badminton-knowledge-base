比赛指南

比赛准备流程

赛前准备 → 赛中执行 → 赛后恢复 · 完整的比赛流程

比赛是训练的检验。正确的比赛准备和恢复流程，能让你在比赛中发挥最佳水平，并为下一场比赛做好准备。

📅 赛前准备

📋
赛前24小时
准备工作和心理调整
  • 整理装备（球拍、球线、球鞋、手胶）
  • 检查比赛信息（时间、地点、对手）
  • 制定比赛策略（针对对手特点）
  • 保证7-9小时睡眠
  • 避免新食物或补充剂
  • 保持正常作息，不要熬夜
🍎
赛前营养
为比赛储备能量
赛前2-3小时
低GI碳水 + 中等蛋白 + 低脂肪（如：燕麦+鸡蛋+香蕉）
赛前1小时
中GI碳水 + 少量蛋白（如：全麦面包+花生酱）
赛前15分钟
快速碳水（如：香蕉、运动饮料）

比赛前30-45分钟
30-25分钟前

深呼吸，调整心态，准备上场

🏸 赛中执行

⚡
比赛策略
执行战术，保持专注
  • 执行赛前制定的战术
  • 专注每一球，不想上一球的失误
  • 观察对手的习惯和弱点
  • 保持稳定的呼吸节奏
  • 局间休息时补水和能量
⏸️

🔄 赛后恢复

💧
赛后即时恢复（0-30分钟）
黄金恢复窗口
  • 慢走2-3分钟，让心率下降
  • 补充碳水（1-1.2g/kg体重）
  • 补充蛋白质（0.3-0.4g/kg体重）
  • 补水（减重×1.5倍）
  • 静态拉伸（每个动作30秒）
🍜
赛后2小时
正餐和继续恢复
  • 吃正餐（碳水+蛋白+蔬菜）
  • 继续补水
  • 轻度活动（散步）
  • 筋膜放松（泡沫轴10分钟）
😴
赛后睡前
促进恢复的睡眠
  • 热水澡（促进血液循环）
  • 如有疼痛，冰敷15分钟
  • 补充镁元素（帮助睡眠）
  • 保证7-9小时睡眠

多日比赛恢复：如果连续比赛，第二天要做主动恢复（散步、游泳、骑车），不要完全休息。完全不动会让肌肉更僵硬。
