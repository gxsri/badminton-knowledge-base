Level 2

技术入门

6-12个月 · 掌握基础击球技术，建立步法连贯性

🎯 目标

掌握正手高远球、吊球、杀球，建立基本步法体系，理解简单战术。

核心理念：这个阶段是"学会打球"的关键期。技术动作必须标准化，为以后的提高打下基础。

🏸 技术训练

训练1：正手高远球（7步分解）
组数：4组 次数：50次/组 频率：每天
  1. 准备姿势：侧身对网，双脚与肩同宽
  2. 引拍后拉：大臂外展，肘弯曲90度
  3. 蹬地转体：后脚蹬地，髋关节先转
  4. 肩部内旋：躯干带动肩关节内旋
  5. 前臂旋内+闪腕：产生"鞭打"效果
  6. 击球点：身体右前上方，手臂接近伸直
  7. 随挥收拍：自然向左下方随挥

关键：力量从地面开始，通过下肢→核心→上肢传递。

训练2：吊球技术
组数：3组 次数：30次/组 频率：隔天
  1. 准备动作与高远球相同
  2. 击球瞬间减速
  3. 拍面稍后仰，切削球托底部
  4. 落点在对方前场，贴网下落

变化：轻吊、劈吊、拦吊三种。

训练3：杀球技术
组数：3组 次数：20次/组 频率：隔天
  1. 双脚起跳，身体后仰成弓形
  2. 击球点在身体前上方
  3. 全身协调发力
  4. 落点在对方身体或边线附近

检查点：是否用全身发力？击球点是否够高？

👟 步法训练

训练4：启动步
组数：3组 次数：20次/组 频率：每天
  1. 准备姿势：双脚与肩同宽，膝盖微曲
  2. 小跳蓄力：对手击球瞬间，双脚离地2-3cm
  3. 落地蹬出：根据来球方向，异侧脚蹬地

关键：小跳要轻，落地要稳，蹬出要快。

训练5：全场4点移动
组数：4组 时间：30秒/组 频率：隔天
  1. 从中心位置出发
  2. 移动到前场左、前场右、后场左、后场右
  3. 每次移动后回中
  4. 计时，目标<4秒
