Level 1

基础建立

3-6个月 · 固化基础动作模式，建立关节稳定性
学习进度
0/10 完成

🎯 目标

在3个月内，固化基础动作模式，建立关节稳定性和基础力量，为技术学习打好基础。

核心理念：这个阶段的重点是"学会正确动作"，而不是"练出肌肉"。动作质量永远第一位。

🏋️ 训练内容

训练1：俯卧撑（上肢力量）
组数：3组 次数：8-15次 频率：隔天
  1. 双手撑地，与肩同宽
  2. 身体成一条直线
  3. 下降至胸部接近地面
  4. 推起至手臂伸直

进阶：跪姿俯卧撑 → 标准俯卧撑 → 击掌俯卧撑

训练2：深蹲（下肢力量）
组数：3组 次数：15-20次 频率：隔天
  1. 双脚与肩同宽
  2. 臀部向后坐，膝盖弯曲
  3. 下蹲至大腿平行地面
  4. 蹬地站起

检查点：膝盖是否超过脚尖？背部是否挺直？

训练3：平板支撑（核心耐力）
组数：3组 时间：60-90秒 频率：每天
  1. 前臂撑地，手肘在肩膀正下方
  2. 身体成一条直线
  3. 收紧腹部，保持呼吸
  4. 不要塌腰或弓背

进阶：标准平板 → 侧平板 → 动态平板

训练4：弹力带行走（臀中肌激活）
组数：2组 次数：每侧10步 频率：每次训练前
  1. 弹力带套在脚踝
  2. 微蹲姿势
  3. 向侧面行走
  4. 保持弹力带张力

检查点：是否用臀部发力？膝盖是否内扣？
