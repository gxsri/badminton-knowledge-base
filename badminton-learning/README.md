# 羽毛球职业训练系统

基于NSCA CSCS认证体系，从零基础到职业水平的完整训练系统。

## 🎯 目标

让读者通过自学达到职业选手水平，覆盖技术、体能、战术、心理、营养、康复全流程。

## 📚 内容结构

### 核心框架
- **00-quickstart.html** - 快速开始（5分钟了解全貌）
- **01-philosophy.html** - 训练哲学（四个核心原则）
- **02-assessment.html** - 基线评估（5个测试）

### 8级训练体系
- **Level 0** - 零基础启蒙（0-3个月）
- **Level 1** - 基础建立（3-6个月）
- **Level 2** - 技术入门（6-12个月）
- **Level 3** - 技术熟练（1-2年）
- **Level 4** - 技术精进（2-3年）
- **Level 5** - 战术应用（3-4年）
- **Level 6** - 准专业（4-5年）
- **Level 7** - 职业水平（5年+）

### 专项内容
- **08-nutrition-recovery.html** - 营养与恢复（交互式计算器）
- **09-strength-conditioning.html** - 力量体能
- **11-footwork.html** - 步伐训练
- **15-technique-analysis.html** - 技术全解析
- **17-anatomy-rehabilitation.html** - 运动解剖与康复

### 实用工具
- **20-error-correction.html** - 纠错指南（单独文档）
- **25-safety-checklist.html** - 训练前安全检查
- **26-sleep-optimization.html** - 睡眠优化指南
- **27-competition-prep.html** - 比赛准备流程
- **03-bsfs-screening.html** - 羽毛球专项功能筛查
- **29-level-locator.html** - 级别定位器
- **30-achievements.html** - 成就系统
- **31-search.html** - 全文搜索

## 🛠️ 技术栈

- 纯HTML/CSS/JavaScript（无框架依赖）
- Chart.js（数据可视化）
- localStorage（本地数据存储）
- 响应式设计（支持移动端）

## 🚀 快速开始

1. 克隆仓库：`git clone https://github.com/gxsri/badminton-learning.git`
2. 打开 `index.html` 即可使用
3. 无需安装任何依赖

## 📱 功能特性

- ✅ 8级渐进式训练体系
- ✅ 交互式计算器（TDEE、营养素、水合等）
- ✅ 级别定位器（快速确定起始级别）
- ✅ 成就系统（激励持续训练）
- ✅ 全文搜索（快速找到内容）
- ✅ 训练进度追踪（localStorage）
- ✅ 移动端适配
- ✅ 打印友好

## 📊 数据说明

所有训练数据存储在浏览器本地（localStorage），清除浏览器数据会丢失进度。建议定期截图保存重要数据。
