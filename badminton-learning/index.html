训练哲学 — 四个不变的原则

不管你是15岁还是50岁，零基础还是复训，以下四个原则不变。

⚡ 核心原则

原则 为什么 什么不能做
动作质量 > 训练数量 神经肌肉系统记住的是你重复最多的模式，练错的动作重复100次=巩固100次错误 不能用"做了多少次"衡量训练效果
神经肌肉控制 > 力量输出 神经系统先学会控制肌肉，肌肉才能发力。顺序不能反 不能在动作模式不稳定时加重量
预防损伤 > 追求表现 一次受伤=倒退回起点，恢复时间往往是训练时间的3-10倍 不能在疲劳状态下冲击极限
长期发展 > 短期进步 神经系统适应需要4-6周，结缔组织初步适应约8-12周 不能每周都加量

这四个原则不是建议，是底线。任何训练安排必须同时满足四条才能执行。

Nutrition

营养计算速查

🔥 TDEE计算

男性 BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄 + 5 女性 BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄 - 161 TDEE = BMR × 活动系数 久坐 = 1.2 轻度 = 1.375（每周1-3次低强度） 中度 = 1.55（每周3-5次中强度） 高度 = 1.725（每周6-7次高强度）

🥩 三大营养素公式

蛋白质： 维持 = 1.2-1.6 g/kg 增肌 = 1.6-2.0 g/kg 减脂 = 2.0-2.4 g/kg 脂肪： 一般 = 0.8-1.0 g/kg（占热量20-25%） 碳水： 休息日 = 2-3 g/kg 训练日 = 3-5 g/kg 高强度 = 5-7 g/kg 分配原则：每餐20-40g蛋白质，训练后30分钟内补充20-30g快速吸收蛋白

💧 水合公式

日常需要 = 体重(kg) × 33ml 训练增加 = 训练时长(min) × 12ml 高温增加 = 温度>30°C时 +20% 判断水合：尿液淡柠檬色=良好，深黄色=缺水
Recovery

恢复时间轴

训练刺激身体，恢复让身体变强。没有恢复就没有进步。

⏰ 训练后24小时恢复指南

0-30分钟：营养窗口 + 整理拉伸 → 快速碳水 1-1.2g/kg + 快速蛋白 0.3-0.4g/kg 30分钟-2小时：正餐 + 补水 → 碳水+蛋白+蔬菜，分次补水 2小时-睡前：轻度活动 + 筋膜放松 → 泡沫轴全身10-15分钟，热水澡 睡觉（7-9小时）：生长激素分泌 + 组织修复 → 不可替代，最重要的恢复手段 第二天早上：评估恢复状态 → 决定今天训练强度

🔄 不同训练类型的恢复时间

训练类型 恢复时间 建议频率
纯技术训练 4-8小时 每天都可以练
步伐训练 24-36小时 隔天练
力量训练 48-72小时 每周2-3次
高强度间歇 48-72小时 每周2次
对抗/比赛 48-72小时 每周1-2次
