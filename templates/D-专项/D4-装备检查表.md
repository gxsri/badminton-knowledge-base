# D4 每周装备检查清单

> **配套**：20-装备选择指南  
> **用法**：每周打球前看一遍，防止到了球场发现没带东西

╔═══════════════════════════════════════════════╗
║          每周装备检查清单                      ║
║  姓名：________  检查日期：________           ║
╚═══════════════════════════════════════════════╝

## □ 球拍

```
带了几把拍：____把
  主拍：线还好吗？ □好 □该换了（上次穿线：____月____日）
  备用拍：有吗？ □有 □没有（建议至少1把备用）
  拍框：有裂吗？ □无 □有（有裂的不要打了）
```

## □ 球鞋

```
鞋底磨平了吗？
  □ 没有，还能打
  □ 已经磨了（主要磨的位置：________）
    该换了吗？ □还能再打1-2个月 □该换了

鞋带：□好的 □该换了
鞋垫：□好的 □该换了
```

## □ 手胶

```
主拍手胶：□上周刚换 □还行 □该换了
备用拍手胶：□好的 □该换了
包里备用胶：□有 □没有
```

## □ 服装

```
√ 运动T恤   □有 □没有
√ 运动短裤  □有 □没有
√ 运动内衣(女)□有 □没有  → 是否高强度支撑？□是 □否
√ 袜子      □有 □没有（羽毛球专用袜更好）
```

## □ 护具

```
□ 护膝（如有需要）
□ 护腕（擦汗用）
□ 护踝（如有需要）
□ 绷带/肌贴（如有需要）
```

## □ 其他

```
√ 水/运动饮料  □有 □没有
√ 毛巾        □有 □没有
√ 备用衣服    □有 □没有（打完换）
√ 球          □有 □没有（带了多少个：____）
√ 手机/钱包   □有 □没有
```
