# 📋 训练表格索引

> 全部表格已按类别分目录存放。A4纸打印，直接填写。

---

## 归档体系

```
templates/
├── README.md              ← 本文件（总索引）
│
├── A-日常/               ← 学员日常训练用（每次训练必带）
│   ├── README.md          ← 分类说明+打印建议
│   ├── A1-单次流程卡.md
│   ├── A2-技术纠错卡.md
│   ├── A3-周打卡表.md
│   └── A4-月评估表.md
│
├── B-比赛/               ← 比赛专用（上场前后用）
│   ├── README.md
│   ├── B1-赛前准备卡.md
│   ├── B2-赛中记录卡.md
│   └── B3-赛后复盘卡.md
│
├── C-教练/               ← 教练/带队用（带学员必备）
│   ├── README.md
│   ├── C1-学员档案.md
│   ├── C2-观察记录.md
│   ├── C3-排课表.md
│   └── C4-阶段报告.md
│
└── D-专项/               ← 专项场景（按需取用）
    ├── README.md
    ├── D1-生理期调整卡.md
    ├── D2-伤病追踪表.md
    ├── D3-步数记录表.md
    └── D4-装备检查表.md
```

## 使用建议

```
打印方式：
  全部A4竖版，单面或双面。
  建议每张打印50份，按月装订成册。

归档方式（推荐用文件夹按类别分页）：
  日常卷：A1+A3（天天用）
  技术卷：A2（按技术分类归档）
  比赛卷：B1+B2+B3（按比赛日期归档）
  学员卷：C1+C2+C4（按学员名归档）
  健康卷：D1+D2（按日期归档）

配套文档：
  所有表格均配套 zh/ 目录下的教学文档使用。
  每张表顶部标注了对应的文档章节。
```
