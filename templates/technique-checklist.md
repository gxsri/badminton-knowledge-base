# 技术自检清单

> 每次训练技术环节前快速过一遍。打勾表示"做到了"，空着表示"要注意"。

## 握拍自检

```
正手握拍：
  ☐ 虎口V形对齐拍柄右上棱
  ☐ 掌心是空的（能塞一根筷子）
  ☐ 小指和无名指固定拍子
  ☐ 食指单独勾在拍柄侧面
  ☐ 拍面垂直（举到眼前检查）

反手握拍：
  ☐ 拇指贴在拍柄斜面上（不是宽面正中间）
  ☐ 掌心同样是空的
  ☐ 拇指根部关节不酸（挑10个球后检查）
```

## 高远球自检（05-）

```
发力顺序：
  ☐ 脚先发力（脚底有踩地感）
  ☐ 髋转动（不是扭腰）
  ☐ 手臂最后动（放松像鞭子）
  ☐ 击球瞬间握紧

击球点：
  ☐ 在额头前方上方
  ☐ 拍子完全伸展时击球

完成后检查：
  ☐ 手臂不酸（酸=发力顺序错了）
```

## 步伐自检（11-）

```
启动：
  ☐ 对手击球前重心保持中立
  ☐ 分腿小跳落地时重心在两脚中间
  ☐ 确认方向再动，不靠猜

路线：
  ☐ 直线最短原则（不走弧线）
  ☐ 最后一步是蹬跨步

回位：
  ☐ 击球即回（不等看完球再回）
  ☐ 回位最后一步控制落地
```

## 网前自检（15-）

```
放网：
  ☐ 网前握拍（手指前移2-3cm）
  ☐ 拍面后仰15-20度
  ☐ 不是"打"，是"接"
  ☐ 手腕完全放松

挑球：
  ☐ 前臂发力（不是手腕捞）
  ☐ 高挑球拍面朝上
```
