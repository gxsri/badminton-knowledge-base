# templates/print/ — 印刷版训练表格

> 专为 A4 打印设计的 HTML 文件。打开浏览器 → 打印 → 输出纸质表格。

---

## 使用方法

```
1. 打开对应的 .html 文件（用浏览器打开）
2. Ctrl+P / Cmd+P 打印
3. 打印设置：
   - 纸张：A4
   - 边距：默认或最小
   - 背景图形：✓ 勾选（保留蓝色页头）
4. 打印即可
```

## 文件清单

| 文件 | 包含表格 | 打印页数 |
|:-----|:---------|:--------:|
| [A-日常.html](A-日常.html) | A1流程卡 + A2纠错卡(6张) + A3周打卡 + A4月评估 | 10页 |
| [B-比赛.html](B-比赛.html) | B1赛前 + B2赛中 + B3赛后 | 3页 |
| [C-教练.html](C-教练.html) | C1学员档案 + C2观察记录 + C3排课表 + C4阶段报告 | 4页 |
| [D-专项.html](D-专项.html) | D1生理期 + D2伤病追踪 + D3步数记录 + D4装备检查 | 4页 |

## 打印建议

```
单次使用：打开对应文件，打印当前页即可
批量印刷：将需要的 HTML 文件合并后批量打印
装订建议：按类别装订成册，封面用分类索引页
```

## 样式说明

- 每个表格自动分页（A4一页一张）
- 蓝色页头含编号+名称+配套文档
- 复选框为空心方框（□），打印后手写打✓
- 填空线为下划线，打印后手写填写
