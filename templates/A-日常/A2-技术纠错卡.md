# A2-1 正手高远球纠错卡

> **配套**：05-高远球、15-技术全解析  
> **用法**：练高远球时带这张，打一个检查一个

╔═══════════════════════════════════════════════╗
║  正手高远球  ——  纠错卡                      ║
╚═══════════════════════════════════════════════╝

### 发力顺序检查（打完5个球后过一遍）

```
□ 脚蹬地 —— 脚底有踩地感？（不是脚浮着）
□ 髋旋转 —— 髋先转还是肩先转？（髋先）
□ 腰腹收紧 —— 核心是紧的还是松的？（紧）
□ 手臂最后动 —— 手臂是不是甩出去的？（是）
□ 击球瞬间握紧 —— 听到"啪"不是"砰"？（啪）
□ 打完手臂酸不酸 —— 手臂酸=发力错了（不酸）
```

### 击球点检查

```
□ 高度：在额头前方上方
□ 前后：在身体前方
□ 拍子完全伸展时击球
```

### 常见问题速查

```
球打不远 → 先查发力顺序（脚→髋→腰→肩→手）
球太平 → 击球点太后/太低
球太高 → 击球点太前/拍面太朝上
球偏右 → 手腕内旋不够
球偏左 → 侧身不够
打完手臂酸 → 发力顺序错了——手臂发力代偿了
```

# A2-2 步伐纠错卡

> **配套**：11-步伐训练

╔═══════════════════════════════════════════════╗
║  步伐  ——  纠错卡                           ║
╚═══════════════════════════════════════════════╝

### 启动检查

```
□ 对手击球前重心保持中立（没有偏）
□ 分腿小跳落地时重心在两脚中间
□ 确认方向再动（不是靠猜）
□ 二次启动频率 < 每局2次
```

### 路线检查

```
□ 走直线（不是弧线）
□ 最后一步是蹬跨步（不是走上去）
□ 步数正手网前 1-2步
□ 步数反手后场 2-3步
```

### 回位检查

```
□ 击球同时已经开始回位（不等看完球）
□ 回位最后一步控制落地（不是冲回去）
□ 回位后重心在中立位
```

### 步数速查

```
位置             当前步数    目标步数    差距
正手网前        ____        1-2步
反手网前        ____        1-2步
正手后场        ____        2-3步
反手后场        ____        2-3步
```

# A2-3 网前技术纠错卡

> **配套**：15-技术全解析

╔═══════════════════════════════════════════════╗
║  网前技术  ——  纠错卡                       ║
╚═══════════════════════════════════════════════╝

### 放网检查

```
□ 网前握拍（手指前移2-3cm）
□ 拍面后仰15-20度
□ 手腕完全放松（不主动发力）
□ 球"自己弹过去"不是"我打过去"
□ 触球点在网带以下10cm以内
```

### 搓球检查

```
□ 拍面从球头侧面切过去（不是碰）
□ 球产生旋转
□ 球过网后向下走（不是向前飘）
□ 动作幅度<15cm（不是大幅挥拍）
```

### 挑球检查

```
□ 前臂发力（不是手腕捞）
□ 高挑球：拍面朝上，球高弧线到底线
□ 平挑球：拍面前倾，球平弧线到后场
```

### 常见问题速查

```
放网弹太高 → 拍面太朝上
放网弹太远 → 手腕紧张有发力
放网下网 → 拍面太朝下
搓球不转 → 没切到球头侧面
挑球不到位 → 用了手腕没用到前臂
```

# A2-4 杀球纠错卡

> **配套**：15-技术全解析

╔═══════════════════════════════════════════════╗
║  杀球  ——  纠错卡                           ║
╚═══════════════════════════════════════════════╝

### 准备检查

```
□ 侧身充分（左肩朝网）
□ 架拍拍头在头后方
□ 肘关节高于肩膀
□ 非持拍手抬起指向球
```

### 发力检查

```
□ 脚蹬地+髋旋转（全身发力）
□ 击球点在身体前上方最高点
□ 手腕内旋（像拧毛巾）
□ 击球瞬间握紧
```

### 落点检查

```
计划杀哪个区：________
实际落点：________
偏差：________
```

### 常见问题速查

```
杀球下网 → 击球点太低/拍面太朝下
杀球出界 → 击球点太后/拍面太朝上
杀球没力 → 没有用全身发力（只用了手臂）
杀完站不稳 → 重心前冲太多，落地时重心过高
```

# A2-5 反手技术纠错卡

> **配套**：15-技术全解析

╔═══════════════════════════════════════════════╗
║  反手技术  ——  纠错卡                       ║
╚═══════════════════════════════════════════════╝

### 握拍检查

```
□ 拇指贴在拍柄斜面上（不是宽面正中间）
□ 掌心是空的
□ 拇指根部关节不酸（挑10个球后检查）
```

### 反手高远球检查

```
□ 肘领先（肘先向球方向走，手在后面）
□ 前臂外旋（手掌从朝下转到朝上）
□ 手腕屈曲（击球时手腕向下"盖"）
□ 拇指顶推（拇指在击球瞬间前顶）
```

### 反手过渡球检查

```
□ 拍面控制方向（不是靠身体转向控球）
□ 过渡球弧度刚好过网（不是挑高球）
```

### 常见问题速查

```
反手打不远 → 肘没有先走/前臂没有外旋
反手打偏 → 拍面方向没控制好
拇指根部痛 → 夹太紧了
手臂酸 → 全程用大臂发力（应该用前臂+手腕）
```

# A2-6 发球与接发纠错卡

> **配套**：12-球路训练、15-技术全解析

╔═══════════════════════════════════════════════╗
║  发球与接发  ——  纠错卡                     ║
╚═══════════════════════════════════════════════╝

### 反手发短球检查

```
□ 站姿：两脚前后，重心在前脚
□ 球拍先触球（不是球先下落再触拍）
□ 击球点低于腰部
□ 拍框朝前（不是朝上）
□ 手腕不发力（靠前臂推送）
```

### 正手发高远球检查

```
□ 侧身站立
□ 球下落的同时引拍
□ 在腰部高度击球
□ 击球瞬间握紧拍子
```

### 接发球检查

```
□ 接发站位正确（往前一步还是往后一步？）
□ 重心放低（膝盖微曲）
□ 拍子举起（不是垂在下面）
□ 从接发开始就在思考"第三拍"
```
