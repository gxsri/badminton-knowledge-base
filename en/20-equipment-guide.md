# Chapter 1: The Three Biggest Buying Mistakes

```
Mistake ①: Beginners buy flagship rackets
  "Buy once, cry once" — wrong. A 3U head-heavy stiff racket is unusable for beginners.
  Result: bad form → injury → "this racket sucks"

Mistake ②: Buying shoes by looks, not fit  
  Badminton shoes come in narrow/standard/wide lasts. Wrong last → blisters → ankle sprain.

Mistake ③: Buying what the pros use
  Lin Dan's racket is built for Lin Dan, not for you.
```

# Chapter 3: Strings & Tension

## String Selection

| Type | Model | Price | Best for |
|:-----|:------|:-----|:---------|
| Thin (0.65mm) | BG-66 Ultimax | 35-45 RMB | Touch/control |
| Standard (0.67mm) | BG-80 | 30-40 RMB | Most players |
| Thick (0.70mm) | BG-65 | 25-30 RMB | Durability |

## Tension Progression

```
First stringing: 22-24 lbs → elastic feel, easy power
After 6 months: 24-25 lbs → better control
After 1 year: 25-26 lbs → precision
After 3 years: 26-28 lbs → stiff, needs clean hitting
```

## How to Talk to Your Stringer

```
❌ Bad: "String it at 25 lbs, BG-80."
✓ Good: "I've been playing about a year, 4U racket, 
   I'm using BG-80 at 25 lbs. I feel like I can't get 
   the shuttle deep enough. Should I lower tension?"
```

# Chapter 4: Shoes

## Fit by Foot Type

```
Narrow feet: Yonex (most models run narrow) → Yonex 65Z3, 88 Dial
Normal feet: Li-Ning, Victor (standard fit) → Li-Ning Flight, Victor P9200
Wide feet: Look for "wide" versions → Li-Ning Chamaleon, Victor P9200 Wide
```

## Shoe Lifespan

| Frequency | Lifespan |
|:----------|:--------:|
| 3x/week | 6-8 months |
| 2x/week | 8-12 months |
| 1x/week | 12-18 months |

Replace when: sole tread worn smooth, cushioning feels dead, ankle support loose

# Chapter 5: Grips & Accessories

```
Thin PU (0.5-0.6mm): best feel, Yonex AC102EX 15-25 RMB
Standard PU (0.7-0.8mm): balanced, Li-Ning GP1000 10-15 RMB
Replace grip: weekly (heavy sweat) / bi-weekly (light sweat)
```

# Chapter 6: Counterfeit Alert

```
High-risk fakes in China (2025-2026):
① Yonex high-end rackets (Astrox 99, Nanflare 800)
② Yonex BG series strings
③ Yonex AC series grips

Buy only from authorized dealers. Price >20% below market → likely fake.
```
