# Badminton Problem Diagnosis Index

> **Use**: When you have a problem, look up the symptom → find possible causes → go to the right document  
> **Print**: A4 front-and-back, keep in your bag

---

## 1. Technical Problems

```
Clear/smash lacks power ─┬─ Kinetic chain broken (legs→hips→core→arm sequence interrupted)
                         │   → [15-technical-training](15-technical-training.md) Ch.2
                         ├─ Contact point too low/too late
                         │   → [05-level1-technique](05-level1-technique.md) Ch.4
                         └─ Grip too tight before contact
                             → [15-technical-training](15-technical-training.md) Ch.1

Clear trajectory too flat ─┬─ Contact point behind head
                           │   → [05-level1-technique](05-level1-technique.md) Ch.4
                           └─ Backswing too late

Smash hits net ─┬─ Contact point too low
                │   → [15-technical-training](15-technical-training.md) Ch.3
                ├─ Racket face too closed
                └─ No forearm pronation

Backhand lacks distance ─┬─ Elbow doesn't lead (hand goes first)
                         │   → [15-technical-training](15-technical-training.md) Ch.2
                         ├─ No forearm supination
                         └─ Thumb on flat face (wrong grip)
                             → [15-technical-training](15-technical-training.md) Ch.1
```

## 2. Physical Problems

```
Arm sore after playing ─┬─ Kinetic chain broken (arm compensating)
                        │   → [15-technical-training](15-technical-training.md) Ch.2
                        ├─ Grip too tight throughout
                        │   → [15-technical-training](15-technical-training.md) Ch.1
                        └─ Insufficient strength
                            → [09-strength-conditioning](09-strength-conditioning.md) Ch.3-4

Knee pain ─┬─ Knee collapses inward (valgus)
           │   → [09-strength-conditioning](09-strength-conditioning.md) Ch.4
           ├─ Glute/quad strength insufficient
           │   → [09-strength-conditioning](09-strength-conditioning.md) Ch.4
           ├─ Insufficient warm-up → [22-warmup-cooldown](22-warmup-cooldown.md)
           └─ (Women) Hormonal ligament loosening
               → [21-women-training](21-women-training.md) Ch.3

Lower back pain ─┬─ Weak core (lumbar compensating)
                 │   → [09-strength-conditioning](09-strength-conditioning.md) Ch.3-4
                 ├─ Tight hip flexors (anterior pelvic tilt)
                 │   → [22-warmup-cooldown](22-warmup-cooldown.md) Ch.2
                 └─ Over-extending backward to reach shuttle
                     → [15-technical-training](15-technical-training.md) Ch.3

Shoulder pain ─┬─ Rotator cuff weakness
               │   → [09-strength-conditioning](09-strength-conditioning.md) Ch.3
               ├─ Elbow below shoulder at contact (impingement risk)
               │   → [15-technical-training](15-technical-training.md) Ch.3
               └─ Tight chest/rounded shoulders
                   → [22-warmup-cooldown](22-warmup-cooldown.md) Ch.2

Can't run in game 3 ─┬─ Insufficient aerobic base
                      │   → [09-strength-conditioning](09-strength-conditioning.md) Ch.5
                      ├─ Poor energy distribution in games 1-2
                      │   → [14-match-strategy](14-match-strategy.md) Ch.1
                      └─ Insufficient carbs before match
                          → [08-nutrition-recovery](08-nutrition-recovery.md) Ch.5
```

## 3. Mental/Match Problems

```
Nervous in matches ─┬─ Activation level too high
                     │   → [07-psychological-training](07-psychological-training.md) Ch.6
                     ├─ Technique not automated enough
                     │   → [15-technical-training](15-technical-training.md) Ch.5
                     └─ No pre-game routine
                         → [07-psychological-training](07-psychological-training.md) Ch.6

Chain errors after mistake ─┬─ No "break button" (emotion reset mechanism)
                            │   → [07-psychological-training](07-psychological-training.md) Ch.4
                            └─ Attention stuck on previous point
                                → [07-psychological-training](07-psychological-training.md) Ch.2

Blown leads ─┬─ Relaxed after getting ahead
             │   → [07-psychological-training](07-psychological-training.md) Ch.6
             ├─ Lost rhythm after break
             │   → [14-match-strategy](14-match-strategy.md) Ch.3
             └─ Opponent adjusted but you didn't
                 → [14-match-strategy](14-match-strategy.md) Ch.4
```

## 4. Footwork Problems

```
Slow start ─┬─ Center of gravity shifted before opponent contact
            │   → [11-footwork-training](11-footwork-training.md) Ch.3
            ├─ Too upright (knees straight → must squat first → one extra step)
            │   → [11-footwork-training](11-footwork-training.md) Ch.3
            └─ Slow reaction (waiting to see shuttle before judging direction)
                → [16-match-reading](16-match-reading.md) Ch.2

Arrived but no time to hit ─┬─ Didn't prepare racket during movement
                            │   → [11-footwork-training](11-footwork-training.md) Ch.5
                            ├─ Last step too short
                            │   → [11-footwork-training](11-footwork-training.md) Ch.5
                            └─ Route not straight (took extra steps)
                                → [11-footwork-training](11-footwork-training.md) Ch.4

Can't recover after hitting ─┬─ Watching own shot instead of recovering
                             │   → [11-footwork-training](11-footwork-training.md) Ch.6
                             ├─ Center of gravity too far forward
                             │   → [11-footwork-training](11-footwork-training.md) Ch.6
                             └─ Can't control final landing step
                                 → [11-footwork-training](11-footwork-training.md) Ch.6
```
