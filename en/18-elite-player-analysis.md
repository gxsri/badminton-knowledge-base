## Chapter 1: Men's Singles — Speed vs Control

### 1.1 Elite Profile Card

| Player | Style | Key Strength | Training Signature |
|:-------|:------|:-------------|:-------------------|
| Lin Dan | Control | Tactical execution, clutch mentality | 2hr+ video analysis daily |
| Lee Chong Wei | Attack | Net pressure + smash | 100 slow-motion swings/day |
| Viktor Axelsen | Attack | High smash point + court coverage | 80% power training philosophy |
| Kento Momota | Speed | Fastest swing speed in the game | Reactive shot training |

### 1.2 Progression Path (5 Levels)

```
L1: Amateur (1-3x/week) → basic rally capability
L2: Advanced Amateur (3-4x/week) → consistent technique
L3: Semi-Pro (5-6x/week) → automated technique under pressure
L4: Provincial/Pro → tactical execution
L5: National/World Class → complete tactical system
```

### 1.3 Training Workflow: L1→L2

```
Week 1-2: Forehand clear foundation
  - Fixed feed: 20 reps × 3 sets, rest 60s
  - Moving feed: 15 reps × 3 sets, rest 90s
  - Standard: 80% to back baseline

Week 3-4: Basic footwork
  - Single direction: 10 reps × 3 sets
  - Two directions: 10 random × 3 sets
  - Standard: Arrive in 3 steps
```

### 1.4 Methodology — 4 Principles

```
1. Training goal = Match demand
2. Training difficulty = Match difficulty + 10%
3. Automate technique first → then read the game
4. Fitness enables technique
```

## Chapter 2: Women's Singles

### Elite Profile Card

```
Modern WS has essentially merged with MS training methodology.
Key difference: female players have 50-60% of male upper body strength,
but 70-80% lower body strength and 85-95% aerobic capacity.

Key WS abilities:
① Defensive coverage (running ability)
② Rally stability (not making mistakes)
③ Transition offense (finding attack opportunities in defense)
```

## Chapter 5: Women's Doubles

### Elite Profile Card

```
WD characteristics:
  • Less smash threat → more rallies
  • Higher avg shots per point → more endurance needed

Key abilities:
① Serve & receive consistency
② Defensive ability (receiving smash + redirecting)
③ Smash & net coordination
```
