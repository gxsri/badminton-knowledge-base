# Chapter 1: Quick Start

## 1.1 Your First Day

```
If you're starting from zero, do these three things:

① Grip (5 min)
  Forehand: V-shape of thumb+index aligns with the top-right bevel.
    Palm should be hollow.
  Backhand: Thumb presses on the diagonal bevel (not the flat face).
  → See [15-technical-training](15-technical-training.md) Ch.1

② Shuttle juggling (10 min)
  Use forehand grip. Juggle the shuttle continuously.
  Target: 50 without dropping.
  This builds "shuttle feel."

③ Footwork self-test (10 min)
  From center → forehand net (touch the tape) → back to center.
  Count your steps. Test all 4 directions.
  Record your numbers. Re-test in one month.
```

## 1.2 Your First Week

```
If you can train 2-3x/week, 1.5hr each:

Session 1 (Technical): Clears + Footwork
  Warm-up 15min → Clear practice 30min → Footwork 20min → Cool-down 10min

Session 2 (Combined): Rally + Conditioning
  Warm-up 15min → Half-court rally 30min → Interval run 15min → Cool-down 10min

Session 3 (Free): Match or weak-point practice
```

# Chapter 2: Why — Core Principles

## Principle ①: Quality > Quantity

```
One sentence: 100 reps of the WRONG movement = 100 reps of consolidated error.

Why: Your neuromuscular system remembers what you repeat most.
  If you practice a flawed movement pattern, you're not "training" — 
  you're "entrenching errors."

How:
  ☐ When learning a new skill, go slow and get it RIGHT first
  ☐ If form breaks down → STOP. Don't "finish the set."
  ☐ 10 correct reps > 50 sloppy reps
```

## Principle ②: Control > Power

```
One sentence: Your nervous system must learn to control muscles FIRST.
  Only then can muscles generate power. The order cannot be reversed.

How:
  ☐ New skill → shadow swings first (no shuttle)
  ☐ Then fixed-position feeding (no movement, just the stroke)
  ☐ Finally, moving to the shuttle
```

## Principle ③: Prevention > Performance

```
One sentence: One injury sets you back to zero.
  Recovery time is 3-10x training time.

How:
  ☐ Warm-up ≥15 min before every session
  ☐ Cool-down ≥10 min after every session
  ☐ Don't "push through" pain
```

## Principle ④: Long-term > Short-term

```
One sentence: Neural adaptation takes 4-6 weeks.
  Connective tissue adaptation takes 3-6 months.

How:
  ☐ Schedule a deload week every 4-6 weeks (50% volume)
  ☐ Don't increase load every week — adaptation takes time
  ☐ Track progress monthly, not daily
```

## 3.1 A Single Training Session

```
┌──────────────┐
│ Warm-up 15min│  ← Never skip. See [22-warmup-cooldown](22-warmup-cooldown.md)
├──────────────┤
│ Technique    │  ← See "Technique Workflow" below
│ (30-50 min)  │
├──────────────┤
│ Conditioning │  ← Choose based on your goal
│ or Match     │
│ (15-30 min)  │
├──────────────┤
│ Cool-down    │  ← Never skip. See [22-warmup-cooldown](22-warmup-cooldown.md)
│ 10 min       │
└──────────────┘
```

## 3.2 Technique Learning Workflow

```
Step 1: Watch (1 min)
  Observe correct form (video/coach/diagram)
  Visualize the movement sequence

Step 2: Shadow swing (5 min)
  No shuttle. Focus on kinetic chain sequence (legs→hips→torso→arm)
  Mirror helps

Step 3: Fixed position (10 min)
  Shuttle in fixed position, no movement
  Focus on contact quality

Step 4: Moving to shuttle (10 min)
  Run from center → hit → recover
  Key: racket ready before arrival

Step 5: In game context (-)
  Use the skill in match play
  Errors allowed — goal is to USE it, not to be perfect
```
